# 新規記事の内容基準 (compact_review_v1)

本文の既存見出し・front matter・語義番号・コロケーション形式は
`entry_spec_v5.md` と `validate_entry.py` に合わせ、Notionとサイトの互換性を守る。
以下は執筆時の一枚の確認表であり、同じ項目の生成前棚卸しとdraft後自己監査を重ねない。

- 主要な現代語義と重要構文を独立した主要辞書2系統以上で確認し、語義境界を示す。
- 各例文の英語、所属語義、訳、文法パターンが自然に対応することを確認する。
- 類義語・反意語は意味の関係軸を示す。該当しない語に件数合わせをしない。
- 発音・語源・語形成は資料の言い方と地域差を正確に限定する。
- 統計的頻度と編集上の10段階目安を混同しない。地域・時代・専門用法を限定する。
- 大きく異なる周辺語義は存在と限定を短く示し、学習価値が高い場合だけ詳述する。
- 各主張と出典の対応を記録し、裏付けのない主要内容を断定しない。

執筆後に `validate_entry.py` で形式を一度確認し、具体的な内容の疑問を
独立レビューA/Bへ渡す。形式修正だけで内容レビューをやり直さない。
