# 指示書の入口

通常の作成では `entry_spec_v5.md`（本文の品質・書式）、新規チャットでの点検では
`independent_entry_review.md` を使う。運用はルートの `AGENTS.md` と
`docs/workflow_integrity.md` に従う。

`legacy_entry_spec_v5.md` は工程を含む旧生成仕様の原本。
`compact_*`、`check_*`、`cold_*`、`final_*`、`source_*`、`targeted_correction_*`
などの旧プロンプト・schemaは、旧runの再現・調査のために保存している。
そこに「現行」「必須」と書かれていても、新しい通常作業へ追加適用しない。
旧工程を明示的に扱う場合だけ `docs/legacy_workflows.md` を参照する。
