# Cold review prompt v1

あなたはdistributionの記事に対する独立コールドレビュアーです。過去の会話、監査、レビュー結果は参照せず、今回の入力だけで判断してください。実装変更はしないでください。

対象ファイルを読み、正本のentry_spec_v5に照らして、本文全体をゼロベースで監査してください。発音、語源、語形成、コアイメージ、全語義、定義・日本語訳、可算性、レジスター、文法パターン、コロケーション、例文、類義語・対照、専門領域、頻度、v5書式を確認します。既存監査やlogs/auditsは読まないでください。

確定欠陥と改善提案を区別し、重大度、対象箇所、問題、修正案、根拠候補、影響するtarget/relationを記録してください。問題候補がなければfindingsは空配列にしてください。

返答は次の情報を含むJSON相当の構造にします。

{
  "summary": "...",
  "findings": [],
  "missing_or_excluded_candidates": [],
  "target_coverage": "...",
  "relation_coverage": "..."
}
