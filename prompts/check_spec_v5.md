# check_spec_v5

このファイルは、利用者が2026-08-05に提示したチェック要件と本文書式を、リポジトリの独立監査へ適用する現行追加仕様である。

生成後の自動チェックおよび既存記事の個別チェックを始める前に、必ず次の順で全文を読む。

1. `prompts/entry_spec_v3.md`
2. `prompts/entry_spec_v4.md`
3. `prompts/entry_spec_v5.md`
4. `prompts/check_spec_v3.md`
5. `prompts/check_spec_v4.md`
6. `prompts/check_spec_v5.md`

全要件を累積適用し、衝突する場合だけv5を優先する。

## 二段階の独立チェック

1. 旧本文について、定義、ニュアンス、例文、訳、コロケーション、構文、自他、前置詞、冠詞、可算性、類義語、反意語、頻度、地域差、レジスター、語源、語形成、形式を校正する。
2. 旧本文の項目を完全と仮定せず、見出し語だけから語義・構文・品詞転換・句動詞・地域差・レジスターをゼロベースで棚卸しし、旧本文と比較する。

「ゼロベース」は旧本文を見ないことではない。旧本文に書かれた語義・構文だけを候補集合にせず、独立棚卸しを先に完成させることを意味する。1箇所だけ指摘された場合も同種の誤りや欠落を記事全体で確認する。

## v5書式監査

- 本文は `＃発音記号` から始まり、前置き・締め・次回予告・`【続きあり】` を含まない。
- 大見出しの有無と順序がv5生成仕様どおりである。
- 空行は独立ブロック間にちょうど1行で、2行以上連続していない。
- 構造見出し以外のすべての非空行が、行末半角スペースちょうど2個で終わる。
- コロケーションは4行固定、類義語・反意語は6行固定で、内部に空行がなく、エントリ間に空行が1行ある。
- `【日本語訳・定義】`、`【頻度】`、`【レジスター/領域】`、`【文法パターン】`、`【語法・注意】` はラベルと本文が同一行にある。
- `【コロケーション】`、`【類義語】`、`【反意語】` は単独行である。
- 独立した `【例文】` 欄、絵文字、裸名詞・裸動詞だけのコロケーションがない。

## 内容監査

- 高頻度の主要品詞・主要義・主要構文を、低頻度の特殊用法より先に確認する。
- 主要品詞、同一品詞内の主要義、自他、可算性、限定・叙述、字義・比喩・慣用義、主語・目的語の種類を確認する。
- 動詞、名詞、形容詞、副詞、短いフレーズについて、v3の構文棚卸し候補を機械的に出力せず、実在し学習価値がある構文を確認する。
- 句動詞、前置詞動詞、句前置詞動詞、自由結合、慣用表現を区別し、小辞、分離可能性、名詞・代名詞・再帰代名詞の位置、後続前置詞による意味差を確認する。
- 過去分詞・現在分詞の形容詞化、名詞化、限定・叙述、ハイフン、`be/get/become/seem` との結合を確認する。
- 語順・前置詞・小辞・品詞・目的語種類・評価・地域・レジスターに重要な差があれば、不適切な統合または細分化を修正する。
- `【文法パターン】` と `【コロケーション】` を双方向に照合し、主要構文の片側だけの収録を認めない。
- 各例文について、定義、構文、品詞、主語・目的語、レジスター、訳が同時に一致することを確認する。
- 類義語の違いが具体的な比較軸で説明され、反意語が同一意味軸上にあることを確認する。
- コアイメージの各枝と番号付き語義を対応させ、歴史的・専門的な別枝を無理に統合しない。
- 主要語義、主要構文、地域差、レジスター、語源を可能な限り複数の信頼できる資料と照合し、事実と推定を区別する。

## 修正と完了条件

- 誤り、重要な欠落、形式不備があれば、差分だけでなく修正版全文を記事ファイルへ反映する。
- 修正不要の箇所は不用意に変えないが、語義追加・統合・分割に伴う番号、頻度順、コアイメージ、構文、例文、相互参照は同期する。
- 修正後に `updated_at` と `prompt_version: entry_spec_v5` を更新し、`scripts/validate_entry.py` を再実行する。
- 独立棚卸しの全主要候補に本文収録先があり、本文だけにある全用法も自然に成立し、v5書式検査が成功した場合だけ `status: checked`、`checked: true` とする。
- 内容確認が残る場合は `status: needs_review`、`checked: false` とし、queueとlogsへ理由を記録する。
- チェック結果と本文を双方向照合し、重要項目の漏れ、不自然な追加、旧版・修正理由・会話断片の混入がないことを最後に確認する。
