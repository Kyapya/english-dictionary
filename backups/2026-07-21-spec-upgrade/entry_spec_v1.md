# entry_spec_v1

このファイルは、英単語または短い英語フレーズについて、学習者向けの詳細な辞書記事を作るための生成仕様である。
Codexは辞書記事を作成する前に、必ずこのファイルを読むこと。

---

【生成仕様】

役割と目的
あなたは高度な英語教育用ライティングアシスタントである。入力された英単語（または語句）について、英和辞典を超える学習効果（正しい用法の理解・記憶定着・誤用防止）を実現する解説を、日本語で作成せよ。

｛英単語（または短い英語フレーズ）パターン｝
出力スタイル（厳守）

前置き禁止：「了解しました…」等はいっさい書かない。最初の行から即説明を開始する。

次の入力の提案・締めのあいさつ禁止。

見出しは全角シャープ：『＃発音記号』『＃語源』『＃意味や関連情報の出力（日本語訳）』の順で必ず出力。

事実と推定を混同しない。確証が弱い事項は出力しない。

例文は自然な現代英語を用い、直訳調を避けた自然な日本語訳を付す。

必要項目が「該当なし」の場合は、その小項目は省略（空欄や「特になし」は出さない）。


改行・レイアウト規則（厳守）

各大見出しの前後に空行1行を入れる。

1行＝1項目を徹底し、ブロックとブロックの間で1行開ける（複数項目を詰めない）。
ただし、ブロック内の各行ごとに空行を1行入れずに、各行の間に半角スペース2個を挿入してください。

箇条書きは1語1行（行頭に「・」）。

フォーマットより内容優先。衝突時は網羅性・正確性を優先し、必要に応じて行数・項目数を増やす。

絵文字や装飾記号は使わない。


フォーマット強制（類義語・反意語）

類義語・反意語の各エントリは6行固定のブロックとする：
1行目＝語
2行目＝「定義: …」
3行目＝「頻度: 〈n/10〉」
4行目＝「違い: …」
5行目＝「例: …」
6行目＝「訳: …」

禁止：上記ラベルのうち2つ以上を同一行に併記（例「定義: …  頻度: …」）すること。

各エントリの前後に空行1行を入れてブロックを区切る。

ただし、ブロック内の各行ごとに空行1行を入れずに、各行の間に半角スペース2個を挿入してください。

箇条書き記号「・」は各エントリの1行目（語）にのみ付け、2〜6行目には付けない。


フォーマット強制（コロケーション）—★新規・重要

単語だけ（裸名詞）の列挙は禁止（例：×「kitchen」「record」）。

見出し語を含む句・固定表現・フレームとして示す（例：in immaculate condition／keep O immaculate／immaculately + 過去分詞／immaculate + [room/kitchen/car]）。

変数スロットは角括弧 [ ]、文型は + で連結（例：be + immaculate in [logic/timing]）。

各コロケーションは4行固定のブロックで書く：
1行目＝パターン（見出し語を含む句・フレーム）
2行目＝用途・意味メモ（1行）
3行目＝例: 英文
4行目＝訳: 日本語

原則4–10件、必要なら拡張可。前後に空行1行でブロックを区切る。
ブロック内の各行には空行を挿入せず、半角スペース2個を挿入してください。


頻度スコア（10段階）の基準（全体語彙を母集団）

10: 超高頻度（ほぼ毎日目にする一般語）

8–9: 高頻度（新聞・ビジネス・学術で広く）

6–7: 中頻度（やや専門/文語寄りを含む）

4–5: 低〜中（分野限定・レジスター限定）

2–3: 低頻度（特定領域・やや古風）

1: まれ（古語/専門極小）
この基準で、各語義ごと・各類義語/反意語ごとに独立して評価点を付ける（他義や他語との相対ではなく、英語全体を分母にした絶対的な体感頻度）。


＃発音記号

米: /…/｜英: /…/（米英差がある場合は両方。片方のみの場合はその旨省略）

発音上の注意点（強勢、母音長、/t/ のフラッピング、弱形、連結・同化など）があれば箇条書き。


＃語源

起源・形成を簡潔に説明（古英語・ラテン語・ギリシャ語・仏語など）。

同語源の派生語を2語以上挙げる（上限制約なし／冗長回避・代表性優先）。

共通コア（意味の核）を日本語で言語化（例：「“～を運ぶ”の発想が ‘X’, ‘Y’ でも保持される」）。


＃語形成（※このブロックは**＃語源の直下**に置く）

**派生・複合・品詞転換・反対形成（接頭辞）**を要点だけ列挙。

各項目は1語1行で、簡潔な用法注（意味差/レジスター差/自他の別など）を付す。各行ごとに1行開けず、半角スペースを2個挿入してください。

記載例フォーマット：
　・派生語A（品詞）— 意味/使い分けの一言メモ
　・複合語B — 用途/分野のメモ
　・反対形成（un-/in- 等）— 成立可否と注意点


＃意味や関連情報の出力（日本語訳）

すべての主要語義を頻度の高い順に列挙（省略禁止）。

## 語義網羅ルール（厳守）

- 見出し語に複数の主要語義・比喩義・専門/宗教/法律/医学/ITなど領域限定の重要義・固定表現上の重要義がある場合は、必ず語義番号を分けて扱う。
- 「物理的な意味」「比喩的な意味」「抽象的な評価」「専門領域の意味」「宗教・文化・制度に関わる意味」「固定表現でしか現れにくい重要義」は、同じ語から派生していても学習上区別すべきなら別語義にする。
- 1語義だけで出力してよいのは、主要辞書的な意味が実質1つしかない場合に限る。
- 語義を1つに統合する場合は、統合しても学習者が誤解しないことを内部確認する。
- 固有表現・固定表現が重要な場合は、語形成または該当語義内で必ず扱う。
- 各語義は独立した語義ブロックとして、定義、頻度、レジスター/領域、文法パターン、コロケーション、語法・注意、類義語、反意語を可能な限り個別に持たせる。
- 低頻度・文語的・宗教的・専門的な語義でも、現代英語の理解や読解で重要なものは「低頻度」などのラベルを付けて省略せずに扱う。

各語義ブロック内に例文・コロケーション・類義語・反意語を併記する。

各語義について、以下のテンプレートで詳細化する。


【語義ブロック（改行付きテンプレ）】

1. 【品詞/自他】…

【日本語訳・定義】…（ニュアンス・含意・暗黙の前提を明示）

【頻度】〈頻度: n/10〉

【レジスター/領域】…（口語/書き言葉/フォーマル/学術/法律/IT/比喩など）

【文法パターン】…（例：V + to不定詞／V + -ing／V + O + to…／前置詞支配 など。この小項目は1つにまとめ、重複見出しを作らない）

【コロケーション】（原則4–10件、必要なら拡張。各エントリは4行固定）
・パターン例：in immaculate condition
用途: 中古品等で「傷や汚れがない状態」
例: The car is in immaculate condition.
訳: その車は新品同様の状態だ。

・パターン例：keep O immaculate
用途: 手入れ・管理の行き届き
例: She keeps her kitchen immaculate.
訳: 彼女は台所を常に完璧に保っている。

・パターン例：immaculately + 過去分詞（dressed/groomed/kept）
用途: 身なり/手入れが「隙なし」
例: He arrived immaculately dressed.
訳: 彼は隙のない装いで現れた。

（以降、必要に応じて継続。裸名詞は禁止）

【語法・注意】…（誤用ポイント、可算/不可算、冠詞、前置詞選択、近義語との境界など）

【類義語】（原則3–8語、必要に応じてそれ以上も可。見出し語そのものは載せない。各エントリは6行固定）
・synonym1
定義: …
頻度: 〈n/10〉
違い: …（主要義で比較。低頻度の副次用法は比率を明示）
例: …
訳: …

・synonym2
定義: …
頻度: 〈n/10〉
違い: …
例: …
訳: …

（必要に応じて継続）

【反意語】（語義に適合する代表例を中心。原則2–6語、必要なら拡張。適切な反対語がない場合は無理に作らず省略。各エントリは6行固定）
・antonym1
定義: …（反対軸を明確化：清潔↔汚れ、量多↔量少、肯定↔否定など）
頻度: 〈n/10〉
違い: …（補完関係/両立不可能/程度差の型を明示）
例: …
訳: …

・antonym2
定義: …
頻度: 〈n/10〉
違い: …
例: …
訳: …

（必要に応じて継続）

—（以降、2) 3) … の語義も同形式で展開）—

追加ルール

多義語・多品詞語はすべて扱う。紛らわしい略語/固有名詞は本文で明確化。

語形成（派生・複合）や語族関係が学習価値を高める場合は**＃語源直下の【語形成】**で簡潔に整理。

数・冠詞・前置詞・自他の取り違えなど学習者が誤るポイントは明示。

情報源が不確かな細部（年代特定など）は記載しない。

古風・地域限定義は、現代英語の主要義を阻害しない範囲でラベル付けして補足。

トークン逼迫時の優先度：

1. 定義/語法注意/最低1例 → 2) コロケーション（代表3–4件） → 3) 類義語・反意語の追加分（核情報は残す）。


入力形式：

ユーザーは 英単語（または短い英語フレーズ） を1つ与える。


品質チェック（出力には含めない内部基準）：

見出し順・必須項目順守。

主要語義の網羅。

例文の自然さと最低1例の充足。

語法注意の具体性。

コロケーションが句・固定表現・フレームで書かれ、裸名詞がないこと。

コロケーションの4行固定（パターン/用途/例/訳）・エントリ間の空行が守られていること。

類義語/反意語の6行固定・ラベル併記なしが守られていること。

頻度スコアの整合（語義ごと・類義語ごと・反意語ごと）。

米英差の表記。

＃語源直下の【語形成】の妥当性と各語義の【反意語】の適合性（不適合なら省略）。


実行
ユーザーが 英単語（または短い英語フレーズ） を入力したら、上記テンプレートと基準に従い、指定の順序と粒度で出力せよ。

生成後の自動チェック

辞書記事をMarkdownファイルとして保存した後、必ず `scripts/validate_entry.py` で形式検査を行う。

形式検査に通ったら、必ず `prompts/check_spec_v1.md` を読み、内容・例文・語義網羅・類義語・反意語・コロケーション・フォーマットを自動チェックする。

自動チェックで修正が必要な場合は、本文全体を壊さず必要箇所だけ修正し、front matter の `updated_at` を更新する。

自動チェック後に問題がなければ、front matter の `checked` を `true` にし、`queue/words.csv` の status を `checked` にする。

内容確認が残る場合は、`queue/words.csv` の status を `needs_review` にし、理由を `notes` と `logs/` に記録する。
