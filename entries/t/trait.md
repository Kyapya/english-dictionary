＃発音記号

米: /treɪt/｜英: /treɪt/、また /treɪ/。1音節で、第1音節の母音は二重母音 /eɪ/。英国の追加変異では、この音節の末尾の子音 /t/ を発音しない。英国では必ず t を読まないというわけではない。標準的な /treɪt/ の複数形 traits は /treɪts/ となる。  

＃語源

フランス語を通じて、ラテン語 tractus「引くこと・線」、さらに trahere「引く」に遡る。初期には、ペンや鉛筆で引いた一筋の線・描画の一筆を指す用法があり、人物を描き分ける個別の特徴という意味につながった。英語での使用は16世紀に遡るが、一つの年を語の誕生年として固定しない。  

trace とも、「引く・線を残す」に関係する語源的なつながりがある。ただし現在の trait は通常「跡を追う」という動詞ではなく、個別の特性を表す名詞である。  

＃語形成

・traits：可算名詞の複数形。personality traits のように複数の特性を並べて捉える。  

・personality trait／character trait：性格の中の個々の特性を表す複合的な名詞表現。personality や character という性質全体と、個別の trait を区別する。  

・trait-based：trait と based を組み合わせた複合修飾で、特性を基準とすることを示す。専門分野により、何を特性として扱うかは異なる。  

＃意味・用法・関連表現

1. 【名詞：可算】特性・性格上の特徴

【日本語訳・定義】人や物を特徴づける個別の性質。とくに、人の性格や行動傾向の一面を述べるのによく使う。長所にも短所にも用い、必ず生まれつき・永久不変という条件は含まない。  

【頻度】〈7/10〉  

【レジスター/領域】一般・人物評・心理や行動の説明。  

【文法パターン】a trait／have several traits／personality traits／a defining trait／share a trait with someone／a trait associated with something。  

【コロケーション・構文例】

・personality traits  
用途: 性格を構成する個別の特性を述べる。  
例: The survey asks participants to describe their personality traits.  
訳: その調査では、参加者に自分の性格特性を説明してもらう。  

・a defining trait  
用途: その人らしさをよく示す特性を述べる。  
例: Curiosity is one of her defining traits.  
訳: 好奇心は、彼女らしさをよく表す特性の一つだ。  

・share a trait with someone  
用途: 他者と特性が共通することを述べる。  
例: She shares several character traits with her brother.  
訳: 彼女には、兄と共通する性格上の特徴がいくつかある。  

・a desirable trait  
用途: 望ましいと評価される特性を述べる。  
例: Patience is a desirable trait in a teacher.  
訳: 忍耐強さは、教師に望まれる特性だ。  

・a trait associated with something  
用途: ある傾向や状態との関連を述べる。  
例: The researchers examined traits associated with persistence.  
訳: 研究者たちは、粘り強さと関連する特性を調べた。  

【語法・注意】一つなら a trait、複数なら traits とする。one of her traits では of の後ろは複数。share a trait with … は特徴の共通性を述べるだけで、必ず遺伝が原因だと証明する表現ではない。trait を人の内面だけ、feature を外見だけと排他的に区分しない。  

【類義語】

・characteristic  
定義: 人や物を特徴づける性質。  
頻度: 〈7/10〉  
違い: trait と使用可能な対象は重なる。characteristic は物・集団・現象の特性にも広く使われ、trait は性格・行動・生物形質の説明と結びつきやすい。対象を排他的に分ける違いではない。  
例: The material has several unusual characteristics.  
訳: その素材には、珍しい特性がいくつかある。  

・feature  
定義: 目立つ部分・特徴的な要素。  
頻度: 〈8/10〉  
違い: 具体的な部分や製品の装備まで含む。trait は個体の性格・性質を一つの特性として捉えることが多い。  
例: The roof is the building's most unusual feature.  
訳: 屋根が、その建物で最も珍しい特徴だ。  

・quality  
定義: 人や物が持つ性質。  
頻度: 〈8/10〉  
違い: 広い語で、人について褒める文脈でもよく使うが、良い性質だけに限定されない。trait 自体も良し悪しを決めない。  
例: Her calmness is a quality I admire.  
訳: 彼女の落ち着きは、私が尊敬する資質だ。  

・attribute  
定義: 人や物に備わるものとして捉える性質・資質。  
頻度: 〈6/10〉  
違い: attribute は対象について認める個々の特質を広く述べ、trait は性格・行動などを特徴づける一面として捉えやすい。意味は大きく重なり、attribute は後天的、trait は生得的といった固定的な分け方はしない。  
例: Reliability is an important attribute in this role.  
訳: この役割では、信頼できることが重要な資質となる。  

2. 【名詞：可算】形質

【日本語訳・定義】生物の形態・生理・行動などに関わる、記述・測定・比較できる特徴。遺伝子、環境、または両者の関わりによって現れるものを含む。  

【頻度】〈5/10〉  

【レジスター/領域】生物学・遺伝学・育種。  

【文法パターン】an inherited trait／an acquired trait／a physical trait／a quantitative trait／variation in a trait。  

【コロケーション・構文例】

・an inherited trait  
用途: 遺伝する特徴を述べる。  
例: The study follows an inherited trait across several generations of plants.  
訳: その研究は、植物の遺伝形質を複数の世代にわたって追跡している。  

・a physical trait  
用途: 身体的な特徴を述べる。  
例: The two populations differ in several physical traits.  
訳: 二つの集団は、いくつかの身体的形質で異なる。  

・a quantitative trait  
用途: 数値で測れる形質を述べる。  
例: Height is a quantitative trait influenced by both genes and environment.  
訳: 身長は、遺伝子と環境の両方の影響を受ける量的形質だ。  

・variation in a trait  
用途: ある形質に見られる変異を述べる。  
例: The experiment measured variation in this leaf trait in plants grown under different conditions.  
訳: その実験は、異なる条件で育てた植物において、葉のこの形質に見られる変異を測定した。  

【語法・注意】trait 全般を「遺伝だけで決まるもの」と定義しない。inherited は遺伝することを追加指定し、acquired は後天的に獲得されたことを示す。個々の trait は個体の phenotype「表現型」の一部であり、両語を常に同義として交換するわけではない。  

dominant/recessive trait は優性・劣性などの遺伝様式に関わる表現で、望ましい・劣っているという価値判断ではない。どの形質がどのように遺伝するかや、個人の健康状態は、trait という語の意味だけから判断しない。  

生物学の character も、形態・機能などの「形質」を表し、trait と重なる。この character を人の性格と訳さない。一方、研究によって分類・比較の単位や用語の使い分けが定められる場合があるため、どの文献でも両語が完全に交換可能だとは決めない。  

3. 【名詞：可算、プログラミング用語】共有する振る舞いを定義する仕組み

【日本語訳・定義】Rust で、型が備える機能・振る舞いを抽象的に定め、異なる型がその振る舞いを共有できるようにする仕組み。  

【頻度】〈2/10〉  

【レジスター/領域】Rustの型・ジェネリクスの説明。  

【文法パターン】define a trait／implement a trait for a type／a trait bound／a default trait method。  

【コロケーション・構文例】

・implement a trait for a type  
用途: 型に特定の振る舞いを実装することを述べる。  
例: The library implements the trait for several data types.  
訳: そのライブラリは、複数のデータ型に対してそのトレイトを実装している。  

・a trait bound  
用途: ジェネリックな型に求める振る舞いの条件を述べる。  
例: The function uses a trait bound to specify the behavior its input type must support.  
訳: その関数は、入力の型に必要な振る舞いを指定するため、トレイト境界を使っている。  

【語法・注意】日常語の「性格上の特徴」ではなく、言語の型システムに関わる専門用語。他言語の interface と似た面はあるが、すべての規則が同じではない。メソッドの宣言だけでなく既定実装を持てる場合もあり、「中身のある処理を書けないもの」とはしない。  

4. 【名詞：可算、プログラミング用語】クラス間で機能を再利用する仕組み

【日本語訳・定義】PHP で、メソッドなどの機能をまとめ、異なるクラスへ取り込んで再利用できるようにする仕組み。通常のクラス継承とは別に、振る舞いを組み合わせるために使う。  

【頻度】〈2/10〉  

【レジスター/領域】PHPのオブジェクト指向プログラミング。  

【文法パターン】use a trait／define a trait／combine traits／a class using a trait。  

【コロケーション・構文例】

・use a trait  
用途: クラスで機能のまとまりを利用することを述べる。  
例: The two classes use the same trait to share logging behavior.  
訳: 二つのクラスは、ログ記録の振る舞いを共有するために同じトレイトを使っている。  

・combine traits  
用途: 複数の機能のまとまりを組み合わせることを述べる。  
例: The class combines two traits rather than inheriting from two parent classes.  
訳: そのクラスは、二つの親クラスを継承するのではなく、二つのトレイトを組み合わせている。  

【語法・注意】トレイト自体を通常のクラスのように単独でインスタンス化する仕組みではない。Rust の trait と名前が共通でも、PHP のコード再利用機構と同一の定義・規則だと考えない。  

プログラミングの trait は言語ごとの専門定義を確認する必要がある。ここでは語の意味と基本的な用語の関係を説明しており、バージョン別の競合解決や継承の細則を網羅するものではない。
