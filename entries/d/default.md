＃発音記号

米・英: /dɪˈfɔːlt/。2音節で、第2音節に強勢を置く発音。名詞、特に「既定値・設定」の意味では /ˈdiːfɔːlt/ という第1音節に強勢を置く発音もある。この別形では第1音節の母音も /ɪ/ から /iː/ に変わる。  
英国英語には第2音節の母音を /ɒ/ とする /dɪˈfɒlt/、米国英語には /ɑː/ とする /dɪˈfɑːlt/ もある。これらは第2音節の母音の違いであり、品詞を必ず区別するものではない。過去形・過去分詞は defaulted、現在分詞は defaulting で、defaulted の語尾は /ɪd/。  

＃語源

中英語 defaute・defaulte を経て、古フランス語・アングロフランス語の「不足・欠如・不履行」を表す語に由来する。背景には defaillir「欠ける・果たせない」があり、さらにラテン語 fallere の系統につながる。現在の英語では「義務を果たさないこと」と「別の指定がないときの選択」を区別して覚える。  
同系統の語には fail「失敗する・果たせない」と fault「欠点・落ち度」がある。現在の綴りを単に de- と英語の fault に分けて、新しい意味を組み立てるわけではない。  

＃語形成

・defaulter：支払いや義務を履行しない人・組織を表す可算名詞。金融では債務不履行者。  
・defaulting：default の現在分詞。a defaulting borrower「返済を履行しない借り手」のように使う。  
・defaulted：default の過去形・過去分詞。a defaulted loan「不履行となった融資」、a defaulted player「失格処分を受けた選手」など、元の用法に応じて意味が変わる。  
・default risk：債務不履行の可能性に伴うリスクを表す複合名詞。  
・default judgment：訴訟上の応答・防御の懈怠に基づく判決。単なる「通常の判決」ではない。  

＃コアイメージ

履行・参加・別の指定などがないことを起点に、その欠如や、それに応じた状態・扱いを表す。未指定時の設定や習慣的な選択は、利用者が義務違反をしたという意味ではない。  

・別の指定がない場合の選択肢 → 「既定値・標準設定・自然に採用される選択肢」（語義1）  

・別の指定がない場合の選択肢の性質 → 「既定の・通常採用される」（語義2）  

・別の指定がない場合の選択動作 → 「既定で～になる・自然に～を選ぶ」（語義3）  

・義務の不履行という状態 → 「債務不履行・義務の不履行」（語義4）  

・当事者による義務の不履行 → 「返済・契約義務を履行しない」（語義5）  

・応答・防御がない場合の訴訟上の状態 → 「訴訟上の応答・防御の懈怠」（語義6）  

・参加・条件充足がない場合の競技の決着 → 「不戦敗・棄権・失格による決着」（語義7）  

・必要な物・手段がない場合の条件 → 「in default of：～がないために・～がなければ」（語義8）  

・応答・防御・出廷がない場合の当事者の行為 → 「訴訟で答弁・防御・出廷を怠る」（語義9）  

・参加・条件充足がない場合の競技者の棄権 → 「競技を棄権する・不戦敗になる」（語義10）  

・参加・条件充足がない場合の試合の放棄 → 「試合を棄権する・不戦敗にする」（語義11）  

・参加・条件充足がない場合の選手への処分 → 「選手・チームを失格にする」（語義12）  

・債務・支払いを対象とする義務の不履行 → 「債務・支払いを履行しない」（語義13）  

・応答・防御がない場合の当事者への処分 → 「当事者を訴訟上の懈怠として扱う」（語義14）  

・不履行となった債務について貸し手が行う扱い・記録 → 「口座・債務を不履行として扱う」（語義15）  

＃意味・用法・関連表現

1. 【名詞・可算／不可算】既定値・標準設定・自然に採用される選択肢

【日本語訳・定義】特別な指定・変更・積極的な選択がなければ採用される値、設定、方法、状態。コンピューターでは選択を省略した際に使われる設定を指し、一般の場面では習慣的な選択肢や、ほかに選択がないため成立する結果を指す。「最善」や「変更不能」を意味するわけではない。  

【頻度】〈8/10〉  

【レジスター/領域】一般・仕事・IT。by default は日常的にも使われる。  

【文法パターン】the default＝既定の選択肢／use something as the default＝それを既定のものとして使う／set something as the default＝それを既定にする／the default is to do something＝特に指定がなければそうする／restore the defaults＝既定の設定に戻す／by default＝変更や積極的選択がなければ・成り行きで。個々の設定は a default や defaults と数えることもある。  

【コロケーション・構文例】

・use something as the default  
用途: 設定を省略した場合の選択肢を示す。  
例: The app uses English as the default until you choose another language.  
訳: そのアプリは、別の言語を選ぶまで英語を既定の言語として使う。  

・set something as the default  
用途: 通常使うものとして設定する。  
例: You can set this printer as the default.  
訳: このプリンターを既定のプリンターに設定できます。  

・the default is to do something  
用途: 指定しなかった場合の動作・方法を述べる。  
例: The default is to save a copy on your device.  
訳: 特に変更しなければ、端末にコピーを保存する設定になっている。  

・restore the defaults  
用途: 変更した設定を既定値へ戻す。  
例: Click this button to restore the defaults.  
訳: このボタンをクリックすると、設定が既定値に戻ります。  

・by default  
用途: 変更しない場合の動作・状態を示す。  
例: Notifications are disabled by default.  
訳: 通知は既定では無効になっている。  

・become something by default  
用途: 積極的な選択より、ほかに候補がない結果を表す。  
例: I became the team leader by default when no one else volunteered.  
訳: ほかに立候補する人がいなかったため、成り行きで私がチームリーダーになった。  

【語法・注意】This is the default. は名詞、a default setting は語義2の形容詞的な限定修飾、The app defaults to English. は語義3の動詞。by default には冠詞を入れず、by the default とはしない。in default は語義4・6の「不履行・懈怠の状態」であり、by default「既定で」とは別表現。win by default の競技用法は語義7。日本語の「デフォルト」を「当然いつもそう」と広く使う場面でも、英語では選択を省略した結果や習慣的選択という関係が必要になる。  

【類義語】

・preset  
定義: あらかじめ保存された設定、または設定の組み合わせ。  
頻度: 〈6/10〉  
違い: 手動で選ぶプリセットもあるため、選択しない場合に採用される default とは一致しないことがある。  
例: I saved the color adjustments as a new preset.  
訳: 色調整を新しいプリセットとして保存した。  

・fallback  
定義: 第一の方法が使えない場合に頼る代替手段。  
頻度: 〈6/10〉  
違い: 初めから使う既定値より、ほかが使えなかった場合の予備という点を強調する。  
例: We kept the paper forms as a fallback.  
訳: 私たちは、代替手段として紙の用紙を残しておいた。  

・norm  
定義: 通常のものとみなされる状態・やり方。  
頻度: 〈8/10〉  
違い: 多く見られる実態や標準に重点があり、未指定時の設定である必要はない。  
例: Working from home has become the norm for this team.  
訳: このチームでは在宅勤務が通常の働き方になった。  

2. 【形容詞・原則限定用法】既定の・通常採用される

【日本語訳・定義】ほかの指定がなければ使われる設定・値・選択肢であることを、名詞の前で示す。ITの設定だけでなく、人や組織が自然に採用する方法や立場にも使う。  

【頻度】〈8/10〉  

【レジスター/領域】一般・IT・仕事。辞書によっては名詞の限定用法と分類される。  

【文法パターン】a default setting＝既定の設定／the default browser＝既定のブラウザー／a default value＝未指定時に使う値／the default option＝通常採用される選択肢／one’s default response＝いつもの反応。通常は名詞の前に置き、very default や more default のような程度表現は用いない。  

【コロケーション・構文例】

・a default setting  
用途: 変更前に使われる設定を指す。  
例: The default setting keeps the screen on for one minute.  
訳: 既定の設定では、画面は1分間点灯したままになる。  

・the default browser  
用途: リンクを開く際などに通常使うブラウザーを指す。  
例: Changing the default browser does not delete your bookmarks.  
訳: 既定のブラウザーを変更しても、ブックマークは削除されない。  

・a default value  
用途: 入力を省略したときに使う値を示す。  
例: This field has a default value of zero.  
訳: この欄の既定値はゼロです。  

・the default option  
用途: 特に別の選択をしない場合の選択肢を示す。  
例: Email is the default option for receiving receipts.  
訳: 領収書の受け取り方法は、既定では電子メールです。  

・one’s default response  
用途: 習慣的・自動的に出る反応を表す。  
例: Her default response to a difficult question is to ask for more evidence.  
訳: 難しい質問を受けたとき、彼女はいつも、さらに根拠を求める。  

【語法・注意】The browser is the default. の default は語義1の名詞。通常の文章で形容詞の述語用法として The browser is default. とするのは避け、It is the default browser. とする。default settings では default に複数の s を付けず、名詞 settings を複数にする。default judgment の default は語義6の訴訟上の懈怠に関わる修飾であり、「標準の判決」という意味ではない。  

【類義語】

・preset  
定義: あらかじめ設定された。  
頻度: 〈6/10〉  
違い: 事前設定という時点に焦点があり、通常選ばれる設定である必要はない。  
例: The camera offers several preset exposure modes.  
訳: そのカメラには、あらかじめ設定された露出モードがいくつかある。  

・standard  
定義: 通常の仕様・標準に沿った。  
頻度: 〈9/10〉  
違い: 標準性を表すが、ユーザーが選択しなかったときに使うという条件は含まない。  
例: The standard package includes technical support.  
訳: 標準パッケージには技術サポートが含まれる。  

・usual  
定義: ふだんの・いつもの。  
頻度: 〈9/10〉  
違い: 一般的な習慣や頻度を述べる語で、設定の仕組みを示さない。  
例: We met at our usual place.  
訳: 私たちはいつもの場所で会った。  

3. 【動詞・自動詞＋to】既定で～になる・自然に～を選ぶ

【日本語訳・定義】ほかの指定や有効な選択肢がないとき、システムなどがある値・動作を自動的に採用する。また、人や組織があまり考えず、いつもの方法・反応に戻ることにも使う。後者には惰性的という批判が伴うことがあるが、必ず悪い選択という意味ではない。  

【頻度】〈7/10〉  

【レジスター/領域】IT。人の習慣的選択を述べる用法は一般・仕事でも使う。  

【文法パターン】something defaults to 〈設定・値〉＝指定がなければその値を使う／someone defaults to 〈方法・反応〉＝自然にその方法や反応を選ぶ／default to doing something＝いつもの行動をする。to は前置詞で、名詞・代名詞・動名詞を続ける。分離しない。  

【コロケーション・構文例】

・default to 〈設定・値〉  
用途: 入力や選択がない場合のシステム動作を示す。  
例: If no language is selected, the menu defaults to English.  
訳: 言語を選択しなければ、メニューは既定で英語になる。  

・default to zero  
用途: 数値が未指定の場合の値を示す。  
例: The counter defaults to zero when the file contains no saved value.  
訳: ファイルに保存された値がなければ、カウンターはゼロを既定値とする。  

・default to 〈方法・反応〉  
用途: 人がいつもの選択や反応をすることを述べる。  
例: Under pressure, the manager tends to default to familiar routines.  
訳: プレッシャーがかかると、その管理者は慣れた手順に頼りがちだ。  

・default to doing something  
用途: 習慣的な行動を動名詞で示す。  
例: When we cannot agree on dinner, we default to ordering pizza.  
訳: 夕食を何にするか決まらないと、私たちはいつもピザを注文する。  

・default to it  
用途: 前に述べた選択肢を代名詞で受ける。  
例: The basic layout is available, and the app defaults to it for new documents.  
訳: 基本レイアウトが用意されており、新しい文書ではアプリがそれを既定で使う。  

【語法・注意】default to do something ではなく default to doing something。default to it を default it to に並べ替えない。この用法は通常自動詞で、設定を人が変更するなら set the value to zero とする。The program defaults to zero. は「プログラムが既定でゼロを使う」で、The borrower defaults on the loan.「借り手がローンを不履行にする」（語義5）とは前置詞も意味も異なる。defaulted/defaulting は基本的に動詞の活用形であり、この自動選択義から特別な分詞形容詞の意味は生じない。  

【類義語】

・fall back on  
定義: ほかの方法がないとき、頼れるものを使う。  
頻度: 〈7/10〉  
違い: 代替策に頼る点を強調する。システムの初期設定そのものを常に意味するわけではない。  
例: When the network failed, we fell back on paper records.  
訳: ネットワークが停止したとき、私たちは紙の記録に頼った。  

・revert to  
定義: 以前の状態や方法に戻る。  
頻度: 〈7/10〉  
違い: 以前そうだったという復帰を表す。default to は初回から使われる設定にも使える。  
例: The team reverted to its earlier schedule.  
訳: チームは以前の日程に戻った。  

・resort to  
定義: ほかに有効な手段がなく、ある方法に訴える。  
頻度: 〈7/10〉  
違い: やむを得ず使う、しばしば好ましくない方法という含みが強い。  
例: They resorted to borrowing money to cover the repairs.  
訳: 彼らは修理費を賄うため、やむなく借金に頼った。  

4. 【名詞・可算／不可算】債務不履行・義務の不履行

【日本語訳・定義】返済・利払いなどの支払義務、または契約上・法律上果たすべき義務を履行しないこと。金融では債務不履行を指すが、契約によっては金銭の未払い以外の約束違反も含む。個々の不履行事例は可算、状態・現象としては不可算で使う。  

【頻度】〈7/10〉  

【レジスター/領域】金融・経済・契約・法律。一般の単なる失敗より、義務との関係が強い。  

【文法パターン】a default on 〈債務・支払い〉＝その不履行／be in default on a loan＝ローンの不履行状態にある／go into default＝不履行状態になる／a default under an agreement＝契約に基づく不履行／the risk of default＝不履行の危険性／an event of default＝契約で不履行事由と定められた事象。  

【コロケーション・構文例】

・a default on 〈債務・支払い〉  
用途: どの債務を履行しなかったかを示す。  
例: A default on the bond payments would alarm investors.  
訳: その債券の支払いが不履行になれば、投資家は不安を抱くだろう。  

・be in default on a loan  
用途: 借り手・融資の不履行状態を表す。  
例: The company is in default on its bank loan.  
訳: その会社は銀行借入れの債務不履行状態にある。  

・go into default  
用途: 不履行状態になる変化を述べる。  
例: Several loans went into default during the downturn.  
訳: 景気後退の間に、複数の融資が債務不履行になった。  

・a default under an agreement  
用途: 支払い以外も含む契約上の不履行を示す。  
例: Failure to provide the required financial reports is a default under this agreement.  
訳: 必要な財務報告を提出しないことは、この契約では不履行に当たる。  

・the risk of default  
用途: 返済などが履行されない可能性を表す。  
例: The analyst said the risk of default had increased.  
訳: そのアナリストは、債務不履行のリスクが高まったと述べた。  

・an event of default  
用途: 契約内で定義された不履行事由を指す。  
例: The contract lists several events of default, including nonpayment.  
訳: その契約は、未払いを含む複数の不履行事由を列挙している。  

【語法・注意】in default は通常無冠詞で、a default は一つの事例を数える。default は insolvency「支払能力の不足」と同義ではなく、資力があっても義務を果たさなければ生じ得る。delinquency「延滞」との区別、治癒期間、通知や手続き、期限の利益の喪失・担保実行などの効果は契約と制度に依存する。「一度支払いが遅れると、どの契約でも直ちに財産を失う」と一般化してはならない。in default of payment は文脈により「支払いをしない場合に」で、語義8の欠如表現とも接する。名詞 This is a default. と動詞 They defaulted on the loan.（語義5）を区別する。  

【類義語】

・nonpayment  
定義: 支払うべき金銭を支払わないこと。  
頻度: 〈6/10〉  
違い: 金銭の未払いに限定する。default は非金銭的な契約義務の違反も含み得る。  
例: The service was suspended for nonpayment.  
訳: 未払いのため、そのサービスは停止された。  

・breach  
定義: 契約・規則・義務に反すること。  
頻度: 〈7/10〉  
違い: 作為による禁止事項違反も含む広い語。default は履行すべきことをしない側面が中心。  
例: The supplier admitted a breach of contract.  
訳: 供給業者は契約違反を認めた。  

・nonperformance  
定義: 義務や約束された行為を履行しないこと。  
頻度: 〈4/10〉  
違い: 契約上の履行がないことを直接述べるかたい語で、特定の金融状態を示すとは限らない。  
例: The dispute concerned nonperformance of the delivery obligations.  
訳: その紛争は、納入義務の不履行をめぐるものだった。  

5. 【動詞・自動詞】返済・契約義務を履行しない

【日本語訳・定義】人・企業・政府などが、負っている返済・利払い・契約上の義務を果たさない。金融で頻出し、支払不能による場合もあるが、意図的か、資力があるかまでは動詞自体で決まらない。  

【頻度】〈7/10〉  

【レジスター/領域】金融・経済・契約・報道。  

【文法パターン】someone defaults＝人・組織が不履行を起こす／default on a loan＝ローンの返済を履行しない／default on payments＝支払義務を履行しない／default on an agreement＝契約上の約束を守らない／default in the performance of 〈義務〉＝その義務の履行を怠る。on/in は前置詞で、後続語句を前に移動して分離しない。  

【コロケーション・構文例】

・default on a loan  
用途: 融資への返済不履行を述べる。  
例: The retailer defaulted on a large loan after its sales collapsed.  
訳: その小売業者は、売上げが激減した後、多額の融資の返済を履行しなかった。  

・default on payments  
用途: 元利金などの支払いを履行しないことを示す。  
例: The issuer defaulted on two interest payments.  
訳: その発行体は、2回の利払いを履行しなかった。  

・default on an agreement  
用途: 金銭以外も含む契約義務の不履行を述べる。  
例: The supplier defaulted on its agreement to deliver the equipment.  
訳: その供給業者は、機器を納入するという契約上の義務を履行しなかった。  

・default in the performance of 〈義務〉  
用途: 契約文などで履行義務を特定する。  
例: The notice alleged that the contractor had defaulted in the performance of its maintenance obligations.  
訳: その通知は、請負業者が保守義務の履行を怠ったと主張していた。  

・a borrower + default  
用途: 支払い対象が明らかなときに単独で使う。  
例: The lender may lose money if a borrower defaults.  
訳: 借り手が債務不履行を起こすと、貸し手は損失を被る可能性がある。  

【語法・注意】通常は default on a loan とする。default a loan という他動詞用法も実在するが、使用域が限られるため語義13に分ける。default on it は可能だが default it on とはしない。自動詞のため、この形そのものを be defaulted にしない。a defaulting borrower「不履行中の借り手」や a defaulted loan「不履行となった融資」は動詞に対応する分詞的修飾で、単に「標準設定の借り手・融資」という意味にはならない。They defaulted. と They are in default. は行為・出来事を動詞で述べるか、状態を名詞句で述べるかの違いがある。  

【類義語】

・renege on  
定義: 約束や合意を反故にする。  
頻度: 〈6/10〉  
違い: いったんした約束を覆す意図的な不誠実さを感じさせやすい。default は資金不足による不履行にも使う。  
例: The employer reneged on its promise to raise wages.  
訳: 雇用主は賃上げの約束を反故にした。  

・fail to pay  
定義: 支払うべき金銭を支払わない。  
頻度: 〈8/10〉  
違い: 平易で具体的な表現で、契約上 default に分類されるかは示さない。  
例: The tenant failed to pay the rent for June.  
訳: その借家人は6月分の家賃を払わなかった。  

・breach  
定義: 契約や義務に違反する。  
頻度: 〈7/10〉  
違い: 他動詞で breach a contract とする。禁止行為をした違反も含む。  
例: The company breached its agreement with the distributor.  
訳: その会社は販売代理店との契約に違反した。  

6. 【名詞・可算／不可算】訴訟上の応答・防御の懈怠

【日本語訳・定義】民事手続きなどで、請求に対して必要な答弁・防御・出廷などを行わないこと、またはその不作為に関する手続き上の状態。default judgment は、こうした懈怠を理由とする判決を指す。身体的に法廷へ来なかったことだけに限定されない。  

【頻度】〈5/10〉  

【レジスター/領域】法律・民事訴訟。具体的手続きは法域による。以下の entry of default と default judgment の区別は米国連邦民事手続きで明確に設けられている。  

【文法パターン】be in default＝訴訟上の懈怠状態にある／an entry of default＝懈怠の記録・登録／enter a default against someone＝当事者について懈怠を記録する／a default judgment＝懈怠に基づく判決／a judgment by default＝同じく懈怠を理由とする判決／set aside an entry of default＝懈怠の登録を取り消す。  

【コロケーション・構文例】

・be in default  
用途: 必要な応答をしない当事者の状態を示す。  
例: The defendant was in default after failing to respond to the complaint.  
訳: 被告は訴状に応答せず、訴訟上の懈怠状態にあった。  

・enter a default against someone  
用途: 応答しない当事者について懈怠を記録する。  
例: The clerk entered a default against the defendant, who had failed to plead or otherwise defend.  
訳: 書記官は、答弁その他の防御をしなかった被告について、懈怠を記録した。  

・a default judgment  
用途: 懈怠を理由とする判決を指す。  
例: The plaintiff applied for a default judgment after the entry of default.  
訳: 原告は、懈怠の登録後に欠席判決を申し立てた。  

・a judgment by default  
用途: 判決が懈怠に基づくことを示す。  
例: The court refused to enter a judgment by default because service had not been established.  
訳: 送達が確認されていなかったため、裁判所は欠席判決を出すことを拒んだ。  

・set aside an entry of default  
用途: 懈怠の登録の取消しを述べる。  
例: The judge set aside the entry of default for good cause.  
訳: 裁判官は、相当な理由があるとして懈怠の登録を取り消した。  

【語法・注意】日本語で default judgment を「欠席判決」と訳す場合も、default 自体を常に「不出廷」と狭く解釈しない。米国連邦民事訴訟規則55では、entry of default と default judgment は別の段階であり、懈怠が記録されただけで直ちに最終判決が出たことにはならない。誰が判決を記録できるか、取消しの条件なども別に定められる。民事上の default を刑事事件の有罪認定と同一視しない。The defendant defaulted. は語義9の自動詞である。  

【類義語】

・nonappearance  
定義: 必要な手続きに出頭・出廷しないこと。  
頻度: 〈4/10〉  
違い: 出頭しないという行為に限定する。答弁書を出さないなど、ほかの防御の欠如も含む default より狭い。  
例: The court recorded the witness’s nonappearance.  
訳: 裁判所は証人が出廷しなかったことを記録した。  

・failure to defend  
定義: 請求に対して防御を行わないこと。  
頻度: 〈4/10〉  
違い: 民事手続きで用いる説明的な定着表現。default という手続き上の状態の成立をそれだけで確定しない。  
例: The motion relied on the defendant’s failure to defend the action.  
訳: その申立ては、被告が訴訟で防御を行わなかったことを根拠としていた。  

7. 【名詞・可算／不可算】不戦敗・棄権・失格による決着

【日本語訳・定義】競技者が出場・続行しないこと、または規則上の理由で競技から除かれることによる敗北や決着。by default は「相手の不出場・棄権・失格などによって」勝つ、あるいは自分のそうした事情で負けるという意味になる。勝敗のどちら側かは win/lose などが決める。  

【頻度】〈5/10〉  

【レジスター/領域】スポーツ・競技。比喩的に議論や地位争いにも使う。競技規則上の細かな分類は種目・大会による。  

【文法パターン】win by default＝不戦勝・相手の失格などによって勝つ／lose by default＝不戦敗・失格などで負ける／a default＝一件の棄権・失格による決着／award a match to someone by default＝不出場・失格等を理由に勝利を与える。  

【コロケーション・構文例】

・win by default  
用途: 相手が競技しないために勝つことを示す。  
例: Our team won by default when the visitors failed to arrive.  
訳: 相手チームが到着しなかったため、私たちのチームは不戦勝となった。  

・lose by default  
用途: 自分の不出場などで負けることを示す。  
例: They lost by default after failing to field enough players.  
訳: 必要な人数の選手をそろえられず、彼らは不戦敗となった。  

・a default  
用途: 結果を一件の棄権・失格として数える。  
例: The referee recorded the result as a default, not a completed match.  
訳: レフェリーは、その結果を試合完了ではなく棄権・失格による決着として記録した。  

・award a match to someone by default  
用途: 運営側の裁定を述べる。  
例: The organizers awarded the match to Lee by default when his opponent did not appear.  
訳: 対戦相手が現れなかったため、主催者はリーの不戦勝とした。  

【語法・注意】by default 自体は「勝つ」という意味ではなく、lose by default も使う。a default は敗者側の不出場・失格や決着を指し、a walkover は通常、勝者側から見た不戦勝。競技の正式記録では withdrawal「出場取りやめ」、retirement「試合途中の棄権」、default「失格」などを区別することがあるため、すべての棄権を公式名称として default と呼ぶわけではない。語義10の自動詞、語義11の試合を目的語にする他動詞、語義12の選手を失格にする他動詞を区別する。  

【類義語】

・forfeit  
定義: 規則上の失格や不参加による試合の敗北。  
頻度: 〈5/10〉  
違い: 特に米国で不戦敗などを表す名詞として使う。金銭・権利の没収を表す別義もある。  
例: The result was recorded as a forfeit.  
訳: その結果は不戦敗として記録された。  

・walkover  
定義: 相手が競技できないことなどによる不戦勝。  
頻度: 〈5/10〉  
違い: 勝利を得る側に焦点がある。比喩では楽勝も意味するが、default に楽勝の意味はない。  
例: She advanced to the final after receiving a walkover.  
訳: 彼女は不戦勝で決勝に進んだ。  

・disqualification  
定義: 規則違反や資格の欠如による失格。  
頻度: 〈6/10〉  
違い: 出場・成績を認めない処分に重点がある。本人の単なる不参加による default とは区別する。  
例: The player’s disqualification ended the match.  
訳: その選手の失格によって試合は終了した。  

8. 【名詞を含む慣用表現】in default of：～がないために・～がなければ

【日本語訳・定義】必要なもの・よりよい代案・証拠などがないことを理由や条件として示す。しばしば、ないので別の方法を採るという文脈で使う。単なる「標準設定で」という意味ではない。  

【頻度】〈4/10〉  

【レジスター/領域】かたい書き言葉・事務的表現。  

【文法パターン】in default of 〈名詞・名詞句〉＝それがないために・ない場合に。句全体が前置詞句として働き、文頭または文末などに置く。default は通常無冠詞・単数で固定される。  

【コロケーション・構文例】

・in default of a better alternative  
用途: よりよい代案がない理由を述べる。  
例: In default of a better alternative, we used the original plan.  
訳: よりよい代案がなかったため、私たちは元の案を使った。  

・in default of evidence  
用途: 判断に必要な証拠がないことを示す。  
例: In default of evidence to the contrary, the committee accepted the report.  
訳: 反証がなかったため、委員会はその報告書を受け入れた。  

・in default of agreement  
用途: 合意が成立しない場合の扱いを示す。  
例: In default of agreement, the matter will be referred to a mediator.  
訳: 合意に至らなければ、その問題は調停人に付託される。  

・in default of payment  
用途: 支払いが行われない場合という条件を示す。  
例: The notice explains what may happen in default of payment.  
訳: その通知は、支払いがない場合に何が起こり得るかを説明している。  

【語法・注意】in default of a better alternative の a は alternative に付き、default に付く冠詞ではない。of の後には欠けているものを置く。in default on a loan「ローンの不履行状態にある」（語義4）とは構造も意味も区別する。in default of payment に続く法的な結果は、表現自体から一律に決まらない。日常語では for lack of や if there is no... が使いやすい。  

【類義語】

・for lack of  
定義: 必要なものが足りない・ないために。  
頻度: 〈7/10〉  
違い: 同じ欠如の理由を表す、より広く使われる表現。  
例: The project was canceled for lack of funding.  
訳: 資金不足のため、その計画は中止された。  

・in the absence of  
定義: ある人・物・条件が存在しない場合に。  
頻度: 〈7/10〉  
違い: 欠如だけでなく人の不在にも広く使う。代替策を採ることは必須ではない。  
例: In the absence of clear instructions, we waited.  
訳: 明確な指示がなかったため、私たちは待った。  

・failing  
定義: ある方法・選択肢が実現しない場合には。  
頻度: 〈5/10〉  
違い: 前置詞として使い、次善の手段を挙げることが多い。  
例: We can meet on Tuesday or, failing that, on Thursday.  
訳: 火曜日に会えますが、それが無理なら木曜日でもかまいません。  

9. 【動詞・自動詞】訴訟で答弁・防御・出廷を怠る

【日本語訳・定義】当事者が訴訟上必要な応答や防御を行わず、default の状態になる。通常は被告などが主語となる。  

【頻度】〈3/10〉  

【レジスター/領域】法律・民事訴訟。  

【文法パターン】a defendant defaults＝被告が答弁・防御などを怠る／default by failing to do something＝特定の不作為によって訴訟上の懈怠となる。直接目的語を取らない。  

【コロケーション・構文例】

・a defendant + default  
用途: 当事者自身の不作為を動詞で述べる。  
例: The defendant defaulted, and the plaintiff then sought a default judgment.  
訳: 被告が答弁・防御を怠り、その後、原告は欠席判決を求めた。  

・default by failing to answer  
用途: 応答しなかったことを明示する。  
例: The company defaulted by failing to answer the complaint.  
訳: その会社は訴状に答弁せず、訴訟上の懈怠となった。  

【語法・注意】The defendant defaulted. は当事者が主語の自動詞、The court defaulted the defendant. は裁判所が当事者を懈怠扱いにする他動詞（語義14）。be defaulted は後者の受動であり、自動詞 default に be を足した形ではない。懈怠から判決への手続きは語義6のとおり別に確認する。  

【類義語】

・fail to appear  
定義: 必要な場に姿を現さない・出廷しない。  
頻度: 〈6/10〉  
違い: 出廷しない場合に意味が重なるが、答弁しないという別の default は表さない。  
例: The defendant failed to appear at the scheduled hearing.  
訳: 被告は予定された審理に出廷しなかった。  

10. 【動詞・自動詞】競技を棄権する・不戦敗になる

【日本語訳・定義】選手やチームが予定された競技に参加しない、または完了せず、相手の勝利となる。辞書上は広い表現だが、公式記録でどの分類になるかは競技規則による。  

【頻度】〈4/10〉  

【レジスター/領域】スポーツ・競技。  

【文法パターン】a player/team defaults＝選手・チームが棄権する／default in a contest＝競技で不参加・未完了により負ける。直接目的語を取らず、理由は because of などで添える。  

【コロケーション・構文例】

・a player + default  
用途: 選手本人が競技できないことを述べる。  
例: His opponent defaulted because he could not reach the venue in time.  
訳: 対戦相手が時間までに会場へ来られず棄権した。  

・default in a contest  
用途: どの競技で不参加・未完了となったかを示す。  
例: The team defaulted in the final when it could not field enough players.  
訳: そのチームは必要な選手数をそろえられず、決勝で不戦敗となった。  

【語法・注意】The player defaulted. は本人側の不参加などを述べる。The player was defaulted. は審判などによる失格処分を表す他動詞の受動（語義12）で、常に交換できるわけではない。default the match は試合を目的語に取る語義11。負傷などによる途中棄権は、正式な競技分類では retirement と区別されることがある。  

【類義語】

・withdraw  
定義: 競技や大会への参加を取りやめる。  
頻度: 〈7/10〉  
違い: 出場前の辞退も含み、必ず不戦敗や相手の勝利を意味するとは限らない。  
例: She withdrew from the tournament because of illness.  
訳: 彼女は病気のため大会への出場を取りやめた。  

・forfeit  
定義: 不参加・違反などにより試合に負ける。  
頻度: 〈5/10〉  
違い: 自動詞では結果としての敗北に重点がある。他動詞では forfeit the game とする。  
例: The team had to forfeit because it had too few players.  
訳: そのチームは選手が足りず、不戦敗を受け入れなければならなかった。  

11. 【動詞・他動詞】試合を棄権する・不戦敗にする

【日本語訳・定義】予定された試合・競技を行わない、または完了せず、その試合を失う。選手・チームが主語、試合が目的語になる。  

【頻度】〈3/10〉  

【レジスター/領域】スポーツ・競技。自動詞用法より使用場面が限られる。  

【文法パターン】default a match/game＝試合を棄権して負ける／default it＝その試合を棄権する。試合を主語にした受動も可能。  

【コロケーション・構文例】

・default a match  
用途: 試合を直接目的語にして棄権を述べる。  
例: The team defaulted its opening match because several players were unavailable.  
訳: 複数の選手が出られなかったため、そのチームは初戦を棄権した。  

・default it  
用途: 前に述べた試合を代名詞で受ける。  
例: They could not field a full team for the game, so they defaulted it.  
訳: その試合に必要な人数をそろえられなかったため、彼らは棄権した。  

【語法・注意】default a match では、主語は試合をする側。default a player では、主語は選手に処分を下す側で、語義12となる。どちらも他動詞だが、目的語が試合か人かによって行為者と結果が異なる。競技の正式な記録用語と一般の叙述は区別する。  

【類義語】

・forfeit  
定義: 試合を不参加・規則違反などにより失う。  
頻度: 〈6/10〉  
違い: この意味では default より広く使われる他動詞。財産や権利を失う別義もある。  
例: The club forfeited the game after using an ineligible player.  
訳: 出場資格のない選手を使ったため、そのクラブは没収試合で敗れた。  

・concede  
定義: 試合の負けを認めて譲る。  
頻度: 〈5/10〉  
違い: 負けを認める意思に焦点があり、出場できない事情による default と同一ではない。  
例: The player conceded the match after losing the first two sets.  
訳: その選手は最初の2セットを落とした後、試合の負けを認めた。  

12. 【動詞・他動詞】選手・チームを失格にする

【日本語訳・定義】審判・大会運営側が、違反などを理由に選手やチームを試合・大会から除き、敗北とする。本人が棄権する用法とは、主語と目的語の役割が異なる。  

【頻度】〈4/10〉  

【レジスター/領域】スポーツ。特にテニスなどの競技規則・報道。  

【文法パターン】default a player＝選手を失格にする／default someone from a tournament＝人を大会から失格にする／be defaulted for 〈違反〉＝その違反で失格処分を受ける。受動態がよく使われる。  

【コロケーション・構文例】

・default a player  
用途: 審判などが選手に処分を下す。  
例: The referee defaulted the player for a serious code violation.  
訳: レフェリーは、重大な行動規範違反を理由にその選手を失格にした。  

・be defaulted from a tournament  
用途: どの大会から除かれたかを述べる。  
例: He was defaulted from the tournament after threatening an official.  
訳: 彼は役員を脅した後、大会から失格処分を受けた。  

・be defaulted for 〈違反〉  
用途: 処分の理由を明示する。  
例: The player was defaulted for refusing to continue the match.  
訳: その選手は試合の続行を拒否したため、失格にされた。  

【語法・注意】defaulted はここでは他動詞の過去分詞で、処分を受ける選手が受動文の主語になる。He defaulted.「本人が棄権した」（語義10）と He was defaulted.「失格にされた」を区別する。処分権者、違反の程度、ほかの種目や賞金への影響は競技規則によるため、この動詞だけで決まらない。a defaulted player は処分済みの選手を指す分詞的な修飾である。テニスでは referee と chair umpire は異なる役職なので、referee を一律に「主審」と訳さない。  

【類義語】

・disqualify  
定義: 規則・資格上の理由で競技者を失格にする。  
頻度: 〈6/10〉  
違い: 広い競技で使い、出場資格の欠如による排除も含む。  
例: The officials disqualified the runner for leaving the marked course.  
訳: 審判団は、指定されたコースを外れた走者を失格にした。  

・exclude  
定義: 参加させない・対象から除く。  
頻度: 〈7/10〉  
違い: 失格処分という競技上の効果を単独では指定しない、広い語。  
例: The organizers excluded the team from the competition.  
訳: 主催者は、そのチームを競技会から除外した。  

13. 【動詞・他動詞】債務・支払いを履行しない

【日本語訳・定義】支払うべき借入金や債務などを直接目的語に取り、その返済・履行を行わない。意味は語義5に近いが、on を伴わない他動詞構文である。  

【頻度】〈3/10〉  

【レジスター/領域】金融・契約のかたい用法。一般には default on a loan/debt がよりよく使われる。  

【文法パターン】default a loan＝借入金の返済を履行しない／default a debt＝債務を履行しない。直接目的語は支払義務の対象で、通常の学習・作文では自動詞＋on の形を優先する。  

【コロケーション・構文例】

・default a debt  
用途: 債務を目的語にして不履行を述べる。  
例: The borrower defaulted the debt when it fell due.  
訳: 借り手は、満期を迎えたその債務を履行しなかった。  

・default a loan  
用途: 借入金を直接目的語にする限定的な用法。  
例: The company defaulted a loan after losing its main customer.  
訳: その会社は、主要な顧客を失った後、借入金の返済を履行しなかった。  

【語法・注意】default a loan は辞書に認められるが、default on a loan と比べて使用域が限られる。The loan was defaulted on. は前置詞 on を残した受動、a defaulted loan は分詞を名詞の前に置く形であり、同じ表面形として混同しない。defaulted は「既定の」という形容詞 default（語義2）の代わりにはならない。この語だけでは担保・債権の消滅や譲渡は意味しない。  

【類義語】

・dishonor  
定義: 支払うべき手形などの支払いを拒む・履行しない。  
頻度: 〈4/10〉  
違い: 特に手形・小切手などの不渡りに使う金融用語で、融資一般の default より対象が限定される。英綴りは dishonour。  
例: The bank dishonored the check because the account lacked sufficient funds.  
訳: 口座の残高が不足していたため、銀行はその小切手の支払いに応じなかった。  

14. 【動詞・他動詞】当事者を訴訟上の懈怠として扱う

【日本語訳・定義】裁判所などが、必要な答弁・防御を行わない当事者について、default の状態にあるとする。処分・認定を受ける当事者を直接目的語に取る。  

【頻度】〈2/10〉  

【レジスター/領域】法律・民事訴訟。限定的な用法で、実務では enter a default against someone などの表現も使う。  

【文法パターン】default a defendant＝被告を訴訟上の懈怠として扱う／a defendant is defaulted＝被告が懈怠扱いにされる。主語が裁判所等の能動文と、当事者が主語の受動文がある。  

【コロケーション・構文例】

・default a defendant  
用途: 裁判所側の判断を他動詞で述べる。  
例: The court defaulted the defendant for failing to respond to the complaint.  
訳: 裁判所は、訴状に応答しなかった被告を懈怠として扱った。  

・be defaulted  
用途: 当事者側から受動で述べる。  
例: The defendant had been defaulted, but no default judgment had yet been entered.  
訳: 被告は懈怠扱いとされていたが、欠席判決はまだ出されていなかった。  

【語法・注意】The defendant defaulted. という自動詞（語義9）と、The court defaulted the defendant. という他動詞では、主語の役割が逆になる。defaulted を見ただけで判決の確定まで読み込まない。entry of default と default judgment の区別は語義6を参照する。  

【類義語】

・enter a default  
定義: 訴訟上の懈怠を記録する。  
頻度: 〈3/10〉  
違い: 記録する手続きに焦点がある定着表現。相手方は against someone で示す。  
例: The clerk entered a default after reviewing the plaintiff’s affidavit.  
訳: 書記官は、原告の宣誓供述書を確認した後、懈怠を記録した。  

15. 【動詞・他動詞】口座・債務を不履行として扱う

【日本語訳・定義】貸し手などが、口座や債務を不履行の状態として扱い、記録する。借り手が返済をしないという語義13とは異なり、扱いを決める貸し手側が主語になる。  

【頻度】〈2/10〉  

【レジスター/領域】英国の信用情報・債権管理実務。限定的な用法。  

【文法パターン】a lender defaults an account＝貸し手が口座を不履行として扱う／an account is defaulted＝口座が不履行として扱われる。目的語や受動文の主語には、口座・債務などを置く。  

【コロケーション・構文例】

・default an account  
用途: 貸し手側が口座を不履行として扱うことを述べる。  
例: The lender defaulted the account after several missed payments.  
訳: 貸し手は、支払いが数回行われなかった後、その口座を不履行として扱った。  

・an account is defaulted  
用途: 不履行として扱われた口座を受動文で示す。  
例: She disputed the date on which her account had been defaulted.  
訳: 彼女は、自分の口座が不履行扱いとされた日付に異議を唱えた。  

【語法・注意】英国の金融実務に見られる用法であり、すべての国・制度で同じ手続きや日数を表すわけではない。The borrower defaulted on the account. は借り手の不履行を述べるのに対し、The lender defaulted the account. は貸し手側の扱いを述べる。通知を送ること、信用情報に登録すること、債権を譲渡することはそれぞれ別の行為なので、この動詞だけで全部が行われたとは判断しない。
