＃発音記号

米: /ˌdɑːkjumenˈteɪʃn/｜英: /ˌdɒkjumenˈteɪʃn/。5音節で、第4音節 /teɪ/ に主強勢、第1音節に第二強勢がある。示した米英差は第1音節の母音 /ɑː/ と /ɒ/。第5音節 /ʃn/ は弱く、強い「ション」にしない。  

document の主強勢は第1音節だが、documentation では -ation の /eɪ/ を含む第4音節が中心になる。-ment の部分へ主強勢を置かない。  

＃語源

英語の document に名詞を作る -ation が付いた語。document は、古フランス語を経てラテン語 documentum「教訓・証拠」、さらに docere「教える」にさかのぼる。documentation 自体の形成と、この語族の古い語源を分けて捉える。doctor「医師・博士」、doctrine「教義」も docere を共有する同根語。  

＃語形成

・document：名詞では個別の文書、動詞では記録する・資料で裏付ける。documentation はこの語からの派生語であり、documentations を通常の「書類の複数形」として使わない。  

・user documentation：製品の利用者向け説明資料。user は資料を使う対象を示す。  

・supporting documentation：申請や主張を裏付ける資料。supporting は「支援的な性格」ではなく根拠を補う働きを示す。  

＃コアイメージ

「参照・確認のために記録を整えること、または整えられた資料」が共通核。提出するものか、読む説明資料か、記録を残す作業かで訳を選ぶ。  

・参照・確認のための証拠資料 → 「必要書類・裏付け資料」（語義1）  

・参照・確認のための説明資料 → 「説明資料・技術文書」（語義2）  

・参照・確認できる記録を整える行為 → 「記録化・文書化」（語義3）  

＃意味・用法・関連表現

1. 【名詞・不可算】必要書類・裏付け資料

【日本語訳・定義】手続きに必要な書類や、事実・資格・主張などを裏付ける資料をまとめて指す。書類の集合として捉え、個別の文書の枚数や点数を数える語ではない。  

【頻度】〈8/10〉  

【レジスター/領域】業務・申請・取引・研究。  

【文法パターン】documentation for 〈申請・手続き〉＝申請・手続きに使う書類／supporting documentation＝裏付け資料／provide documentation＝書類や資料を提出・提示する／documentation of 〈事実〉＝事実を証明する資料／without documentation＝裏付け書類なしで  

【コロケーション・構文例】

・documentation for an application  
用途: 書類を使う目的を示す。  
例: We have collected the documentation for the application.  
訳: 私たちはその申請に使う書類をそろえた。  

・supporting documentation  
用途: 説明や請求を支える書類群を示す。  
例: Please send the supporting documentation with your request.  
訳: 依頼に裏付け資料を添えて送ってください。  

・provide documentation of 〈事実〉  
用途: 何を証明する資料かを述べる。  
例: The seller provided documentation of ownership.  
訳: 売主は所有権を示す書類を提示した。  

・without the required documentation  
用途: 必要書類がないことを表す。  
例: We cannot process the application without the required documentation.  
訳: 必要書類がなければ、その申請を処理できません。  

【語法・注意】通常は a documentation・three documentations としない。個別に数えるなら a document・three documents。The documentation is complete. のように単数扱いする。some documentation・all the necessary documentation が自然。documentation of ownership は所有権の証拠資料、documentation for an application は申請という用途を示す。of が常に作業を示すわけではなく、語義3との区別は文脈による。  

【類義語】

・paperwork  
定義: 事務手続きに必要な書類、またはその処理。  
頻度: 〈8/10〉  
違い: 書類仕事という実務面を強調する。documentation は手続きだけでなく研究上の根拠資料も指す。  
例: Please return the paperwork to the office.  
訳: その書類を事務所へ返してください。  

・evidence  
定義: 事実や主張を支える証拠。  
頻度: 〈9/10〉  
違い: 文書に限らず物・証言・観察結果なども含む不可算名詞。documentation は記録・書類としての資料を指す。  
例: There is little evidence to support the claim.  
訳: その主張を裏付ける証拠はほとんどない。  

・records  
定義: 事実や活動を保存した記録類。  
頻度: 〈9/10〉  
違い: 何が起きたかの保存が中心。documentation は申請に必要な書類など、その用途や裏付けの働きに焦点を置きやすい。  
例: The records include copies of the receipts.  
訳: その記録類には領収書の写しが含まれている。  

2. 【名詞・不可算】説明資料・技術文書

【日本語訳・定義】製品・機器・ソフトウェアなどの使い方や仕様、構造、保守方法を説明する資料。紙の説明書だけでなく、オンラインの手引きや参照資料も含む。  

【頻度】〈7/10〉  

【レジスター/領域】製品案内・技術・ソフトウェア。  

【文法パターン】documentation for 〈製品・ソフトウェア〉＝製品・ソフトウェアの説明資料／user documentation＝利用者向け説明資料／technical documentation＝技術資料／consult the documentation＝説明資料を参照する／update the documentation＝説明資料を更新する  

【コロケーション・構文例】

・documentation for 〈ソフトウェア〉  
用途: 何の使い方を説明する資料かを示す。  
例: The documentation for this software includes working examples.  
訳: このソフトウェアの説明資料には、実際に動く例が含まれている。  

・user documentation  
用途: 利用者向けの説明資料を指す。  
例: The user documentation explains how to reset the device.  
訳: 利用者向けの説明資料には、機器をリセットする方法が書かれている。  

・consult the technical documentation  
用途: 技術的な情報を調べる。  
例: Consult the technical documentation before changing the settings.  
訳: 設定を変更する前に技術資料を参照してください。  

・update the documentation  
用途: 製品などの変更に合わせて資料を改訂する。  
例: We updated the documentation after adding the new feature.  
訳: 私たちは新機能を追加した後、説明資料を更新した。  

【語法・注意】この語義でも不可算で、The documentation is available online. とする。a manual は1冊・1つのマニュアルを数えられるが、documentation は複数の手引きや参照ページを含む総体になり得る。for は資料の対象、on は扱う話題を示すことがある。docs は技術分野のくだけた略称で、正式な文章では documentation が使える。  

【類義語】

・manual  
定義: 機器や作業の扱い方を詳しく説明した手引き。  
頻度: 〈8/10〉  
違い: 通常は可算で、一つの手引きとしてまとまったものを指す。documentation は手引き以外の参照資料も含む。  
例: The manual includes a troubleshooting section.  
訳: そのマニュアルにはトラブル対処の章がある。  

・instructions  
定義: 操作や作業の具体的なやり方を示す指示。  
頻度: 〈9/10〉  
違い: 何をどう行うかという手順に焦点がある。documentation は背景・仕様・設計なども説明する。  
例: Follow the installation instructions carefully.  
訳: インストールの手順に注意して従ってください。  

・guide  
定義: ある作業や分野を理解するための案内・手引き。  
頻度: 〈8/10〉  
違い: 読者を導く構成を意識する語。documentation は技術仕様のような参照用情報も含む。  
例: The guide covers the basic editing tools.  
訳: そのガイドは基本的な編集ツールを扱っている。  

3. 【名詞・不可算】記録化・文書化

【日本語訳・定義】出来事・手順・合意などを参照できる形に記録すること、または根拠資料をそろえて内容を裏付けること。完成した書類そのものを指す語義1・2と、作業や過程としての捉え方を区別する。  

【頻度】〈6/10〉  

【レジスター/領域】業務・研究・記録管理。  

【文法パターン】documentation of 〈出来事・手順〉＝出来事・手順の記録化／documentation of 〈主張〉＝主張の資料による裏付け／careful documentation＝丁寧な記録化／the documentation process＝記録を整える過程  

【コロケーション・構文例】

・documentation of 〈手順〉  
用途: 手順を記録に残す作業を指す。  
例: Documentation of the testing process took several days.  
訳: 試験過程の文書化には数日かかった。  

・careful documentation of 〈出来事〉  
用途: 記録する行為の丁寧さを評価する。  
例: Careful documentation of the excavation helped preserve the context of each find.  
訳: 発掘作業を丁寧に記録したことが、各出土品が見つかった状況を残すのに役立った。  

・documentation of 〈主張〉  
用途: 根拠資料をそろえる作業を述べる。  
例: The editor requested better documentation of the claims.  
訳: 編集者は、それらの主張をもっと十分な資料で裏付けるよう求めた。  

【語法・注意】of の後は記録・裏付けの対象で、作業者は documentation by the research team のように by で示せる。documentation of the agreement は「合意を文書化すること」と「合意を示す資料」の両方になり得る。took several days のような述語なら作業の読みが明確になる。記録する媒体は文章だけとは限らず、写真や図を組み込む場合もある。単語そのものは承認・契約成立・公表を意味しない。  

【類義語】

・recording  
定義: 情報や出来事を記録として残すこと。  
頻度: 〈7/10〉  
違い: この行為義では不可算。音声・映像の収録も含む広い語で、documentation は参照・裏付けのために記録を整える面を強調する。  
例: Accurate recording of the results is essential.  
訳: 結果を正確に記録することが不可欠だ。  

・record-keeping  
定義: 活動や取引などの記録を継続して作成・管理すること。  
頻度: 〈6/10〉  
違い: 単発の記録化より、日常的な保存・管理の仕組みに焦点がある。  
例: Good record-keeping makes reviews easier.  
訳: 記録をきちんと管理しておくと、見直しがしやすくなる。  

・substantiation  
定義: 証拠を示して主張を裏付けること。  
頻度: 〈4/10〉  
違い: 真実性や根拠の補強に焦点があり、手順を説明資料にする意味には使わない。  
例: The allegation requires substantiation.  
訳: その申し立てには裏付けが必要だ。
