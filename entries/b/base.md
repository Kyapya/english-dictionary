＃発音記号

米・英: /beɪs/。1音節で、母音は二重母音 /eɪ/。名詞・動詞・形容詞で発音を変えない。複数形・三人称単数形 bases は /ˈbeɪsɪz/、動詞の過去形・過去分詞 based は /beɪst/、basing は /ˈbeɪsɪŋ/。based の語尾に母音を加えて2音節にしない。音楽の低音を表す bass とは同音だが、魚を表す bass は別の発音なので一律に同音と覚えない。  

＃語源

名詞の基本的な系列は、フランス語を経由し、ラテン語 basis を通じて、ギリシャ語の基盤・足場を表す語にさかのぼる。動詞 base は名詞に由来する。一方、卑しい・品位の低いという形容詞は、フランス語 bas、ラテン語 bassus「低い」の系列で、名詞と同じ語源から全てを説明しない。basis と base は関連していても、現代の語形・使い方は別である。  

＃語形成

・based：動詞の過去形・過去分詞。based on は根拠、based in は拠点を示すことが多い。名詞の前では evidence-based、Tokyo-based などの複合修飾も作る。  

・baseless：主張などに根拠がないことを表す形容詞。卑しいという base に単純に否定を加えた意味ではない。  

・baseness：道徳的な卑しさを表す名詞。名詞 base の拠点や土台を数える複数形ではない。  

・basely：卑劣にという副詞。基本的にという basically と取り違えない。  

＃コアイメージ

物・活動・判断がよりどころとする土台や足場・基準点。野球の足場から生まれた語義13〜17も、戻って確かめる接点、押さえるべき要点、正しい足場からの逸脱、最初の足場への到達としてつなげて覚えられるが、句全体の定着した意味は各項で学ぶ。語義11・25は「低い」という別系統の形容詞で、この核を共有しない同綴異義。語義22・23・26は制度的専門義で、酸塩基反応の性質・核酸の特定成分・トランジスタの特定部分という語彙的な定義自体を、この土台の核から予測できないため個別に覚える。語義27・28の俗語 based も、通常の分詞とは意味系統を分ける同綴異義として扱い、土台から好意的評価を直接導かない。  

・物を支える土台となる部分 → 「底部、付け根、支えとなる部分」（語義1）  

・活動を支える土台となる場所 → 「活動拠点、生活や事業の拠点」（語義2）

・計画を支える土台となる考え → 「考え・計画の基礎、出発点」（語義5）

・図形の高さの土台となる辺や面 → 「図形の底辺、底面」（語義18）

・語形成の土台となる形 → 「語形成の基体」（語義24）  

・恋愛的な進展の最初の足場 → 「キスに至る段階：first base」（語義29）  

＃意味・用法・関連表現

1. 【名詞：可算・通常単数】底部、付け根、支えとなる部分

【日本語訳・定義】物の下側にある部分や、それを支える底・台。また、体の部位や物が他の部分とつながる付け根を指す。どの物の base かによって、底面・ふもと・基部などと訳し分ける。  

【頻度】〈9/10〉  

【レジスター/領域】日常・物の説明・身体・建築。  

【文法パターン】the base of something／at the base of something／a broad base／a metal base／the base of the thumb。  

【コロケーション・構文例】

・the base of something  
用途: 物の最下部や支える部分を述べる。  
例: Water had collected around the base of the wall.  
訳: 壁の下の部分の周囲に、水がたまっていた。  

・at the base of something  
用途: 山などの下側の位置を示す。  
例: The village lies at the base of the mountain.  
訳: 村は、その山のふもとにある。  

・a broad base  
用途: 下部の幅が広く、安定している形を述べる。  
例: The vase has a broad base that keeps it from tipping easily.  
訳: その花瓶は底が広く、簡単には倒れない。  

・a metal base  
用途: 支台の材料を述べる。  
例: The lamp is fixed to a heavy metal base.  
訳: ランプは、重い金属製の台座に固定されている。  

・the base of the thumb  
用途: 指の付け根の位置を述べる。  
例: The glove was worn through at the base of the thumb.  
訳: 手袋は、親指の付け根のところが擦り切れていた。  

【語法・注意】base は物との位置関係で意味が決まる。山ならふもと、ランプなら台座、親指なら付け根と、日本語の一語に固定しない。at the base は位置、the base of the object は対象との関係を示す。建物の地盤とつながる基礎構造を特に述べる foundation より、base は台や底面を広く指せる。  

【類義語】

・bottom  
定義: 物や場所の一番下の部分。  
頻度: 〈10/10〉  
違い: 上下関係の最下部を広く指す。base はそこが物を支える部分・付着部であるという面にも注目する。  
例: There was some sand at the bottom of the bag.  
訳: かばんの底には、少し砂があった。  

・foundation  
定義: 建物などを安定して支える基礎。  
頻度: 〈8/10〉  
違い: 全体を構造的に支える基礎に重点がある。base は小さな物の台座や、身体の付け根にも使う。  
例: The engineers checked the building's foundations.  
訳: 技術者たちは、建物の基礎を確認した。  

2. 【名詞：可算】活動拠点、生活や事業の拠点

【日本語訳・定義】人や組織が滞在し、そこを中心として活動する場所。恒久的な本拠地にも、旅行や調査の一時的な拠点にも使う。  

【頻度】〈8/10〉  

【レジスター/領域】一般・旅行・業務・調査。  

【文法パターン】a base for doing something／use somewhere as a base／an operational base／a home base／return to base。  

【コロケーション・構文例】

・a base for doing something  
用途: 何をする拠点なのかを示す。  
例: The town is a convenient base for exploring the surrounding hills.  
訳: その町は、周囲の丘陵を巡るのに便利な拠点だ。  

・use somewhere as a base  
用途: 一定の場所を拠点として使う。  
例: The researchers used the village as a base during the survey.  
訳: 研究者たちは、調査中、その村を拠点として使った。  

・an operational base  
用途: 実務的な活動を行う拠点を述べる。  
例: The rescue team established an operational base near the affected area.  
訳: 救援隊は、被災地域の近くに活動拠点を設けた。  

・a home base  
用途: 戻ってくる中心的な拠点を指す。  
例: She travels frequently but keeps a home base in Tokyo.  
訳: 彼女は頻繁に旅をするが、東京に生活の拠点を置いている。  

・return to base  
用途: 作業や活動の拠点へ戻る。  
例: The survey team returned to base before dark.  
訳: 調査隊は、暗くなる前に拠点へ戻った。  

【語法・注意】a base for exploring の for の後ろには動名詞を置ける。a base in Tokyo なら所在地であり、for と役割が違う。拠点に戻るなどの慣用的な使い方では return to base と無冠詞になることがあるが、全ての文で冠詞を省くわけではない。a base は必ずしも会社の登記上の本社や、個人の正式な住所ではない。  

【類義語】

・headquarters  
定義: 組織を指揮・管理する本部。  
頻度: 〈8/10〉  
違い: 管理・指揮の中心という役割がある。base は調査隊の一時的な滞在先など、必ずしも本部でない活動拠点にも使う。  
例: The company moved its headquarters to a larger building.  
訳: 会社は、本社をより大きな建物に移した。  

3. 【名詞：可算・慣用的に無冠詞も】軍事基地

【日本語訳・定義】軍が人員・装備を配置し、訓練・補給・作戦などを行う拠点。一般的な活動拠点より、軍事施設という対象が明確な用法。  

【頻度】〈7/10〉  

【レジスター/領域】軍事・報道・歴史。  

【文法パターン】a military base／an air base／a naval base／be stationed at a base／return to base。  

【コロケーション・構文例】

・a military base  
用途: 軍の施設としての基地を指す。  
例: The road passes a military base outside the city.  
訳: その道路は、市外にある軍事基地のそばを通っている。  

・an air base  
用途: 軍用機などの活動拠点を述べる。  
例: The aircraft returned to the air base after the exercise.  
訳: 航空機は、演習後に航空基地へ戻った。  

・a naval base  
用途: 海軍の拠点を述べる。  
例: The port developed around a naval base.  
訳: その港は、海軍基地を中心に発展した。  

・be stationed at a base  
用途: 人員が基地に配置されていることを述べる。  
例: He was stationed at a base near the coast.  
訳: 彼は、海岸近くの基地に配属されていた。  

・return to base  
用途: 軍事任務から所属基地に帰還する。  
例: The patrol was ordered to return to base.  
訳: 哨戒隊は、基地へ戻るよう命じられた。  

【語法・注意】base を全て一般旅客用の空港と訳さない。an air base は軍事的な航空拠点を指す。at a base は所在地、to base は帰還先など、前置詞の働きを区別する。この単語だけでは、特定の基地の所有権・管轄・運用条件は分からない。  

4. 【名詞：可算・通常単数】支持基盤、顧客基盤、経済的な基盤

【日本語訳・定義】人や組織を継続的に支える支持者・顧客・収入源などのまとまり。物理的な場所ではなく、活動を成り立たせる人的・経済的な支えを表す。  

【頻度】〈8/10〉  

【レジスター/領域】ビジネス・政治・経済・報道。  

【文法パターン】a customer base／a fan base／a support base／an economic base／broaden one's base。  

【コロケーション・構文例】

・a customer base  
用途: 継続的に商品やサービスを利用する顧客の層を述べる。  
例: The business built a loyal customer base over many years.  
訳: その事業は、長年かけて忠実な顧客層を築いた。  

・a fan base  
用途: 人や作品を支えるファンの集まりを述べる。  
例: The band has a small but enthusiastic fan base.  
訳: そのバンドには、少人数ながら熱心なファンがついている。  

・a support base  
用途: 政治家や運動を支える人々の層を述べる。  
例: The candidate's support base extends beyond the capital.  
訳: その候補者の支持層は、首都の外にも広がっている。  

・an economic base  
用途: 地域などの経済を支える産業・活動を述べる。  
例: Tourism has become an important part of the island's economic base.  
訳: 観光は、その島の経済基盤の重要な部分になった。  

・broaden one's base  
用途: 支持者や顧客などの範囲を広げる。  
例: The organization hopes to broaden its base by reaching younger members.  
訳: その組織は、若い会員を取り込んで基盤を広げたいと考えている。  

【語法・注意】customer base は顧客が集まる建物ではなく、顧客層を指す。fan base のように前の名詞で何の基盤かを示せる。広い顧客層があることと、一人ひとりが高額の売上を生むことは別であり、base だけでは人数や収益性は決まらない。tax base も経済の文章で見るが、具体的な課税対象や計算範囲は税制度ごとに確認する。  

5. 【名詞：可算】考え・計画の基礎、出発点

【日本語訳・定義】判断・計画・発展などの出発点として使う知識・考え・情報など。人的な支持層ではなく、何かを組み立てるための内容的な土台を指す。  

【頻度】〈7/10〉  

【レジスター/領域】一般・教育・業務・議論。  

【文法パターン】a sound base for something／a knowledge base／build on an existing base／provide a base for something。  

【コロケーション・構文例】

・a sound base for something  
用途: 活動の確かな土台を述べる。  
例: The initial survey provides a sound base for further research.  
訳: 初期調査は、追加研究の確かな土台を提供している。  

・a knowledge base  
用途: 活動を支える蓄積した知識を述べる。  
例: The training helped the team develop a broader knowledge base.  
訳: 研修は、チームがより幅広い知識の基盤を築く助けになった。  

・build on an existing base  
用途: 既存の基礎を生かしてさらに発展させる。  
例: The course builds on the existing base of skills that students bring with them.  
訳: その授業は、学生が既に持っている技能の基盤を生かして進められる。  

・provide a base for something  
用途: 今後の活動に必要な足場を提供する。  
例: The agreement provides a base for future cooperation.  
訳: その合意は、今後の協力の基礎となる。  

【語法・注意】base は抽象的な基盤にも使えるので、物理的な底にしか使えないとは覚えない。ただし basis と常に交換できるわけではなく、on a daily basis のような定着した表現を on a daily base に変えない。knowledge base は一般的な知識の蓄積のほか、情報技術の文脈では整理された知識の集合を指す場合がある。  

【類義語】

・basis  
定義: 判断や活動が依拠する理由・土台。  
頻度: 〈8/10〉  
違い: 判断根拠や方式を述べる表現に広く使う。base は発展の出発点や蓄積した資源としての基盤を述べることもあり、定着した構文ごとに選ぶ。  
例: The decision was made on the basis of the available evidence.  
訳: その決定は、利用できる証拠に基づいて行われた。  

6. 【動詞：他動詞】根拠・基礎を置く、基づかせる

【日本語訳・定義】判断・作品・計画などを、情報・原則・経験などから成り立つものにする。base A on B では、A が基づくもの、B がその根拠や素材となる。  

【頻度】〈9/10〉  

【レジスター/領域】日常・業務・学術・報道。  

【文法パターン】base something on something／base something upon something／be based on evidence／be based on a true story／base a decision on the assumption that …。  

【コロケーション・構文例】

・base something on something  
用途: 何を何に基づかせるかを能動態で示す。  
例: We based the estimate on last year's sales figures.  
訳: 私たちは、昨年の売上高に基づいて見積もりを出した。  

・base something upon something  
用途: upon を用いて根拠を改まって述べる。  
例: The author bases her argument upon a detailed study of the records.  
訳: 著者は、記録の詳細な調査を議論の根拠にしている。  

・be based on evidence  
用途: 受動態で、証拠に基づくことを述べる。  
例: The recommendation is based on evidence from several trials.  
訳: その勧告は、複数の試験の証拠に基づいている。  

・be based on a true story  
用途: 作品の素材となる実際の出来事を述べる。  
例: The film is loosely based on a true story.  
訳: その映画は、実話を緩やかに下敷きにしている。  

・base a decision on the assumption that …  
用途: 判断を支える想定の内容を示す。  
例: They based the decision on the assumption that demand would continue to rise.  
訳: 彼らは、需要が上がり続けるという想定に基づいて決定した。  

【語法・注意】We base our plans on evidence. の目的語は our plans で、根拠 evidence は on の後ろに置く。Our plans are based on evidence. では plans が主語になる。「計画は証拠に基づく」の意味で Our plans base on evidence. と他動詞の目的語や受動の be を落とさない。based on は根拠・素材、based in は活動場所を示すことが多い。また、根拠が assumption なら、based on だけで内容が証明済みとは言えない。  

【類義語】

・ground  
定義: 判断や考えを根拠・現実に結びつける。  
頻度: 〈6/10〉  
違い: ground something in evidence のように、実際の事実・経験との結びつきを強調する。base A on B の on を、全ての近義語へ機械的に移さない。  
例: Her analysis is grounded in practical experience.  
訳: 彼女の分析は、実務経験に根ざしている。  

7. 【動詞：他動詞・受動態が多い】拠点を置く、配置する

【日本語訳・定義】人・組織・活動を、一定の場所を中心として動くように置く。どの根拠で判断したかではなく、どこで活動するかを述べる。  

【頻度】〈8/10〉  

【レジスター/領域】一般・業務・活動場所の説明。  

【文法パターン】be based in 〈都市・地域〉／be based at 〈施設〉／base operations in 〈都市・地域〉／base oneself in 〈都市・地域〉。  

【コロケーション・構文例】

・be based in 〈都市・地域〉  
用途: 人や組織が活動の中心とする都市・地域を述べる。  
例: The designer is based in Osaka but works with clients worldwide.  
訳: そのデザイナーは大阪を拠点としながら、世界各地の顧客と仕事をしている。  

・be based at 〈施設〉  
用途: 特定の施設などを拠点として述べる。  
例: The research team is based at the university's coastal laboratory.  
訳: 研究チームは、大学の沿岸研究所を拠点としている。  

・base operations in 〈都市・地域〉  
用途: 活動の拠点を能動態で設定する。  
例: The company decided to base its regional operations in Singapore.  
訳: 会社は、地域事業の拠点をシンガポールに置くことにした。  

・base oneself in 〈都市・地域〉  
用途: 自分の活動拠点を置く。  
例: She based herself in the capital while researching the book.  
訳: 彼女は、本の調査をしている間、首都を拠点にした。  

【語法・注意】be based in Tokyo は東京が拠点であるという意味で、常にその瞬間東京にいるとは限らない。名詞や代名詞を置く場合は base the team in Tokyo／base it in Tokyo とする。base oneself の再帰代名詞は主語に合わせる。所在地の in と、建物・施設を指す at は具体的な場所の捉え方で選ぶ。根拠を示す based on data と混同しない。  

8. 【複合修飾 -based：名詞の前】～に基づく、～を拠点とする

【日本語訳・定義】前に置いた情報・素材・場所などを、基盤・主な構成・活動拠点として持つことを表す複合修飾。前半の語の種類によって関係が変わる。  

【頻度】〈8/10〉  

【レジスター/領域】一般・業務・製品・学術。

【コロケーション・構文例】

・an evidence-based approach

例: The team adopted an evidence-based approach to evaluating the programme.  
訳: チームは、事業を評価するために証拠に基づく方法を採用した。  

・a Tokyo-based company  
用途: 所在地を前から一まとまりで修飾する。  
例: A Tokyo-based company developed the software.  
訳: 東京を拠点とする会社が、そのソフトウェアを開発した。  

・a plant-based product  
用途: 植物由来の材料を基盤とする製品を述べる。  
例: The shop introduced a new plant-based product.  
訳: 店は、植物由来の新しい製品を導入した。  

・a web-based service

9. 【名詞：可算・通常単数】主成分、基礎材料、下に重ねる層

【日本語訳・定義】混合物や製品の主な材料、また上に別のものを加えるための土台となる材料や層。出来上がった物の底の形だけでなく、素材としての役割に注目する。

・an oil base

【語法・注意】a base for the sauce の for は、この材料から何を作るかを示す。a tomato base は主な材料の種類を述べ、必ずトマトしか入っていないとは限らない。化粧品の base は基礎となる役割を広く指し、具体的な製品が primer か foundation かは商品説明や使い方で確認する。英語と日本語の商品分類を単語だけで同一視しない。  

10. 【名詞の限定用法・形容詞的用法】基本の、追加分を含まない

【日本語訳・定義】賃金・価格・機種などについて、追加手当や追加装備を含める前の基本となる額・仕様を表す。道徳的に卑しいという形容詞の意味とは別である。

・base salary

例: The job offers a base salary plus a performance bonus.  
訳: その仕事では、基本給に加えて業績賞与が支給される。  

・base pay  
用途: 通常の支給額の土台を述べる。  
例: Overtime payments are separate from base pay.  
訳: 時間外手当は、基本給とは別に支払われる。  

・the base price  
用途: オプションなどを加える前の価格を述べる。  
例: The base price does not include delivery or installation.  
訳: 基本価格には、配達費と設置費は含まれていない。

訳: 基本モデルでも、後方カメラが付いている。  

【語法・注意】base salary／basic salary のように、地域や慣用によって選ばれる形がある。base が付けば全ての契約で同じ手当を除外するというわけではなく、含まれる範囲は条件を読む。ここでの base は主に名詞の前に置き、The salary is base. とすると卑しいという別の形容詞の読みを誘うため、基本給という意味には使わない。  

11. 【形容詞】卑しい、卑劣な

【日本語訳・定義】動機・行為・欲望などが、道徳的に低劣であると強く非難する。所得や身分が低いという意味を現代の人に機械的に当てはめる語ではない。  

【頻度】〈4/10〉  

【レジスター/領域】硬い表現・文学的な非難。  

【文法パターン】base motives／base instincts／a base betrayal／be base／baser instincts。  

【コロケーション・構文例】

・base motives  
用途: 行為の動機を道徳的に非難する。  
例: He accused his rival of acting from base motives.  
訳: 彼は、ライバルが卑劣な動機から行動していると非難した。  

・base instincts  
用途: 人の低劣な衝動に訴えることを述べる。  
例: The speech appealed to the crowd's base instincts.  
訳: その演説は、群衆の卑しい本能に訴えかけた。  

・a base betrayal  
用途: 裏切りを強く非難する。  
例: She regarded the sale of their secrets as a base betrayal.  
訳: 彼女は、自分たちの秘密を売り渡すことを卑劣な裏切りと見なした。  

・be base  
用途: 行為の性質を述語で評価する。  
例: His conduct was base, whatever excuse he offered.  
訳: どんな言い訳をしたにせよ、彼の振る舞いは卑劣だった。  

【語法・注意】限定用法と叙述用法がある。比較は baser、最上級は basest。基礎的なという意味の basic と交換できない。basely は卑劣に、baseness は卑劣さという派生形で、この評価の系列に属する。  

【類義語】

・vile  
定義: 道徳的に極めて不快で、嫌悪すべき。  
頻度: 〈5/10〉  
違い: base が品位・動機の低劣さを強調するのに対し、vile は嫌悪感をより前面に出す。  
例: It was a vile attempt to intimidate a witness.  
訳: それは、証人を脅そうとする実に卑劣な試みだった。  

・dishonorable  
定義: 名誉や倫理に反する。  
頻度: 〈4/10〉  
違い: base と重なるが、dishonorable は守るべき名誉や行動規範への違反を中心にする。  
例: The committee condemned his dishonorable conduct.  
訳: 委員会は、彼の不名誉な振る舞いを非難した。  

【反意語】

・noble  
定義: 動機や行為が道徳的に立派な。  
頻度: 〈6/10〉  
違い: 動機・行為の道徳的な高さという評価軸で base と対立する。身分上の貴族という意味とは区別する。  
例: Her decision was guided by noble motives.  
訳: 彼女の決断は、気高い動機に導かれていた。  

12. 【形容詞】根拠のない：baseless

【日本語訳・定義】主張・疑い・告発などに、それを支える事実や理由がない。単にまだ最終的に証明されていないという弱い意味よりも、根拠を欠くと判断する表現である。  

【頻度】〈6/10〉  

【レジスター/領域】報道・議論・やや硬い表現。  

【文法パターン】baseless allegations／a baseless accusation／baseless rumors／be baseless。  

【コロケーション・構文例】

・baseless allegations  
用途: 申し立てに根拠がないと述べる。  
例: The company rejected the allegations as baseless.  
訳: 会社は、その申し立てには根拠がないとして退けた。  

・a baseless accusation  
用途: 非難の根拠の欠如を指摘する。  
例: A baseless accusation can still damage a person's reputation.  
訳: 根拠のない非難でも、人の評判を傷つけることがある。  

・baseless rumors

・be baseless

【語法・注意】発音は /ˈbeɪsləs/。base の土台・根拠の系列に -less が付いた形で、卑しくないという意味ではない。限定・叙述とも可能。baseless と false は同義ではなく、根拠があるかと内容が真実かは別の判断である。

訳: 彼女の不安は、取り越し苦労だったと分かった。  

・unsubstantiated  
定義: 証拠による裏付けが示されていない。  
頻度: 〈5/10〉  
違い: baseless よりも、証拠がまだ提示・確認されていないという状態に焦点を置ける。  
例: The article repeated several unsubstantiated claims.  
訳: その記事は、裏付けが示されていない主張をいくつも繰り返した。

19. 【名詞：可算】記数法の基数

【日本語訳・定義】位取り記数法で、隣り合う位の重みの関係を決める数。十進法は base ten、二進法は base two と表す。  

【頻度】〈4/10〉  

【レジスター/領域】数学・情報処理。  

【文法パターン】in base ten／in base two／a base-ten number system／convert from base two to base ten。  

【コロケーション・構文例】

・in base ten  
用途: 十進表記であることを示す。  
例: The answer is written in base ten.  
訳: 答えは十進法で書かれている。  

・in base two  
用途: 二進表記を指定する。  
例: Five is written as 101 in base two.  
訳: 5は、二進法では101と書く。  

・a base-ten number system  
用途: 名詞を修飾して記数法を説明する。  
例: We normally use a base-ten number system for everyday calculations.  
訳: 日常の計算には、通常十進の記数法を使う。  

【語法・注意】base ten のような名称は無冠詞。名詞の前に置く複合修飾では base-ten のようにハイフンを使う。二進法の base が2であることと、個々の計算式の累乗の底が2であることは別の話である。  

20. 【名詞：可算】累乗・対数の底

【日本語訳・定義】累乗で何乗するかの対象になる数。また、対数で基準とする数。どちらも数学的な関係の中で base と呼ばれ、記数法の基数とは用途を区別する。  

【頻度】〈4/10〉  

【レジスター/領域】数学。  

【文法パターン】the base and the exponent／a logarithm to base ten／a logarithm with base two。  

【コロケーション・構文例】

・the base and the exponent  
用途: 累乗の構成部分を区別する。  
例: In three to the fourth power, the base is three and the exponent is four.  
訳: 3の4乗では、底は3で、指数は4である。  

・a logarithm to base ten  
用途: 対数の底を示す。  
例: The logarithm of one hundred to base ten is two.  
訳: 10を底とする100の対数は2である。  

【語法・注意】base と exponent は同じ計算に使う別の要素で、反意語ではない。対数の to base ten と、十進表記を示す in base ten は前置詞を含めて区別する。  

21. 【名詞：可算】割合・比較の基準となる数値

【日本語訳・定義】割合や変化率などを計算するとき、計算の出発点・基準にする量。何を base に採るかで同じ変化の割合も変わるため、基準量を明示する。  

【頻度】〈5/10〉  

【レジスター/領域】数量比較・統計・経済の説明。  

【文法パターン】use something as a base／a base of 100／the base for calculating something。  

【コロケーション・構文例】

・use something as a base  
用途: 割合計算の基準値を指定する。  
例: Use last year's sales as a base when calculating the percentage increase.  
訳: 増加率を計算するときは、前年の売上高を基準にする。  

・a base of 100  
用途: 指数の基準値を述べる。  
例: The index uses a base of 100 for the first year.  
訳: その指数では、初年度の基準値を100としている。  

【語法・注意】base は、ここでは比率そのものではなく比率を計算する基準量。base year は比較の基準年という複合表現。税務の tax base も課税の基準となる範囲・量を指すが、具体的な算定内容は税の種類や制度によって異なり、常に総収入そのものとは限らない。  

22. 【名詞：可算】化学の塩基

【日本語訳・定義】酸に対する化学的な性質で分類される物質。どの酸塩基理論を用いるかによって定義の仕方があり、プロトンを受け取る物質、電子対を供与する物質などとして扱う。  

【頻度】〈5/10〉  

【レジスター/領域】化学・理科教育。  

【文法パターン】a strong base／a weak base／act as a base／acids and bases。  

【コロケーション・構文例】

・a strong base  
用途: 酸塩基としての強さの分類を述べる。  
例: The textbook lists sodium hydroxide as a strong base.  
訳: その教科書は、水酸化ナトリウムを強塩基として挙げている。  

・a weak base  
用途: 弱塩基という分類を述べる。  
例: Ammonia is a weak base in water.  
訳: アンモニアは、水中では弱塩基である。  

・act as a base  
用途: 反応の中で塩基として働くことを述べる。  
例: In this reaction, the molecule acts as a base by accepting a proton.  
訳: この反応では、その分子はプロトンを受け取ることで塩基として働く。  

【語法・注意】化学での base を土台と訳さない。alkali は水に溶ける塩基を指す用語として使われるが、base 全体と無条件に同一視しない。strong／weak はこの分類では濃度が高い／低いと同義ではない。物質を味見して判定するという意味の語ではなく、安全性もこの語だけでは分からない。  

23. 【名詞：可算】核酸を構成する塩基

【日本語訳・定義】DNAやRNAを構成する、アデニンなどの塩基部分。配列の説明では A、T、G、C などで表される単位に注目して使う。  

【頻度】〈4/10〉  

【レジスター/領域】分子生物学・遺伝学。  

【文法パターン】a sequence of bases／a base pair／the order of the bases。  

【コロケーション・構文例】

・a sequence of bases  
用途: 核酸の塩基配列を述べる。  
例: The diagram shows a short sequence of bases in DNA.  
訳: その図は、DNA中の短い塩基配列を示している。  

・a base pair  
用途: 二つの塩基の対を述べる。  
例: The illustration highlights one base pair in the DNA molecule.  
訳: その図解では、DNA分子の一つの塩基対が強調されている。  

【語法・注意】base と nucleotide は完全な同義語ではない。ヌクレオチドは塩基だけでなく糖・リン酸部分も含む。base pair を塩基が一個という意味で数えない。ここでは語彙上の区別を述べており、配列だけから病気や性質を判断できるという含意はない。  

24. 【名詞：可算】語形成の基体

【日本語訳・定義】接辞などを付けて新しい語形・語を作る際に、その操作の土台となる形。すでに接辞を含んだ形が、次の操作の base になることもある。  

【頻度】〈3/10〉  

【レジスター/領域】言語学・語形成。  

【文法パターン】attach a suffix to a base／a complex base／the base of a derived word。  

【コロケーション・構文例】

・attach a suffix to a base  
用途: 接尾辞を付ける対象を説明する。  
例: We attach the suffix -ness to the base happy to form happiness.  
訳: 基体のhappyに接尾辞-nessを付けて、happinessを作る。  

・a complex base  
用途: 内部構造を持つ基体を述べる。  
例: A complex base may already contain an affix.  
訳: 複合的な基体は、すでに接辞を含んでいることがある。  

【語法・注意】base を必ずそれ以上分けられない root と同一視しない。root は語根、stem は語幹という説明に使われるが、用語の範囲には分析上の差もある。上の例では綴りが happy から happi- に変わる点も区別する。  

25. 【形容詞：主に限定】貴金属でない、品位の低い：base metal

【日本語訳・定義】金属について、貴金属ではないことを表す。また、古い記述などでは純度・品質が低い金属という意味でも用いる。人の道徳的評価ではなく、金属の価値・性質に関する系列である。  

【頻度】〈4/10〉  

【レジスター/領域】金属・工業。純度の低さを表す用法は古い記述にも見られる。  

【文法パターン】base metals／a base metal／coins of base metal。  

【コロケーション・構文例】

・base metals  
用途: 貴金属ではない金属類を述べる。  
例: The chapter distinguishes precious metals from base metals.  
訳: その章は、貴金属と卑金属を区別している。  

・a base metal  
用途: 金属の分類を示す。  
例: Copper is classified as a base metal rather than a precious metal.  
訳: 銅は、貴金属ではなく卑金属に分類される。  

【語法・注意】卑金属という訳の卑は、人間への侮辱を意味しない。現代の分類で base metal と呼ばれるからといって、必ず不純物が多いわけではない。

【文法パターン】the base of a transistor／the base terminal／base current。

・the base terminal

27. 【形容詞：based】人の目に左右されず、自分らしくある

【日本語訳・定義】他人の評価を恐れず、自分の個性や信念を保っていることを好意的に述べる俗語。通常の based on の分詞とは別の語彙的な意味として読む。  

【頻度】〈3/10〉  

【レジスター/領域】英語圏の俗語・オンライン文化。  

【文法パターン】stay based／be based。  

【コロケーション・構文例】

・stay based  
用途: 自分らしさを保つことを、俗な言い方で勧める。  
例: Stay based—don't change your style just to please the crowd.  
訳: 自分らしくいこう。みんなに気に入られようとして、自分のスタイルを変えないで。  

【語法・注意】/beɪst/ と1音節で発音する。on 以下の根拠を省略しただけの形とは限らない。使用する集団や文脈に依存する評価語で、正式な人物評に一般化しない。次の語義28では、自分らしさよりも発言などへの賛同・称賛が前面に出る。  

28. 【形容詞：based】いいね、支持できる、称賛に値する

【日本語訳・定義】意見・行動などを支持し、格好いい・よく言ったと評価するネット上の俗語。周囲に迎合しない意見への称賛にも使うが、客観的に正しいという認定ではない。  

【頻度】〈5/10〉  

【レジスター/領域】インターネットの俗語・冗談を含む非常にくだけた表現。  

【文法パターン】that's based／a based take／be pretty based。  

【コロケーション・構文例】

・that's based  
用途: 相手の意見などを肯定的に評価する。  
例: You told them to give everyone a proper break? That's based.  
訳: みんなにちゃんと休憩を取らせるよう言ったの？ それはよく言ったね。  

・a based take  
用途: 自分が支持する意見を俗な言い方で称賛する。  
例: Several commenters called her view on the redesign a based take.  
訳: コメントした何人かは、デザイン変更に関する彼女の意見を、支持できるいい意見だと評した。  

【語法・注意】That's based. は That is based on evidence. と違い、根拠を示す on 以下を必要としない。限定用法では a based take のように使える。この俗語だけで話者の政治的立場を決めつけない一方、どの意見に賛同しているかは文脈で読む。丁寧な業務文書では避ける。  

29. 【名詞句：単数・慣用的に無冠詞】キスに至る段階：first base

【日本語訳・定義】恋愛的・性的な進展を野球の塁にたとえ、キスに至る段階を指す俗な表現。業務上の最初の進展を表す語義17とは対象が異なる。  

【頻度】〈3/10〉  

【レジスター/領域】特に米国のくだけた会話・恋愛をスポーツにたとえる俗語。  

【文法パターン】get to first base with someone／not get past first base。  

【コロケーション・構文例】

・get to first base with someone

例: He said he'd got to first base with his date, meaning they had kissed.  
訳: 彼は、デート相手とキスをしたという意味で、一塁まで進んだと言った。  

【語法・注意】相手を with の後ろに置く。この比喩の段階を普遍的な恋愛の手順や、相手の同意の有無の説明として扱わない。競技の点取りにたとえる言い方を不快に感じる人もいるため、相手や場面を選ぶ。
