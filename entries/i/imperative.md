＃発音記号

米: /ɪmˈper.ə.t̬ɪv/｜英: /ɪmˈper.ə.tɪv/。4音節で主強勢は第2音節。示した米英差は第4音節の頭の子音で、米の /t̬/ は短くはじく音、英では /t/。第3音節の母音は弱い /ə/。形容詞と名詞で主強勢は変わらない。  
名詞の複数形 imperatives は語尾に /z/ が加わり、音節数は増えない。副詞 imperatively も主強勢は第2音節のままで、語尾に /li/ が加わる。  

＃語源

後期ラテン語 imperativus「命令に関する」に由来する。元の imperare「命じる」は、in-「向かって」と parare「準備する」にさかのぼる。英語では文法用語として早くから使われたが、現代では「対応を強く求める、欠かせない」という一般的な意味も重要である。語頭の im- はこの語では否定の接頭辞ではない。  
同じ imperare の語族に emperor「皇帝」、empire「帝国」、imperious「尊大で命令口調の」がある。より遠い同族に parare を含む prepare「準備する」がある。imperative を帝国に関する語として訳したり、imperious と常に同じ悪い評価を持つと考えたりしない。  

＃語形成

・imperatives：可算名詞の複数形。business imperatives「事業上の必須課題」、文法の negative imperatives「否定命令文」など。形容詞そのものに複数語尾が付くわけではない。  
・imperatively：副詞。「どうしても必要なほど、強く要求して、命令的に」。やや硬く、She spoke imperatively. なら「彼女は命令するような調子で話した」。一般的な文では It is imperative to ... などの形容詞構文の方がよく使われる。  
・imperativeness：不可算名詞。「必要不可欠であること、強制的・命令的であること」。まれで硬い。具体的な必須課題は an imperative、必要性一般は necessity と表せることが多い。  

＃コアイメージ

「ある行動・対応へ強く向かわせる」という核。必要性が人に対応を求める場合、課題や命令という形を取る場合、相手に行動を促す文の形式、命令する話し方、コンピューターに手順を指定する方式へつながる。文法の命令形には穏やかな勧めも含まれるため、どの語義でも「威圧的だ」とするわけではない。  

・行動を求める強い必要性 → 「必要不可欠な、どうしてもしなければならない」（語義1）  

・行動を求める課題・要請 → 「必須の課題・要請、命令」（語義2）  

・行動を求める文法上の形式 → 「命令形の、命令法・命令文」（語義3）  

・行動を求める強い話し方 → 「命令的な、有無を言わせぬ」（語義4）  

・行動を求める計算上の手順指定 → 「命令型の」（語義5）  

＃意味・用法・関連表現

1. 【形容詞・主に叙述用法、限定用法も】必要不可欠な、どうしてもしなければならない

【日本語訳・定義】ある行動・条件がきわめて重要で、しなかったり欠けたりすることを容認できないと述べる。早急な対応の必要性を伴うことが多いが、長期的な安全・信頼などの不可欠な条件にも使える。「重要だ」より強く、「ぜひしたい」という希望だけでもない。法律上の義務であることまでは、この語だけでは決まらない。  

【頻度】〈7/10〉  

【レジスター/領域】フォーマル。業務上の注意、報告、政策・安全管理、強い提言。相手に向けると要求の強さが出る。  

【文法パターン】It is imperative that 〈主語〉 + 〈動詞原形〉＝～することが不可欠だ／It is imperative that 〈主語〉 + should 〈動詞原形〉＝同じく必要性を述べる／It is imperative to do something＝～することが不可欠だ／It is imperative for someone to do something＝その人が～することが不可欠だ／〈行動・条件〉 + be / become / remain imperative＝その行動・条件が不可欠だ・不可欠になる・引き続き不可欠だ／make it imperative to do something＝～することを不可欠にする／an imperative need for 〈名詞〉＝差し迫った・不可欠な必要性。that節の動詞原形には be も含む。  

【コロケーション・構文例】

・It is imperative that 〈主語〉 + 〈動詞原形〉  
用途: 行動する人を明示し、強い必要性を伝える。  
例: It is imperative that each supervisor check the revised schedule before assigning shifts.  
訳: 各監督者がシフトを割り当てる前に改訂版の日程を確認することが不可欠だ。  

・It is imperative that 〈主語〉 + be 〈過去分詞〉  
用途: 必要な処理を、受動形のthat節で述べる。  
例: It is imperative that the backup files be stored outside the main office.  
訳: バックアップファイルを本社事務所とは別の場所に保管することが不可欠だ。  

・It is imperative that 〈主語〉 + should 〈動詞原形〉  
用途: should を用いて必要な行動を述べる。特に英国英語で見られる型。  
例: It is imperative that the contractor should notify us before replacing any component.  
訳: 部品を交換する前に、請負業者から当社へ連絡してもらうことが不可欠だ。  

・It is imperative to do something  
用途: 行為者を特定せず、必要な行動を述べる。  
例: It is imperative to preserve the original records during the investigation.  
訳: 調査中は元の記録を保全することが不可欠だ。  

・It is imperative for someone to do something  
用途: 誰に必要な行動なのかを不定詞構文で示す。  
例: It is imperative for new staff to complete the safety briefing before entering the plant.  
訳: 新入職員は工場に入る前に安全説明を受け終える必要がある。  

・remain imperative  
用途: 状況が変わっても必要性が失われていないことを述べる。  
例: Regular maintenance remains imperative even when the equipment appears to be working normally.  
訳: 機器が正常に動いているように見えても、定期的な保守は引き続き不可欠だ。  

・make it imperative to do something  
用途: 新たな事情が対応を不可欠にしたことを述べる。  
例: The discovery of a second leak made it imperative to inspect the entire system.  
訳: 2か所目の漏れが見つかったことで、システム全体の点検が不可欠になった。  

・an imperative need for 〈名詞〉  
用途: 名詞の前で、特に強い必要性を表す。  
例: The report identified an imperative need for better coordination between the two departments.  
訳: 報告書は、2部門の連携改善がどうしても必要だと指摘した。  

【語法・注意】要求・必要性を表すthat節では原形を使う型が重要。It is imperative that he arrive early. の arrive に三単現の -s を付けず、be動詞も he be ready とする。主節が It was imperative ... でも、この原形の型では that he arrive / be ready のまま。これは要求を表す仮定法現在であり、語義3の直接相手に言う命令文とは区別する。  

否定は原形の前に not を置き、It is imperative that he not disclose the figures.「彼がその数値を漏らさないことが不可欠だ」とする。受動形なら that the figures not be disclosed。不定詞では It is imperative not to disclose the figures. となる。It is not imperative to disclose the figures. は「開示することは必須ではない」で、開示しないことを要求してはいない。  

should を伴う型もあり、特に英国英語と結び付くが、原形の型も英国英語で使う。地域・文脈によって直説法も現れるため、that he arrives / that he is ready を見かけたら常に誤文と断定しない。自分で要求を明確に書くときは、原形または should を使う型を押さえる。  

It is imperative for him to attend. は自然だが、He is imperative to attend. を「彼は出席しなければならない」の意味で使わない。形式主語 it を置くか、His attendance is imperative. とする。make it imperative to ... の it も形式目的語で、make imperative him to ... のように並べない。  

強い必要性を表すので absolutely imperative がよく合う。very imperative を中心的な型として覚えるより、absolutely imperative を優先する。ただし必要性を比べる more imperative / less imperative は可能で、絶対に比較できない形容詞ではない。限定用法では an imperative need / duty などがあり、「必ずbe動詞の後だけ」とはしない。  

【類義語】

・essential  
定義: 目的の達成や成立に欠かせない。  
頻度: 〈9/10〉  
違い: essential は不可欠な要素・条件を広く示す。imperative は行動を求める切迫感や、しなければならないという力を出しやすい。  
例: Accurate contact information is essential for a reliable delivery service.  
訳: 信頼できる配送サービスには、正確な連絡先情報が欠かせない。  

・vital  
定義: 成否・存続などにきわめて重要な。  
頻度: 〈8/10〉  
違い: vital は影響の大きさ、imperative は必要な対応を怠れない点に焦点を置きやすい。どちらも It is ... that / to ... と使える。  
例: It is vital to maintain public confidence during the transition.  
訳: 移行期間中に人々の信頼を保つことがきわめて重要だ。  

・urgent  
定義: 待たずに対応すべき、緊急の。  
頻度: 〈8/10〉  
違い: urgent は時間的な切迫を直接表す。imperative は先延ばしできない場面にも使うが、長期的な不可欠性にも使える。  
例: The supplier sent an urgent request for a revised delivery address.  
訳: 供給業者は、変更後の配送先を至急知らせてほしいと依頼した。  

・mandatory  
定義: 規則・法律・権限ある指示によって義務付けられた。  
頻度: 〈7/10〉  
違い: mandatory は義務を定める外的な規則に焦点を置く。imperative は、正式な規則がなくても状況上不可欠だという判断に使える。  
例: Attendance at the induction session is mandatory for all new employees.  
訳: すべての新入社員に、導入研修への出席が義務付けられている。  

【反意語】

・optional  
定義: 実行・選択するかを本人が選べる、任意の。  
頻度: 〈8/10〉  
違い: 「しなければならない」必要性と「選んでも選ばなくてもよい」という義務性の対立。重要であっても任意の場合はあり、重要性の低さを直接表す語ではない。  
例: The afternoon workshop is optional.  
訳: 午後のワークショップへの参加は任意だ。  

・unnecessary  
定義: 必要がない、なくてもよい。  
頻度: 〈8/10〉  
違い: imperative の強い必要性と、必要性がない状態が対立する。not imperative は単に「必須とまではいえない」場合もあり、必ず unnecessary と同じ強さではない。  
例: A second application is unnecessary if your details have not changed.  
訳: 登録内容に変更がなければ、再度の申請は不要だ。  

2. 【名詞・可算】必須の課題・要請、命令

【日本語訳・定義】必ず実行・充足すべきだとされる課題・要求・義務。事業上の必要性、道徳的な責務、行動を方向付ける原則などを、一つの要請として捉える。具体的な「命令」を指す文語的な用法もある。状況から生じる必要性にも使い、必ず誰かが命令を発したことを前提としない。  

【頻度】〈6/10〉  

【レジスター/領域】フォーマル。経営・政策・倫理・評論。具体的な命令を指す用法は文語寄り。哲学の categorical imperative などにも使う。  

【文法パターン】an imperative＝一つの必須課題・要請／a moral / business / strategic imperative＝道徳・事業・戦略上の要請／the imperative to do something＝～しなければならないという要請／the imperative of doing something＝～するという不可欠の課題／〈行動〉 + be an imperative＝その行動が必須課題だ／competing imperatives＝互いに競合する要請。具体的な要請を複数扱うときは imperatives とする。  

【コロケーション・構文例】

・a business imperative  
用途: 事業の維持・成功のために避けて通れない課題を示す。  
例: Reducing delivery errors has become a business imperative for the company.  
訳: 配送ミスを減らすことが、その会社にとって事業上の必須課題になった。  

・a moral imperative  
用途: 損得だけでなく、道徳的に果たすべき要請と位置付ける。  
例: The director described honest reporting as a moral imperative, even when the results were disappointing.  
訳: 責任者は、結果が期待外れでも正直に報告することは道徳的な責務だと述べた。  

・the imperative to do something  
用途: 避けられない要求の内容を不定詞で示す。  
例: The team struggled to reconcile the imperative to cut costs with the need to retain experienced staff.  
訳: チームは、経費削減という要請と、経験豊富な職員を確保する必要性を両立させるのに苦労した。  

・the imperative of doing something  
用途: 実施すべき課題の内容を名詞的に示す。  
例: The discussion returned to the imperative of keeping the service accessible to rural residents.  
訳: 議論は、地方の住民もサービスを利用できる状態を保つという不可欠の課題に立ち返った。  

・competing imperatives  
用途: どちらも必要だが、同時に満たしにくい複数の要請を示す。  
例: Managers must balance the competing imperatives of speed, accuracy, and cost control.  
訳: 管理者は、迅速さ・正確さ・経費管理という競合する要請の釣り合いを取らなければならない。  

・the categorical imperative  
用途: カント哲学の「定言命法」という定着した専門表現。  
例: The lecturer contrasted the categorical imperative with rules that apply only if we pursue a particular goal.  
訳: 講師は、定言命法と、特定の目的を追求する場合にだけ適用される規則を対比した。  

・an imperative to do something  
用途: 文語的に、実際に出された命令の内容を示す。  
例: The guard's imperative to leave the building at once allowed no discussion.  
訳: 直ちに建物から出るようにという警備員の命令には、議論の余地がなかった。  

【語法・注意】It is imperative to act. の imperative は形容詞なので冠詞を付けない。Taking action is an imperative. の imperative は可算名詞で、ここでは an が必要。「必須だ」と「必須課題だ」の品詞差を意識する。  

a moral imperative は、話者が道徳的な必要性を示しているのであり、誰もがその判断に同意しているとは限らない。economic imperatives は経済事情から生じる要請で、必ず「経済的な命令」とは訳さない。具体的な命令を平明に述べるだけなら an order / a command が普通で、imperative は硬い表現になる。  

哲学では categorical imperative「定言命法」は、特定の欲求や目的の達成を条件としない無条件の要請。対して hypothetical imperative「仮言命法」は、ある目的を求めるならその手段を取るべきだという条件付きの要請である。カントの用語としての区別であり、日常の a moral imperative を使うたびに、この哲学体系への賛同を表すわけではない。語義3の「命令文」という文法形式とも区別する。  

【類義語】

・necessity  
定義: なくてはならない物事、不可欠の条件。  
頻度: 〈8/10〉  
違い: a necessity は必要な物や設備にも広く使う。an imperative は行動・対応を要求する課題としての力を出しやすい。  
例: Reliable internet access is a necessity for our remote team.  
訳: 安定したインターネット接続は、遠隔勤務のチームに不可欠だ。  

・requirement  
定義: 満たすことを求められる条件・要求。  
頻度: 〈9/10〉  
違い: requirement は申請条件や仕様などを中立的に述べられる。imperative は要求の強さ・重要性を前面に出し、必ず明文化された条件とは限らない。  
例: The specification includes a requirement for offline access.  
訳: 仕様には、オフラインで利用できることが要件として含まれている。  

・obligation  
定義: 約束・立場・法律・道徳などから生じる義務。  
頻度: 〈8/10〉  
違い: obligation は誰が誰に対して義務を負うかに焦点を置きやすい。imperative は状況上避けられない課題にも使い、特定の相手への義務を前提としない。  
例: We have an obligation to notify customers of the change.  
訳: 私たちには、その変更を顧客に知らせる義務がある。  

・command  
定義: 権限を持つ人などが発する命令。  
頻度: 〈8/10〉  
違い: 具体的な命令を指す imperative と重なる。command は命じる行為・発言が明確で、経済事情から生じる要請を表す business imperative とはそのまま交換しない。  
例: The crew followed the captain's command to return to port.  
訳: 乗組員は、港へ戻るようにという船長の命令に従った。  

3. 【形容詞・主に限定用法／名詞・命令法は通常the付き、個々の形式は可算】命令形の、命令法・命令文

【日本語訳・定義】文法で、聞き手などに行動を求めたり促したりする形式に関する語。形容詞では imperative clause「命令節」のように使う。名詞 the imperative は「命令法・命令形」という文法カテゴリー、an imperative / imperatives は個々の命令文・命令形の語句などを指す。英語では典型的に動詞の原形で始まり、主語は表面上現れない。命令だけでなく、依頼・助言・招待にも使う。  

【頻度】〈5/10〉  

【レジスター/領域】文法・言語教育。「命令形」という形式の分類で、発話が失礼・威圧的であると必ず評価しているわけではない。  

【文法パターン】形容詞: an imperative clause / an imperative sentence＝命令節・命令文／the imperative mood＝命令法／an imperative form＝命令形。名詞: in the imperative＝命令形で／use the imperative＝命令形を使う／an imperative / negative imperatives＝一つの命令文・否定命令文。分類を表す用法なので、通常は very imperative のような程度表現を付けない。  

【コロケーション・構文例】

・an imperative clause  
用途: 形容詞として、節の種類を指す。  
例: The editor replaced the long explanation with an imperative clause: "Keep the entrance clear."  
訳: 編集者は長い説明を、「入口をふさがないでください」という命令節に置き換えた。  

・the imperative mood  
用途: 形容詞として、動詞や節の文法カテゴリーを名付ける。  
例: The lesson compares the imperative mood with other ways of asking people to act.  
訳: その授業では、命令法と、人に行動を求めるほかの方法を比較する。  

・in the imperative  
用途: 名詞として、命令形で表現されていることを述べる。  
例: Most of the safety instructions are written in the imperative.  
訳: 安全上の指示の大部分は命令形で書かれている。  

・use the imperative  
用途: 名詞として、命令形という形式の使用を述べる。  
例: The guide uses the imperative to give short, clear directions to visitors.  
訳: その案内は、訪問者に短く明確な指示を出すために命令形を使っている。  

・negative imperatives  
用途: 可算名詞の複数形として、禁止などを示す命令文を指す。  
例: Negative imperatives such as "Don't touch the screen" appear throughout the manual.  
訳: 「画面に触れないでください」のような否定命令文が、マニュアルの各所に現れる。  

【語法・注意】命令形の通常の肯定形は動詞原形で、Close the lid.「ふたを閉じてください」。否定形は Don't close the lid.。be も Don't be late. とし、Are not late. を命令文として作らない。主語を出して You stay here.「あなたはここにいて」と言うこともあるため、「命令文には主語が絶対にない」は不正確。  

Please take a seat. は丁寧な勧め、Enjoy your stay. は願いを込めた言葉で、形が imperative でも強制命令とは限らない。Let's begin. のような let を使った形も、行動を促す構文として扱われる。句読点は常に感嘆符でなくてよく、書き方・語調・人間関係によって丁寧さが変わる。  

in the imperative には通常 the を付ける。一つの実例なら an imperative、複数なら imperatives と数えられる。imperative sentence の imperative は形容詞で、a sentence imperative と名詞の後ろへ機械的に移さない。The sentence is imperative. と分類を述べる叙述用法も専門的な説明では見られるが、まず名詞の前の型を覚える。  

It is imperative that she be informed. の imperative は語義1の「不可欠な」。that she be informed は要求を表す仮定法現在の節で、Be informed! のような直接の命令文と同じ構文ではない。また、declarative「平叙の」、interrogative「疑問の」は文の種類の対照語であり、単純に「命令の反対」を表す語ではない。  

4. 【形容詞・限定／叙述】命令的な、有無を言わせぬ

【日本語訳・定義】声・口調・身ぶりなどが、相手に行動や服従を強く求める性質を持つ。威圧的に響くこともあるが、本人の尊大な性格だけでなく、緊急事態で強く指示する場合にも使う。単に必要性が高いという語義1や、文法上の形式という語義3とは焦点が異なる。  

【頻度】〈4/10〉  

【レジスター/領域】フォーマル・文語寄り。人物の話し方・指示の調子の描写。  

【文法パターン】an imperative tone / an imperative gesture＝命令するような口調・身ぶり／〈声・口調〉 + be / become imperative＝命令的だ・命令的になる。性質の強さを比べる more imperative も可能。人が何かをすべきだという意味で someone is imperative to do ... とはしない。  

【コロケーション・構文例】

・an imperative tone  
用途: 行動を強く要求する口調を描く。  
例: She used an imperative tone to tell everyone to move away from the damaged cable.  
訳: 彼女は命令するような口調で、損傷したケーブルから全員離れるように言った。  

・an imperative gesture  
用途: 言葉以外の動作が強い指示を伝える場面を描く。  
例: With an imperative gesture, the officer directed the waiting drivers to stop.  
訳: 警官は有無を言わせぬ身ぶりで、待っている運転手たちに止まるよう指示した。  

・become imperative  
用途: 話し方が、穏やかな依頼から命令的なものへ変わることを描く。  
例: His tone became imperative when the visitors ignored the evacuation announcement.  
訳: 訪問者たちが避難放送に従わないのを見て、彼の口調は命令的になった。  

【語法・注意】an imperative tone は話し方の性質、an imperative sentence は語義3の文法分類。同じ発言について両方が成り立つこともあるが、丁寧な命令形の文にも、命令形でない威圧的な発言にも出会う。  

imperious は「偉そうに指図する」という人格・態度への否定的評価を強く出しやすい。imperative は切迫した状況に応じた強い指示にも使え、必ずしも話し手を尊大だと非難しない。ただし、日常の感想として「その人は偉そうだ」と言うなら imperious / bossy などの方が意図が明確になる。  

【類義語】

・commanding  
定義: 権威や力を感じさせ、人を従わせるような。  
頻度: 〈6/10〉  
違い: commanding voice は声の存在感・統率力も表す。imperative tone は具体的に行動を強く求める調子を示しやすい。  
例: Her commanding voice could be heard above the noise.  
訳: 彼女の威厳ある声は、騒音の中でも聞き取れた。  

・peremptory  
定義: 反論・拒否を認めないような、断固として一方的な。  
頻度: 〈4/10〉  
違い: peremptory はぶっきらぼうさや取り付く島のなさを強調する。imperative は強く要求する調子を表し、緊急時の妥当な指示にも使える。  
例: He dismissed the suggestion with a peremptory wave of his hand.  
訳: 彼は取り付く島のない手ぶりで、その提案を退けた。  

・imperious  
定義: 自分が従われて当然だという態度で、尊大に命じる。  
頻度: 〈4/10〉  
違い: imperious は話し手の支配的・高圧的な態度への評価が強い。imperative は必要に迫られた強い指示にも使うため、尊大さを必須としない。  
例: The guests resented the host's imperious manner.  
訳: 客たちは、主催者の尊大な態度に不快感を抱いた。  

5. 【形容詞・限定／叙述】命令型の

【日本語訳・定義】プログラミングで、コンピューターに実行する処理・手順を指定し、変数などの状態を変えながら計算を進める方式の。何を得たいかを中心に表す declarative「宣言型の」と対比される。人に対する命令口調や、プログラムが不可欠だという意味ではない。  

【頻度】〈4/10〉  

【レジスター/領域】コンピューター科学・ソフトウェア開発の専門語。一般の業務指示書を何でも imperative programming と呼ぶわけではない。  

【文法パターン】imperative programming＝命令型プログラミング／imperative code＝命令型のコード／an imperative approach＝命令型の方法／〈実装・コード〉 + be imperative＝命令型である。方式の分類だが、more imperative のように実装の傾向を比較する用法もある。  

【コロケーション・構文例】

・imperative programming  
用途: 計算の手順を明示するプログラミング方式を指す。  
例: The course introduces imperative programming through variables, loops, and conditional statements.  
訳: その講座では、変数・ループ・条件文を通じて命令型プログラミングを紹介する。  

・imperative code  
用途: 個々の処理や状態変化を記述するコードを指す。  
例: The imperative code updates a running total after each item is processed.  
訳: その命令型のコードは、各項目を処理するたびに累計値を更新する。  

・an imperative approach  
用途: 目標を達成する具体的な手順を記述する方針を指す。  
例: An imperative approach specifies how to create each resource rather than only describing the desired final state.  
訳: 命令型の方法では、望む最終状態を記述するだけでなく、各リソースをどう作成するかを指定する。  

・be imperative  
用途: 実装の方式を叙述する。  
例: The query is declarative, but the surrounding update logic is imperative.  
訳: クエリは宣言型だが、その周囲の更新処理は命令型だ。  

【語法・注意】imperative と object-oriented「オブジェクト指向の」は、単純な反対語ではない。オブジェクト指向の言語・実装でも、命令型の処理を多く使う。同じ言語やシステムが複数の方式を支えることもあり、言語全体を一つの型に固定しすぎない。  

対照となる declarative は「何を実現したいか」、imperative は「どの手順で実現するか」に焦点を置く、というのが基本的な区別。procedural「手続き型の」は命令型と近接するが、手続き・関数による構成の仕方にも関わるため、どの分類でも完全に同じ範囲とは限らない。functional「関数型の」は関数の評価・合成を中心に考える方式で、単に「関数を1つでも使うコード」という意味ではない。
