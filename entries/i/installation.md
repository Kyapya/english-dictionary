＃発音記号

米・英: /ˌɪn.stəˈleɪ.ʃən/。4音節で、第1音節に第二強勢、第3音節に主強勢がある。第2音節の母音は弱い /ə/、第3音節は /eɪ/。install の強勢のある母音とは形が変わり、installation では -la- の部分を強く読む。  

＃語源

中世ラテン語 installatio に由来し、installare「席・地位に据える」から作られた名詞。installare は in-「中へ」と stallum「席・場所」から成る。英語では install と -ation の対応で覚えられるが、歴史的な借用経路と現代の語形成上の対応は区別する。install「設置する・就任させる」、installer「設置作業者・導入プログラム」は同じ語族で、stall「区画・席」も語源的につながる。  

＃語形成

・install：設備を設置する・ソフトを導入する・人を役職に就ける、などの動詞。  
・installer：設置作業者、またはインストールを実行するプログラム。可算名詞。  
・reinstallation：再設置・再インストール。再び導入することを表す名詞。  
・uninstallation：ソフトウェアのアンインストール。一般の施設の撤去を広く指す語ではない。  
・installation art：空間に物・光・音などを構成して成立させる美術表現。art は分野を指す場合、不可算。  
・installation artist：インスタレーション作品を制作する美術家。  

＃コアイメージ

共通するのは、物や人を所定の場所・環境・役割に据えること、または据えられて成り立つもの。行為を表す用法と、完成した設備・施設・作品を表す用法で数え方が変わる。  

・設備を使用する場所に据える行為 → 「設置・取り付け」（語義1）  

・ソフトを使用する環境に据える行為 → 「インストール・導入」（語義2）  

・使用する場所に据えられた設備 → 「設置設備・装置一式」（語義3）  

・特定の活動の場所に据えられた施設 → 「施設・基地」（語義4）  

・鑑賞する空間に据えられた作品 → 「インスタレーション作品」（語義5）  

・人物を任務を果たす地位に据える行為 → 「就任・任命」（語義6）  

＃意味・用法・関連表現

1. 【名詞・不可算、個別の施工は可算】設置・取り付け

【日本語訳・定義】機器・設備・備品を取り付け、使える状態にすること。作業一般は不可算で、個別の設置工事や施工例を一件として捉える場合は可算にもなる。  

【頻度】〈8/10〉  

【レジスター/領域】一般・設備・建設・業務。  

【文法パターン】installation of 〈機器・設備〉＝機器・設備の設置／the installation of 〈特定の設備〉＝その設備の設置工事／installation costs＝設置費用／free installation＝無料の設置サービス／an installation＝一件の設置作業  

【コロケーション・構文例】

・the installation of 〈設備〉  
用途: 設置する対象を of で示す。  
例: The installation of the new lift will begin next month.  
訳: 新しいエレベーターの設置工事は来月始まる。  

・installation costs  
用途: 機器代などと区別して設置費を指す。  
例: Installation costs are included in the quotation.  
訳: 設置費用は見積もりに含まれている。  

・free installation  
用途: 設置作業が無料であることを示す。  
例: The supplier offers free installation with this model.  
訳: その供給業者は、この機種について無料の設置サービスを提供している。  

・complete an installation  
用途: 一件の施工を数える。  
例: The team completed three installations this week.  
訳: そのチームは今週、設置工事を3件完了した。  

・prior to installation  
用途: 設置より前の段階を表す。  
例: Check the dimensions prior to installation.  
訳: 設置前に寸法を確認してください。  

【語法・注意】設置という作業一般なら installation is ... と単数一致にし、冠詞を付けないことが多い。an installation は個別の施工、または語義3の設置済みの装置を指す。delivery and installation は「配送と設置」で、配送されたことだけでは設置済みとは限らない。設置後の点検・動作確認・保守まで、すべてをこの語だけで含むとは断定できない。  

【類義語】

・fitting  
定義: 設備・部品の取り付け。  
頻度: 〈6/10〉  
違い: 特に英国英語で使い、寸法を合わせて取り付ける作業にも適する。  
例: The price includes the fitting of the new carpet.  
訳: 料金には新しいカーペットの敷設が含まれている。  

・setup  
定義: 機器を使える状態に準備すること。  
頻度: 〈7/10〉  
違い: 一時的な機器配置・接続・設定にも使い、固定工事を必ずしも含まない。  
例: The setup of the sound equipment took an hour.  
訳: 音響機器の準備には1時間かかった。  

・mounting  
定義: 物を台や面に固定すること。  
頻度: 〈5/10〉  
違い: 設置工程のうち、支えに取り付ける行為を特に表す。  
例: The mounting of the display requires two people.  
訳: そのディスプレイの取り付けには2人必要だ。  

【反意語】

・removal  
定義: 設置した物を取り外すこと・撤去。  
頻度: 〈8/10〉  
違い: 設置位置へ据えることに対し、そこから取り去る方向上の反対。  
例: Removal of the old boiler will take one day.  
訳: 古いボイラーの撤去には1日かかる。  

2. 【名詞・不可算、個別の導入は可算】インストール・導入

【日本語訳・定義】ソフトウェアやアプリを端末・システムに導入し、使用できるようにすること。導入の過程一般は不可算で、個々の導入作業や導入済みの環境を区別して数える場合は可算になる。  

【頻度】〈8/10〉  

【レジスター/領域】コンピューター・一般。  

【文法パターン】installation of 〈ソフトウェア〉＝ソフトウェアの導入／installation on 〈端末〉＝端末への導入／during installation＝インストール中に／a clean installation＝既存の導入状態を引き継がない新規導入／a successful installation＝正常に完了した一回の導入  

【コロケーション・構文例】

・installation of 〈ソフトウェア〉  
用途: 導入対象を示す。  
例: Installation of the software requires administrator access.  
訳: そのソフトウェアのインストールには管理者権限が必要だ。  

・installation on 〈端末〉  
用途: 導入先の端末を示す。  
例: The guide covers installation on a laptop.  
訳: そのガイドはノートパソコンへのインストールを扱っている。  

・during installation  
用途: 導入処理中の出来事を示す。  
例: An error message appeared during installation.  
訳: インストール中にエラーメッセージが表示された。  

・a clean installation  
用途: 以前の導入状態を引き継がない作業を示す。  
例: The technician performed a clean installation of the operating system.  
訳: 技師は基本ソフトのクリーンインストールを行った。  

・a successful installation  
用途: 一回の導入の成否を述べる。  
例: The message confirms a successful installation.  
訳: そのメッセージはインストールが正常に完了したことを示している。  

【語法・注意】一般に of は導入するソフト、on は導入先の端末を示す。installation と download「ダウンロード」は別の段階になり得る。a clean installation で何が削除・保持されるかは製品や手順による。既に入っているソフト環境を指す an existing installation のような可算用法もあり、「ソフトの installation は必ず不可算」とはしない。  

【類義語】

・install  
定義: 一回のソフト導入作業。  
頻度: 〈5/10〉  
違い: ITのややくだけた短い名詞表現で、a clean install などで使う。  
例: The install finished without errors.  
訳: インストールはエラーなく完了した。  

・setup  
定義: ソフトを使うための導入・設定作業。  
頻度: 〈8/10〉  
違い: ソフトの配置だけでなく、初期設定を含む広い準備過程を指すことがある。  
例: The setup process asks you to choose a language.  
訳: セットアップの過程で、言語を選ぶよう求められる。  

【反意語】

・uninstallation  
定義: インストール済みソフトを削除すること。  
頻度: 〈5/10〉  
違い: 導入に対する方向上の反対。どのファイルが残るかは処理方法による。  
例: Uninstallation of the program took less than a minute.  
訳: そのプログラムのアンインストールには1分もかからなかった。  

3. 【名詞・可算】設置設備・装置一式

【日本語訳・定義】特定の場所に据え付けられて使用される設備・装置、またはその一式。設置という作業ではなく、設置されたもの自体を指す。単体の機器にも一つのシステム全体にも使われる。  

【頻度】〈6/10〉  

【レジスター/領域】技術・建築・設備。  

【文法パターン】a heating installation＝暖房設備／an electrical installation＝電気設備一式／existing installations＝既設設備  

【コロケーション・構文例】

・a heating installation  
用途: 設置された暖房システムを指す。  
例: The building has an old heating installation.  
訳: その建物には古い暖房設備がある。  

・an electrical installation  
用途: 設置済みの電気設備を指す。  
例: An electrician inspected the electrical installation.  
訳: 電気技師がその電気設備を点検した。  

・a solar installation  
用途: 設置済みの太陽光発電設備などを指す。  
例: The school’s solar installation supplies part of its electricity.  
訳: その学校の太陽光発電設備は、使用電力の一部を供給している。  

・existing installations  
用途: 既に据え付けられている設備をまとめる。  
例: The engineers assessed the condition of the existing installations.  
訳: 技師たちは既設設備の状態を評価した。  

【語法・注意】installations は複数の設備・システムを数える。equipment は通常不可算なので、an installation と an equipment を同じように使わない。the installation of the heater は普通「ヒーターの設置作業」、the heating installation は「暖房設備」で、of の有無と語の組み合わせが解釈を変える。  

【類義語】

・system  
定義: 相互に働く部品・機器のまとまり。  
頻度: 〈9/10〉  
違い: 設置済みかどうかより、機能上の組み合わせに焦点がある。  
例: The heating system needs an upgrade.  
訳: その暖房システムは更新が必要だ。  

・equipment  
定義: ある作業に使う装備・機器。  
頻度: 〈9/10〉  
違い: 通常不可算で、据え付けられた設備にも持ち運べる道具にも使う。  
例: The laboratory has modern testing equipment.  
訳: その研究室には最新の試験機器がある。  

・apparatus  
定義: 特定の目的に使う器具・装置。  
頻度: 〈6/10〉  
違い: 科学実験や技術的な装置に適する語で、設置場所との関係は必須ではない。  
例: The apparatus measures air pressure.  
訳: その装置は気圧を測定する。  

4. 【名詞・可算】施設・基地

【日本語訳・定義】特定の活動のために建物・設備などが整えられた施設。軍事・産業・エネルギー関係などでよく使う。機器一台ではなく、施設や拠点として捉える用法。  

【頻度】〈6/10〉  

【レジスター/領域】報道・軍事・産業。日常の建物を何でも installation と呼ぶわけではない。  

【文法パターン】a military installation＝軍事施設／an industrial installation＝産業施設／a nuclear installation＝原子力関連施設／installations at 〈場所〉＝その場所の施設群  

【コロケーション・構文例】

・a military installation  
用途: 軍の活動のための施設を指す。  
例: Access to the military installation is restricted.  
訳: その軍事施設への立ち入りは制限されている。  

・an industrial installation  
用途: 産業用の施設全体を指す。  
例: The new road serves several industrial installations.  
訳: その新しい道路は複数の産業施設へのアクセスを担っている。  

・a nuclear installation  
用途: 原子力関連設備を備える施設を指す。  
例: Inspectors visited the nuclear installation.  
訳: 検査官たちはその原子力施設を訪れた。  

・offshore installations  
用途: 海上の産業施設をまとめて指す。  
例: Helicopters carry workers to the offshore installations.  
訳: ヘリコプターが作業員を海上施設へ運んでいる。  

【語法・注意】施設の目的や分野を military・industrial などで限定するのが典型的。installation だけで基地の法的地位、施設の規模、常設か仮設かまで一律に決まるわけではない。ホテル・店舗・駅など一般の施設を広く述べたいときは、文脈に合う facility などを使う。  

【類義語】

・facility  
定義: 特定の活動に使う建物・設備・場所。  
頻度: 〈8/10〉  
違い: installation より用途が広く、医療・教育・スポーツなどにも普通に使える。  
例: The town opened a new sports facility.  
訳: その町は新しいスポーツ施設を開設した。  

・base  
定義: 人員や物資を置く活動拠点。  
頻度: 〈7/10〉  
違い: 軍事などの活動の出発点・本拠地という機能を強調する。  
例: The aircraft returned to base.  
訳: その航空機は基地へ戻った。  

・complex  
定義: 関連する複数の建物・設備の集合。  
頻度: 〈6/10〉  
違い: 複数施設がまとまっている構造に焦点を当てる。  
例: The company built a large industrial complex.  
訳: その会社は大規模な工業施設群を建設した。  

5. 【名詞・可算】インスタレーション作品

【日本語訳・定義】物・光・音・映像などを空間に配置・構成し、その空間との関係も含めて体験させる美術作品。複数の素材を使うことや期間限定であることはよくある特徴だが、すべての作品の必須条件ではない。  

【頻度】〈5/10〉  

【レジスター/領域】現代美術。分野全体は installation art。  

【文法パターン】an art installation＝インスタレーション作品／a sound installation＝音を用いたインスタレーション作品／an interactive installation＝鑑賞者の参加・反応を取り込む作品／a site-specific installation＝特定の場所に合わせて作られた作品  

【コロケーション・構文例】

・an art installation  
用途: 作品としての installation を明確にする。  
例: The gallery commissioned an art installation for its entrance hall.  
訳: その画廊は玄関ホール用のインスタレーション作品を発注した。  

・a sound installation  
用途: 音を構成要素とする作品を指す。  
例: Visitors could hear recorded footsteps in the sound installation.  
訳: 来場者は、その音のインスタレーション作品の中で、録音された足音を聞くことができた。  

・an interactive installation  
用途: 鑑賞者の動きなどに反応する作品を指す。  
例: The interactive installation changes color when visitors move.  
訳: その参加型インスタレーション作品は、来場者が動くと色が変わる。  

・a site-specific installation  
用途: 場所の特性に合わせた作品を表す。  
例: The artist created a site-specific installation for the former station.  
訳: その美術家は、かつて駅だったその建物のために、場所の特性に合わせたインスタレーション作品を制作した。  

【語法・注意】an installation は作品一件、installation art は美術の表現分野で通常不可算。the installation of a painting は「絵画を展示場所に設置すること」（語義1に通じる行為）であり、その絵画が自動的にインスタレーション作品になるわけではない。sound・light・interactive などの語があるからといって、実用設備の意味を排除できるわけでもなく、art・gallery などの文脈を確認する。  

【類義語】

・artwork  
定義: 一つの美術作品。  
頻度: 〈7/10〉  
違い: 絵画・彫刻なども含む上位の語で、空間全体を構成する形式に限定しない。  
例: The museum acquired three new artworks.  
訳: その美術館は新たに美術作品を3点取得した。  

・sculpture  
定義: 立体的な形を作る彫刻、またはその作品。  
頻度: 〈7/10〉  
違い: 立体的な作品という点で重なるが、installation は空間・音・映像などの構成も含み得る。  
例: A metal sculpture stands in the courtyard.  
訳: 中庭には金属製の彫刻が立っている。  

6. 【名詞・通常不可算】就任・任命

【日本語訳・定義】人を重要な役職・権限のある地位に正式に据えること。宗教上・大学などの役職への就任で使われ、就任式を伴う場合にも用いる。語だけで特定の法的な任命手続きを指定するものではない。  

【頻度】〈4/10〉  

【レジスター/領域】正式・宗教・大学・公的な組織。  

【文法パターン】the installation of 〈役職者〉＝役職者の就任／someone’s installation as 〈役職名〉＝人のその役職への就任／an installation ceremony＝就任式  

【コロケーション・構文例】

・the installation of 〈役職者〉  
用途: 新たな役職者が正式に地位に就くことを述べる。  
例: The installation of the new bishop will take place in June.  
訳: 新しい司教の就任は6月に行われる予定だ。  

・someone’s installation as chancellor  
用途: 就任先の役職を as で示す。  
例: Her installation as chancellor attracted many former students.  
訳: 彼女の学長就任には、多くの卒業生が集まった。  

・an installation ceremony  
用途: 式典であることを明示する。  
例: The university held an installation ceremony for its new president.  
訳: その大学は新しい学長の就任式を開いた。  

【語法・注意】この行為義は通常不可算で、the installation of ...・her installation のように特定して使う。an installation ceremony の a が付く中心名詞は ceremony。選出・任命の決定と、正式に職に据えることは異なる場合があり、election や nomination と一律に置き換えない。  

【類義語】

・induction  
定義: 正式に役職・組織へ迎え入れること。  
頻度: 〈5/10〉  
違い: 就任のほか入会・入隊などの正式な導入にも使う。  
例: His induction into office was marked by a short ceremony.  
訳: 彼の就任に際して短い式典が行われた。  

・inauguration  
定義: 大統領などの正式な就任、または就任式。  
頻度: 〈6/10〉  
違い: 特に高位の公職で使い、施設の開設・開始という別の意味もある。  
例: The presidential inauguration was held outdoors.  
訳: 大統領就任式は屋外で行われた。  

・appointment  
定義: 役職に任命すること・任命。  
頻度: 〈8/10〉  
違い: 地位を与える決定に焦点があり、就任式を含むとは限らない。  
例: Her appointment as director was announced yesterday.  
訳: 彼女の理事への任命は昨日発表された。
