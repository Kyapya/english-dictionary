＃発音記号

米・英: /ˌæp.lɪˈkeɪ.ʃən/。4音節で、第3音節の /keɪ/ に主強勢、第1音節に第二強勢がある。語末の -tion は /ʃən/。動詞 apply /əˈplaɪ/ の強勢と母音を、そのまま application に持ち込まない。  

＃語源

中英語に入り、フランス語系の形とラテン語 applicatio「接触させること・結び付けること」にさかのぼる。借用経路の記述には、古フランス語を経たとする整理と、中期フランス語・中世ラテン語を挙げる整理がある。基底の applicare は ad-「～へ」と plicare「折る」に関係するが、現代の各語義を「折る」だけから推測することはできない。  
apply「適用する・申請する」と applicable「適用できる」は同じ語族。現在の application は apply に対応する名詞として覚えられるが、英語の apply に単純に -ation を足して初めて生まれた、と借用の歴史まで断定しない。  

＃語形成

・apply：動詞。apply for a job は「仕事に応募する」、apply a rule to a case は「規則を事例に適用する」。申請義と適用義で後続の形が異なる。  
・applicant：申請者・応募者を表す可算名詞。申請書や申請そのものを指さない。  
・applicable：適用できる・当てはまるという形容詞。applicable to something の to は適用対象を導く。  
・applicator：塗布・散布などに使う器具を表す可算名詞。塗る行為を表す application と区別する。  
・app：主にソフトウェア義の application を短くした可算名詞。スマートフォンのほか、パソコンなどのアプリにも使う。米語のくだけた文脈では申請書・応募書類の略にもなる。  

＃意味・用法・関連表現

1. 【名詞・可算/不可算】申請・応募・申し込み

【日本語訳・定義】仕事、資格、入学、許可などを得るために、担当する相手へ正式に求めること、または個々の申し出。書面やオンラインの手続きが典型的だが、語自体が常に紙の書類を意味するわけではない。採用や許可などの結果までは含まない。  

【頻度】〈9/10〉  

【レジスター/領域】一般、採用、教育、行政、会員登録、業務上の手続き。  

【文法パターン】make an application for something＝あるものを申請する／submit an application to 〈機関〉 for something＝機関にあるものを求めて申請を提出する／an application to do something＝ある行為をするための申請／applications from 〈応募者〉＝応募者からの申請／process an application＝申請を処理・審査する／withdraw an application＝申請を取り下げる／on application to 〈窓口〉＝その窓口への申し出に応じて／by application＝申請によって  

【コロケーション・構文例】

・make an application for something  
用途: 求めるものを for の後ろに示す。  
例: We made an application for permission to use the hall.  
訳: 私たちはホールの使用許可を申請した。  

・submit an application to 〈機関〉 for something  
用途: 提出先と求めるものを一つの文で区別する。  
例: The group submitted an application to the council for a grant.  
訳: その団体は地方自治体に助成金の申請を提出した。  

・an application to do something  
用途: 許可・参加などを求める行為を不定詞で示す。  
例: Her application to join the research team was successful.  
訳: 研究チームへの参加を求める彼女の申し込みは認められた。  

・applications from 〈応募者〉  
用途: 応募が誰から来たものかを示す。  
例: We welcome applications from people with experience in retail.  
訳: 小売業の経験がある方からの応募を歓迎します。  

・process an application  
用途: 受け取った申請の処理について述べる。  
例: The office is still processing my application for membership.  
訳: 事務局は私の入会申請をまだ処理している。  

・withdraw an application  
用途: 申請者側が手続きを取り下げる。  
例: He withdrew his application after accepting another job.  
訳: 彼は別の仕事を引き受けた後、応募を取り下げた。  

・on application to 〈窓口〉  
用途: 申し出れば資料などを提供するという案内に使う。  
例: Full details are available on application to the membership office.  
訳: 詳細は会員窓口にお申し出いただければ入手できます。  

・by application  
用途: 申請という方法を、個々の件数を数えずに表す。  
例: Access to the archive is by application only.  
訳: その資料庫の利用には申請が必要です。  

【語法・注意】個別の申請は an application、複数なら applications。on application や by application では、申請という行為を不可算で捉える。an application to the university の to は提出先を示す前置詞、an application to study abroad の to は動詞原形を導く不定詞である。for は得たい地位・許可など、from は申請者を示す。application が accepted でも、受付を済ませた意味か、内容を認めた意味かは文脈による。process は「処理する」であり、承認済みという意味にはしない。語義2の application は記入・提出する書式そのもの。通常の「申し込む」は apply for something といい、apply an application と重ねない。対照表現の registration は名簿・制度への「登録」で、採用や許可を求める application と段階が異なる場合がある。  

【類義語】

・request  
定義: 相手に何かを求める依頼・要求。  
頻度: 〈9/10〉  
違い: 正式な応募や審査手続きを伴わない日常の頼み事にも広く使える。application は職・許可などを求める手続きに焦点がある。  
例: I sent a request for a copy of the schedule.  
訳: 私は日程表のコピーを求める依頼を送った。  

・petition  
定義: 権限のある相手に決定や対応を求める正式な請願・申し立て。  
頻度: 〈6/10〉  
違い: 多数の署名による請願や法的な申し立てにも使う。一般の仕事への応募を指す application とは対象が異なる。  
例: Residents presented a petition asking for a safer crossing.  
訳: 住民は、より安全な横断場所を求める請願を提出した。  

2. 【名詞・可算】申請書・応募書類

【日本語訳・定義】申請・応募をするために情報を記入する用紙や電子フォーム、または記入済みの申請書類。申請という働きかけではなく、その内容を載せる書式・文書を指す。  

【頻度】〈8/10〉  

【レジスター/領域】採用、申請手続き、事務、オンラインサービス。  

【文法パターン】fill out an application＝申請書に記入する／fill in an application form＝申請用紙に記入する／complete an application＝申請書の記入を完成させる／a blank application＝未記入の申請書／attach something to an application＝申請書に何かを添付する  

【コロケーション・構文例】

・fill out an application  
用途: 応募・申請のフォームへの記入を述べる。  
例: Please fill out the application in black ink.  
訳: 申請書は黒インクでご記入ください。  

・fill in an application form  
用途: 特に英語圏の英国系の表現で、用紙の欄を埋めることを述べる。  
例: She filled in the application form on her laptop.  
訳: 彼女はノートパソコンで申請フォームに記入した。  

・complete an application  
用途: 必要事項を記入し終えることを述べる。  
例: Check the address before you complete the application.  
訳: 申請書の記入を終える前に、住所を確認してください。  

・a blank application  
用途: まだ情報の入っていない用紙・フォームを指す。  
例: A blank application is available at the reception desk.  
訳: 未記入の申請用紙は受付で入手できます。  

・attach something to an application  
用途: 申請書に補足資料を付ける。  
例: Attach a copy of your certificate to the application.  
訳: 申請書に証明書のコピーを添付してください。  

【語法・注意】application form とすると書式であることが明確になる。fill out は米語で特によく使われ、fill in は英語圏の英国系で一般的だが、どちらかの地域だけの表現と決め付けない。complete は記入を終えることで、submit「提出する」とは別の段階。an application が「一つの申請」か「一通の申請書」かは、approve、fill out など周囲の動詞から判断する。application form の前半は名詞による修飾で、通常は単数形 application を使う。対照表現の questionnaire は回答を集める「質問票」で、応募手続きに含まれても application と同じ種類の文書とは限らない。  

【類義語】

・form  
定義: 決められた欄に情報を記入する用紙・画面。  
頻度: 〈9/10〉  
違い: 申請に限らず、注文・調査・記録などに使う書式全般を指す。application は申請・応募という目的がある。  
例: Write your contact details on this form.  
訳: この用紙に連絡先を記入してください。  

3. 【名詞・可算/不可算】応用・活用・用途

【日本語訳・定義】知識、理論、技術、方法などを、実際の目的や問題に役立てること。また、その具体的な使い道。実際に用いる行為は不可算、個々の応用例・用途は可算で表しやすい。理論が正しいと知ることと、それを実務に使うことを区別する語である。  

【頻度】〈8/10〉  

【レジスター/領域】一般、技術、研究、教育、業務。  

【文法パターン】the application of something to something＝知識・方法などを対象に応用すること／practical applications of something＝あるものの実用的な応用例／applications in 〈分野〉＝その分野での用途／find an application for something＝あるものの使い道を見いだす／have wide application＝広く応用できる  

【コロケーション・構文例】

・the application of something to something  
用途: 用いる手段と適用先を of と to で区別する。  
例: The course explores the application of statistics to quality control.  
訳: その講座では、品質管理への統計学の応用を扱う。  

・practical applications of something  
用途: 理論や研究から生まれる具体的な使い道を述べる。  
例: The team demonstrated three practical applications of the sensor.  
訳: チームは、そのセンサーの実用的な応用例を三つ実演した。  

・applications in 〈分野〉  
用途: 技術が使われる領域を示す。  
例: This material has applications in packaging and construction.  
訳: この材料は包装と建設の分野で用途がある。  

・find an application for something  
用途: 新しい方法や製品を何に使えるか見いだす。  
例: We found an application for the technique in document restoration.  
訳: 私たちは、その技法を文書の修復に活用できることを見いだした。  

・have wide application  
用途: 一つの技術・原則などが広い範囲で役立つと述べる。  
例: The method has wide application in language research.  
訳: その方法は言語研究に広く応用できる。  

【語法・注意】application of a method は「方法を用いること」、an application of a method は「その方法の一つの応用例」と捉えられる。application to teaching の to は前置詞なので、後ろに teaching のような動名詞を置ける。語義1の an application to teach「教えるための申請」とは意味も構造も違う。applications in agriculture は農業という利用分野、an application for this material はこの材料の使い道を示す。同じ for でも申請義では「求めるもの」になるため、前置詞だけで訳を決めない。語義4は規則の運用で、「便利な使い道」に重点のあるこの語義と区別する。  

【類義語】

・use  
定義: 何かを使うこと、またはその使い道。  
頻度: 〈10/10〉  
違い: 日常的な道具の使用まで含む最も広い語。application は理論や技術を具体的な目的に当てはめる場面で使いやすい。  
例: We are looking for new uses for recycled glass.  
訳: 私たちは再生ガラスの新しい用途を探している。  

・utilization  
定義: 利用可能な資源・設備などを活用すること。  
頻度: 〈6/10〉  
違い: 資源を実際に使う度合いや効率に注目しやすく、個々の用途を数える applications とは形が異なる。  
例: The report examines the utilization of office space.  
訳: 報告書はオフィススペースの活用状況を検討している。  

・implementation  
定義: 計画・制度・仕組みを実行に移すこと。  
頻度: 〈8/10〉  
違い: 決めた内容を実施する段階に焦点がある。application はすでにある知識や方法を別の対象へ使う場合にも用いる。  
例: Implementation of the new timetable begins in April.  
訳: 新しい時刻表の実施は4月に始まる。  

4. 【名詞・主に不可算】適用・当てはまり

【日本語訳・定義】規則、法律、基準などを具体的な人・事例・状況に当てはめて運用すること。また、規則や考えなどがその状況に当てはまること・関係すること。実際に当てはめる行為と、当てはまる範囲のどちらを表すかは、動詞や修飾語から読み分ける。  

【頻度】〈7/10〉  

【レジスター/領域】業務、行政、法律、規程・制度の説明。  

【文法パターン】the application of 〈規則・基準〉 to something＝規則・基準を対象に適用すること／strict application of something＝ある規則などを厳格に適用すること／consistent application of something＝ある基準などを一貫して適用すること／the scope of application of something＝規則などの適用範囲／have no application to something＝ある事例・状況には当てはまらない  

【コロケーション・構文例】

・the application of 〈規則・基準〉 to something  
用途: 何の規則をどの対象に適用するかを示す。  
例: The notice explains the application of the policy to temporary staff.  
訳: 通知は、その方針を臨時職員にどう適用するかを説明している。  

・strict application of something  
用途: 基準を厳格に運用することを述べる。  
例: Strict application of the rules left no room for an exception.  
訳: 規則が厳格に適用され、例外の余地はなかった。  

・consistent application of something  
用途: 対象が変わっても同じ基準で運用することを述べる。  
例: Consistent application of the criteria helps applicants understand the process.  
訳: 基準を一貫して適用することは、応募者が手続きを理解する助けになる。  

・the scope of application of something  
用途: 規定が及ぶ範囲を述べる。  
例: This section defines the scope of application of the agreement.  
訳: この節では、その協定の適用範囲を定めている。  

・have no application to something  
用途: 規則・考えなどが対象の事例には当てはまらないと述べる。  
例: This rule has no application to contracts signed before April.  
訳: この規則は、4月より前に署名された契約には当てはまらない。  

【語法・注意】the application of the rules は規則の「適用」であり、規則を求める「申請」ではない。個別の適用事例を意識すれば a particular application のような可算用法もあるが、一般的な運用は不可算で表す。strict application は実際に厳格に運用すること、have no application to... は「～には当てはまらないこと」を示す。applicability は適用可能性・該当性に焦点があり、後者では意味が近いが、実際の運用という行為を表す application とは区別する。法律・協定の効力、例外、適用対象はその制度の内容で決まり、application という単語だけから推定できない。  

【類義語】

・enforcement  
定義: 法律・規則を守らせること。  
頻度: 〈7/10〉  
違い: 遵守を確保する働きかけに焦点がある。application は規則を事例に当てはめることで、違反への対応を必ずしも含まない。  
例: Enforcement of the parking rules is the council's responsibility.  
訳: 駐車規則を守らせることは地方自治体の責任である。  

・implementation  
定義: 決定した制度・方針を実施すること。  
頻度: 〈8/10〉  
違い: 制度を実施に移すことを広く指す。application は実施される規則を具体的な対象へ当てはめる側面を示す。  
例: The department is preparing for implementation of the new policy.  
訳: その部署は新方針の実施に向けて準備している。  

・relevance  
定義: ある問題・状況と関係があること。  
頻度: 〈7/10〉  
違い: この語義の「当てはまり」に近いが、関連することを広く表し、規則を実際に運用する行為は指さない。  
例: The example has little relevance to our discussion.  
訳: その例は、私たちの議論とほとんど関係がない。  

5. 【名詞・可算】アプリケーション・アプリ

【日本語訳・定義】文書作成、表計算、画像編集など、特定の作業や目的のために使うソフトウェア。一つのプログラムやソフトウェア製品として数える。スマートフォン専用という意味ではなく、パソコンやウェブ上で使うものも含む。  

【頻度】〈8/10〉  

【レジスター/領域】コンピューター、業務システム、一般のデジタル機器利用。  

【文法パターン】run an application＝アプリを実行する／launch an application＝アプリを起動する／install an application＝アプリをインストールする／a web application＝ウェブを通じて使うアプリ／an application for doing something＝ある作業をするためのアプリ  

【コロケーション・構文例】

・run an application  
用途: アプリを動作させることを述べる。  
例: This computer can run several applications at once.  
訳: このパソコンは複数のアプリを同時に実行できる。  

・launch an application  
用途: 起動という動作に焦点を当てる。  
例: Click the icon to launch the application.  
訳: アイコンをクリックしてアプリを起動してください。  

・install an application  
用途: 利用する端末にアプリを導入する。  
例: I installed an application for editing audio files.  
訳: 私は音声ファイルを編集するアプリをインストールした。  

・a web application  
用途: ブラウザーなどを通して使う種類のアプリを指す。  
例: We track requests through a web application.  
訳: 私たちはウェブアプリで依頼の処理状況を管理している。  

・an application for doing something  
用途: アプリの用途を動名詞で示す。  
例: They developed an application for organizing digital photographs.  
訳: 彼らはデジタル写真を整理するアプリを開発した。  

【語法・注意】an application、two applications と数えるが、software は通常不可算で、an application に対応するのは a piece of software などの形。open an application はアプリを開くこと、open an application form は申請フォームを開くことなので、後ろの語も読む。an application for editing は編集用アプリ、an application to edit the journal は雑誌の編集を担当するための応募などになり得る。日常の app はこのソフトウェア義で広く使う。ただし米語のくだけた文脈では college apps「大学への出願書類」のように、申請書・応募書類を略すこともある。正式な申請案内では略さず application と書くほうが明確である。  

【類義語】

・program  
定義: コンピューターに処理を行わせる命令のまとまり。  
頻度: 〈9/10〉  
違い: 利用者向けの作業アプリ以外にも広く使う。コンピューター義では英語圏の英国系でも通常 program と綴る。  
例: The program sorts the records by date.  
訳: そのプログラムは記録を日付順に並べ替える。  

・software  
定義: コンピューターで使うプログラムなどをまとめて指す語。  
頻度: 〈9/10〉  
違い: 不可算名詞で、application のようにそのまま一個・二個と数えない。アプリやシステム用のソフトを広く含む。  
例: The software supports several file formats.  
訳: そのソフトウェアは複数のファイル形式に対応している。  

6. 【名詞・可算/不可算】塗布・散布・作用させること

【日本語訳・定義】塗料、クリームなどを表面に塗ったり、物質を対象へ施したりすること。また、熱や圧力などを対象に加えて作用させること。行為全体は不可算、個々の回数・処置を区切れば可算になる。  

【頻度】〈6/10〉  

【レジスター/領域】製品の説明、塗装、化粧品、製造、技術。医療でも使うが、語自体は使用量や治療効果を定めない。  

【文法パターン】the application of something to 〈表面・対象〉＝物質・力などを対象へ施すこと／repeated applications of something＝物質などを繰り返し施すこと／for external application＝外側・皮膚などに用いるための／the application of heat＝熱を加えること／the application of pressure＝圧力を加えること  

【コロケーション・構文例】

・the application of something to 〈表面・対象〉  
用途: 塗布する物と塗布先を示す。  
例: The diagram shows the application of adhesive to the panel.  
訳: 図は、パネルに接着剤を塗る工程を示している。  

・repeated applications of something  
用途: 一度ずつの塗布・散布を複数回として捉える。  
例: Repeated applications of polish restored the shine.  
訳: 磨き剤を繰り返し塗ることで、つやが戻った。  

・for external application  
用途: 製品が体の外側に使うものだと示す表示を読む。  
例: The bottle is labeled "For external application only."  
訳: そのボトルには「外用に限る」と表示されている。  

・the application of heat  
用途: 製造などで熱を加えることを述べる。  
例: The application of heat softens the plastic sheet.  
訳: 熱を加えると、そのプラスチックのシートは軟らかくなる。  

・the application of pressure  
用途: 対象に圧力を加える動作を述べる。  
例: The application of pressure holds the layers together while the glue dries.  
訳: 接着剤が乾く間、圧力を加えることで各層を密着させておく。  

【語法・注意】application of paint の of は塗る物、application to wood の to は塗る先を示す。two applications は「2回の塗布」などで、量が2単位という意味とは限らない。application of heat は熱の応用分野ではなく、文脈によって「加熱」を表す。external application は外用という使い方の表示であり、特定の量・頻度や安全性まで含意しない。薬剤や化粧品の適切な使い方は、その製品の指示を別に確認する。塗られた物質・層そのものを指す用法は語義8に分ける。  

【類義語】

・coating  
定義: 表面を層で覆うこと、またはその層。  
頻度: 〈7/10〉  
違い: この語義の application は塗る行為・回数が中心。coating は表面を覆う行為と完成した膜の両方を表し、application にも層・物質を指す別の用法がある。熱や圧力を加える用法には置き換えない。  
例: The metal has a protective coating.  
訳: その金属には保護用の被膜がある。  

・spreading  
定義: 物を表面などに広げること。  
頻度: 〈6/10〉  
違い: 広げ方・動作に焦点がある。application は塗布・散布をより広く表し、単に載せる場合にも使う。  
例: Even spreading of the paste prevents thick patches.  
訳: ペーストを均一に広げると、厚みのある部分ができるのを防げる。  

7. 【名詞・不可算】専念・勤勉な努力

【日本語訳・定義】仕事や学習に注意を集中し、根気よく取り組むこと。単に何かを試すだけでなく、課題へ継続して力を注ぐ姿勢を表す。能力や才能そのものとは区別される。  

【頻度】〈4/10〉  

【レジスター/領域】改まった文章、人物評価、学習・仕事への取り組み。  

【文法パターン】application to 〈仕事・学習〉＝仕事・学習への専念／with application＝熱心に取り組んで／require application＝根気強い努力を必要とする／a lack of application＝取り組む熱意・努力の不足  

【コロケーション・構文例】

・application to 〈仕事・学習〉  
用途: 努力を集中させる対象を示す。  
例: Her steady application to her studies impressed her tutors.  
訳: 学業にこつこつ取り組む彼女の姿勢は、指導教員たちに感銘を与えた。  

・with application  
用途: 努力を続けることが上達などにつながると述べる。  
例: With application, you can master the basic techniques.  
訳: 熱心に取り組めば、基本的な技法を身に付けられます。  

・require application  
用途: 才能や興味だけでなく、継続的な努力が要ると述べる。  
例: Learning to play the instrument requires patience and application.  
訳: その楽器の演奏を習得するには、忍耐とひたむきな努力が必要だ。  

・a lack of application  
用途: 課題への取り組みが十分でないことを指摘する。  
例: The trainer attributed the poor results to a lack of application.  
訳: トレーナーは、成績が振るわなかった原因を、十分に努力していなかったことだとした。  

【語法・注意】この意味では不可算で、普通 an application や applications と数えない。application to her work は「仕事への専念」で、job application「仕事への応募」ではない。特に diligence、patience、talent などとの並列・対比が手掛かりになる。動詞なら apply oneself to something で、本人が力を注ぐことを再帰代名詞で表す。名詞 application 自体に再帰代名詞を付ける必要はない。  

【類義語】

・diligence  
定義: 注意深く、まじめに努力を続けること。  
頻度: 〈5/10〉  
違い: 仕事を丁寧かつ着実にこなす姿勢を強く表す。application は注意と力を課題に向けることに焦点がある。  
例: The task was completed with great diligence.  
訳: その作業は非常に丁寧かつ勤勉に進められ、完了した。  

・concentration  
定義: 注意を一つの対象に集中すること。  
頻度: 〈8/10〉  
違い: 注意の向け方が中心で、長期に努力を続けることまでは含まない。application は根気よい取り組みを表しやすい。  
例: Checking these figures demands concentration.  
訳: これらの数字を確認するには集中力が必要だ。  

・dedication  
定義: 大切だと考える仕事・活動などに力を注ぐこと。  
頻度: 〈7/10〉  
違い: 対象への献身や強い思いを含みやすい。application は課題に熱心に取り組む実際の姿勢を述べる。  
例: Her dedication to teaching has never faded.  
訳: 教育に力を尽くす彼女の姿勢は、ずっと変わっていない。  

8. 【名詞・可算】塗られた層・塗布する物質

【日本語訳・定義】表面や体に施す物質、または塗った結果できた層。塗料、保護剤、外用剤などについて使い、塗る動作や回数を指す語義6とは焦点が異なる。  

【頻度】〈3/10〉  

【レジスター/領域】塗装、製品・処置の説明。一般には layer、coating や物質自体の名前のほうが明確な場合が多い。  

【文法パターン】a thick application of something＝厚く塗られた物質の層  

【コロケーション・構文例】

・a thick application of something  
用途: 塗られた物質の層を、その厚さとともに示す。  
例: A thick application of paint had begun to crack.  
訳: 厚く塗られた塗料の層に、ひびが入り始めていた。  

【語法・注意】application が crack「ひび割れる」などの主語になるときは、塗る行為ではなく塗られた物質・層を指す。a second application が塗布の2回目を指す場合とは区別する。外用剤そのものを指す用法もあるが、application だけでは成分、適応、効能は分からない。  

【類義語】

・coating  
定義: 物の表面を覆っている層。  
頻度: 〈7/10〉  
違い: 表面を覆う膜であることが明確。application は施した物質に焦点があり、別義では塗布の行為にもなる。  
例: A clear coating protects the printed surface.  
訳: 透明な被膜が印刷面を保護している。
