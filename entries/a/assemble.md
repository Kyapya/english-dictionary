＃発音記号

米・英: /əˈsem.bəl/。3音節で、第2音節に主強勢がある。第1・第3音節の母音は弱い /ə/、第2音節は /e/。assembled は /əˈsem.bəld/ で、-ed を独立した音節にしない。assembling は /əˈsem.blɪŋ/ のように発音できる。  

＃語源

中英語・古フランス語を経て、ラテン語 simul「一緒に」に関連する俗ラテン語の動詞にさかのぼる。「ばらばらのものが一緒になる」という語源上の意味が、集合・収集・組立につながる。同じ simul の系統に simultaneous「同時の」、ensemble「合奏団・まとまり」がある。  

＃語形成

・assembles：三人称単数現在形。  
・assembled：過去形・過去分詞。an assembled crowd は集まった群衆、a fully assembled desk は組立済みの机。  
・assembling：現在分詞・動名詞。末尾の e を落として -ing を付ける。  
・assembly：組立作業、組み立てたユニット、集会・議会などを表す名詞。  
・assembler：組立工、またはアセンブリ言語を機械語側のコードへ変換するプログラム。  
・reassemble：再び集める・集まる、または組み立て直す。  
・disassemble：機械などを分解する。dissemble「本心を隠す」とは別の語。  
・self-assemble：部品や分子などが自ら組み合わさる。特に科学・技術で使う。  

＃コアイメージ

核は「別々の要素を集めて、ひとまとまりにする・なる」。人や資料の集合と、部品を合わせる組立を区別する。情報処理では、記号的な命令を機械向けのコードへ組み上げる専門用法がある。  

・部品を集めて製品にする行為 → 「組み立てる」（語義1）  

・人や情報を集めてまとまりにする行為 → 「集める・取りまとめる」（語義2）  

・人々が集まってまとまりになる動き → 「集まる・集合する」（語義3）  

・記号的な命令を機械向けに組み上げる処理 → 「アセンブルする」（語義4）  

＃意味・用法・関連表現

1. 【動詞・他動詞】組み立てる

【日本語訳・定義】部品を適切につなぎ合わせ、製品・装置・構造などを作る。目的語には完成品と、組み合わせる部品のどちらも置ける。部品自体を製造することや、設置場所で使える状態にすることまでは必ずしも含まない。  

【頻度】〈8/10〉  

【レジスター/領域】一般・製造・家具・機器  

【文法パターン】assemble 〈製品〉＝製品を組み立てる／assemble 〈部品〉 into 〈完成物〉＝部品を組み合わせて完成物にする／assemble 〈製品〉 from 〈部品〉＝部品から製品を組み立てる／be assembled by 〈作業者〉＝その作業者によって組み立てられる／a fully assembled 〈製品〉＝完全に組立済みの製品  

【コロケーション・構文例】

・assemble 〈製品〉  
用途: 完成物を目的語にする。  
例: It took us an hour to assemble the desk.  
訳: 私たちがその机を組み立てるのに1時間かかった。  

・assemble 〈部品〉 into 〈完成物〉  
用途: 部品と完成後の形を区別する。  
例: The technicians assembled the components into a working prototype.  
訳: 技術者たちは、その部品を組み合わせて動作する試作品を作った。  

・assemble 〈製品〉 from 〈部品〉  
用途: 組立に用いる材料・部品を示す。  
例: The robots assemble the units from prefabricated parts.  
訳: そのロボットは、あらかじめ製作された部品からユニットを組み立てる。  

・be assembled by 〈作業者〉  
用途: 製品を主語にした受動態を使う。  
例: Each pump is assembled by a trained technician.  
訳: ポンプは1台ずつ、訓練を受けた技術者によって組み立てられる。  

・a fully assembled 〈製品〉  
用途: 過去分詞で組立済みの状態を修飾する。  
例: We ordered a fully assembled cabinet.  
訳: 私たちは、完全に組立済みのキャビネットを注文した。  

【語法・注意】assemble a chair と assemble the parts into a chair は、目的語が完成品か部品かという違い。assemble は「部品を並べるだけ」ではなく、組み合わせる動作を表す。ただし was assembling や tried to assemble なら、完成したことまでは断定できない。assembled parts、The unit is assembled. の assembled は組立という動作・結果に基づく分詞用法である。very assembled とは通常いわず、fully、partly、already などで完成度や時点を表す。get assembled は「組み立てられる」、seem fully assembled は「組立済みに見える」となる。  

【類義語】

・put together  
定義: 部品などを組み合わせて作る。  
頻度: 〈9/10〉  
違い: assemble より日常的な表現。代名詞目的語は put it together と小辞の前に置く。  
例: Can you help me put it together?  
訳: これを組み立てるのを手伝ってもらえますか。  

・build  
定義: 構造物・製品などを作り上げる。  
頻度: 〈9/10〉  
違い: assemble は部品の接合に焦点がある。build は設計・加工を含む製作全体にも使える。  
例: They built the shelves from recycled wood.  
訳: 彼らは再利用した木材で棚を作った。  

・construct  
定義: 構造物や装置を計画的に作り上げる。  
頻度: 〈8/10〉  
違い: assemble より製作・建設全体に焦点を置き、形式的な響きがある。  
例: The team constructed a small testing platform.  
訳: そのチームは、小型の試験台を製作した。  

【反意語】

・disassemble  
定義: 組み合わさった物を部品に分ける。  
頻度: 〈6/10〉  
違い: assemble と、部品をまとめる方向・分ける方向で対立する。  
例: Disassemble the frame before moving it.  
訳: 移動する前にフレームを分解してください。  

・take apart  
定義: 物をばらして構成部分に分ける。  
頻度: 〈8/10〉  
違い: assemble の逆方向の動作を日常的にいう。  
例: She took the printer apart to inspect the rollers.  
訳: 彼女はローラーを調べるため、プリンターを分解した。  

2. 【動詞・他動詞】集める・取りまとめる

【日本語訳・定義】人・物・情報などを、ある場所や目的のもとに集めてまとまりにする。チームを編成する、資料・証拠を集めるといった用法がある。目的をもった収集に使われやすいが、集めたものが十分であることや成果を出したことまでは保証しない。  

【頻度】〈8/10〉  

【レジスター/領域】一般・業務・研究・報道  

【文法パターン】assemble a team＝チームを集めて編成する／assemble 〈人々〉 in 〈場所〉＝人々をその場所に集める／assemble 〈資料〉 for 〈目的〉＝その目的のために資料を集める／assemble 〈材料〉 into 〈まとまり〉＝材料を集めてそのまとまりにする／be assembled from 〈情報源〉＝その情報源から集められる  

【コロケーション・構文例】

・assemble a team  
用途: 必要なメンバーを集める。  
例: The director assembled a team of engineers and designers.  
訳: 責任者は、技術者とデザイナーからなるチームを編成した。  

・assemble 〈人々〉 in 〈場所〉  
用途: 人を集める側を主語にする。  
例: The guide assembled the visitors in the lobby.  
訳: ガイドは訪問者をロビーに集めた。  

・assemble 〈資料〉 for 〈目的〉  
用途: 情報・資料の収集を表す。  
例: She assembled the data for the annual report.  
訳: 彼女は年次報告書のためにデータを集めた。  

・assemble 〈材料〉 into 〈まとまり〉  
用途: 収集物をまとめた結果を示す。  
例: The editor assembled the interviews into a book.  
訳: 編集者は、そのインタビューを集めて1冊の本にまとめた。  

・be assembled from 〈情報源〉  
用途: 複数の出所からの収集を受動態で述べる。  
例: The evidence was assembled from several independent sources.  
訳: その証拠は、互いに独立した複数の情報源から集められた。  

【語法・注意】人が目的語でも「人を組み立てる」とせず、集める・編成すると読む。assemble data、assemble evidence は不可算名詞を目的語にできる。The manager assembled the staff. では manager が人を集める側、The staff assembled. は語義3で職員自身が集まる側。the assembled guests「集まった客たち」の assembled は集合後の状態を示す分詞的修飾で、性格の評価などは加わらない。assemble oneself を一般的な「集合する」の必須形として覚える必要はない。  

【類義語】

・gather  
定義: 散在する人・物・情報を集める。  
頻度: 〈9/10〉  
違い: assemble より広く日常的で、組織的なまとまりを作ることを強調しない。  
例: We gathered comments from all departments.  
訳: 私たちは、全部門から意見を集めた。  

・collect  
定義: 物や情報を集めて保有・整理する。  
頻度: 〈9/10〉  
違い: assemble は集めて1つのまとまりを作る側面が強い。collect は継続的な収集や回収にも使う。  
例: The researcher collected samples from five locations.  
訳: その研究者は、5か所から試料を採取した。  

・compile  
定義: 資料を集め、一覧や文書などにまとめる。  
頻度: 〈7/10〉  
違い: assemble は人や物にも使える。compile は情報を集めて利用できる形に整理することに焦点がある。  
例: We compiled a list of approved suppliers.  
訳: 私たちは、承認済みの納入業者の一覧を作成した。  

・convene  
定義: 会議や人々を公式に招集する。  
頻度: 〈6/10〉  
違い: assemble は資料や物も集められる。convene は会議・委員会などを集めて開く場面に限定されやすい。  
例: The chair convened an emergency meeting.  
訳: 議長は緊急会議を招集した。  

【反意語】

・disperse  
定義: 人々などを散らす・解散させる。  
頻度: 〈6/10〉  
違い: 人々を1か所へ集める assemble に対し、複数の場所へ散らす方向の対立。  
例: The police dispersed the crowd.  
訳: 警察は群衆を解散させた。  

3. 【動詞・自動詞】集まる・集合する

【日本語訳・定義】人々がある場所に集まり、1つの集団になる。会議・式典・集合指示などで使われる。特定の目的のためであることが多いが、正式な会議に限らない。  

【頻度】〈7/10〉  

【レジスター/領域】一般・やや形式的・案内・報道  

【文法パターン】assemble in 〈部屋・区域〉＝その部屋・区域に集まる／assemble at 〈集合地点〉＝その地点に集合する／assemble for 〈行事〉＝その行事のために集まる／assemble to 〈動詞〉＝その動作をするために集まる／assemble in front of 〈建物〉＝その建物の前に集まる  

【コロケーション・構文例】

・assemble in 〈部屋〉  
用途: 集まる人々を主語にする。  
例: The delegates assembled in the conference room.  
訳: 代表者たちは会議室に集まった。  

・assemble at 〈集合地点〉  
用途: 集合場所を点として示す。  
例: Please assemble at the main entrance at nine.  
訳: 9時に正面入口に集合してください。  

・assemble for 〈行事〉  
用途: 集まる目的の行事を示す。  
例: The employees assembled for the safety briefing.  
訳: 従業員たちは、安全説明会のために集まった。  

・assemble to 〈動詞〉  
用途: 集まって何をするかを示す。  
例: The residents assembled to discuss the proposal.  
訳: 住民たちは、その提案を話し合うために集まった。  

・assemble in front of 〈建物〉  
用途: 集合する位置を述べる。  
例: A crowd assembled in front of the station.  
訳: 駅前に群衆が集まった。  

【語法・注意】自動詞なので、場所を直接目的語にして assemble the lobby「ロビーに集まる」とはしない。assemble in the lobby とする。他動詞の assemble the visitors「訪問者を集める」と区別する。The visitors assembled. は能動の集合、The visitors were assembled by the guide. はガイドが集めた受動で、動作主の情報が異なる。We are assembled here. は集まっている状態としても読める。通常の現在の予定なら We will assemble here.。together を添えることもあるが、集合という意味は assemble だけで含む。  

【類義語】

・gather  
定義: 人々が集まる。  
頻度: 〈9/10〉  
違い: assemble より日常的で、自然発生的な集合にも広く使う。  
例: People gathered near the fountain.  
訳: 人々が噴水の近くに集まった。  

・meet  
定義: 人々が会う・会合する。  
頻度: 〈10/10〉  
違い: assemble は人々が集合する動きに焦点がある。meet は少人数の待合せや交流にも広く使う。  
例: We will meet at the café at noon.  
訳: 私たちは正午にそのカフェで会う。  

・congregate  
定義: 多くの人々が同じ場所に集まる。  
頻度: 〈5/10〉  
違い: assemble より群がる様子を描きやすく、公式な集合指示に限られない。  
例: Fans congregated outside the arena.  
訳: ファンたちは会場の外に集まった。  

・convene  
定義: 会議や委員会が正式に集まる・開かれる。  
頻度: 〈6/10〉  
違い: assemble より、公式の会議・会合の開始に焦点がある。  
例: The committee will convene on Monday.  
訳: 委員会は月曜日に開かれる。  

【反意語】

・disperse  
定義: 集まっていた人々が散る。  
頻度: 〈6/10〉  
違い: 集まる方向に対する、散って離れる方向の反対語。  
例: The crowd dispersed after the announcement.  
訳: 発表後、群衆は散っていった。  

・scatter  
定義: 人々や物がばらばらに散る。  
頻度: 〈7/10〉  
違い: assemble がひとまとまりになるのに対し、scatter は各方向へ分かれる動きを強調する。  
例: The players scattered across the field.  
訳: 選手たちはフィールドの各所へ散らばった。  

4. 【動詞・他動詞】アセンブルする

【日本語訳・定義】アセンブリ言語の命令やソースコードを、アセンブラーで機械語側のコードに変換する。通常はオブジェクトファイルなどを生成する工程で、プログラムを実行することとは異なる。  

【頻度】〈3/10〉  

【レジスター/領域】情報処理・プログラミング  

【文法パターン】assemble 〈ソースファイル〉＝ソースファイルをアセンブルする／assemble 〈命令〉 into machine code＝命令を機械語に変換する／be assembled into an object file＝オブジェクトファイルにアセンブルされる  

【コロケーション・構文例】

・assemble 〈ソースファイル〉  
用途: アセンブラーで変換処理を行う。  
例: Use the assembler to assemble the source file.  
訳: アセンブラーを使って、そのソースファイルをアセンブルしてください。  

・assemble 〈命令〉 into machine code  
用途: 入力と出力の種類を明示する。  
例: The tool assembles these symbolic instructions into machine code.  
訳: そのツールは、これらの記号的な命令を機械語に変換する。  

・be assembled into an object file  
用途: 変換結果がファイルになる工程を表す。  
例: The source was assembled into an object file before linking.  
訳: リンクの前に、そのソースはオブジェクトファイルにアセンブルされた。  

【語法・注意】目的語が program や code のときは、単に複数の資料を「取りまとめる」語義2か、アセンブラーによる変換かを確認する。compile は一般に高水準言語などの翻訳工程にも広く使われ、assemble はアセンブリ言語からの変換を特定する。link「リンクする」と run「実行する」は別の工程であり、assemble だけで実行済みとは言えない。  

【類義語】

・translate  
定義: プログラムや命令を別の言語・表現へ変換する。  
頻度: 〈5/10〉  
違い: assemble は入力がアセンブリ言語である特定の翻訳処理。translate はその上位の一般的な説明語。  
例: The compiler translates source code into another representation.  
訳: そのコンパイラーは、ソースコードを別の表現に変換する。  

【反意語】

・disassemble  
定義: 機械語側のコードをアセンブリ言語の表現に戻す。  
頻度: 〈3/10〉  
違い: コード変換の方向が反対。ただし、元のコメントや変数名まで完全に復元することを意味しない。  
例: The debugger can disassemble the machine code.  
訳: そのデバッガーは、機械語を逆アセンブルできる。
