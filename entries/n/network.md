＃発音記号

米: /ˈnet.wɝːk/｜英: /ˈnet.wɜːk/  

・2音節で、第1音節の /e/ に強勢がある。米英の違いは第2音節で、米音 /wɝːk/ は r 音を伴う母音、ここに示す英音 /wɜːk/ は r 音を伴わない母音である。  

・名詞・動詞で強勢位置は変わらない。networks の語尾は /s/、networked の語尾は /t/。networking は network に /ɪŋ/ が続く3音節で、強勢は第1音節のまま。  

＃語源

net「網」と work「作られたもの、細工」の複合語。もとは糸や線を交差させた網状の作りを指し、道路・通信線・組織・人間関係など、複数の要素が結び付く仕組みに広がった。動詞は名詞からの品詞転換で、ネットワークを作る・利用する行為を表す。  

・netting「網、網地」は net の語族で、物理的な網の材料を指す。  

・netted「網目状の、網で覆われた」も net からの形。network の「つながり」の意味を、そのまま人脈形成の動詞として置き換えられる語ではない。  

＃語形成

・networker：可算名詞で「人脈作りをする人」。a skilled networker は人と関係を築くのが上手な人を指す。  

・networked：過去分詞、および「ネットワークで結ばれた」を表す分詞形容詞。networked devices のように名詞の前でも使う。単独の networked にハイフンは不要。  

・networking：動詞の現在分詞のほか、不可算名詞で「人脈形成」または「コンピューターネットワークの構築・運用」。語義7・9で区別する。  

・network effect：利用者などが増えるにつれて、そのネットワークの価値・利便性が変わる効果。ビジネスでは価値が高まる効果を指すことが多い。  

＃コアイメージ

複数の要素がつながり、または交差して、網状の全体を形作ること。名詞ではそのつながり・構造を、動詞や networking ではつながりを作る・活用することを表す。  

・機器のつながりによる情報交換の仕組み → 「通信網、コンピューターネットワーク」（語義1）  

・経路や線状の要素のつながり・交差 → 「網状の系統・模様、路線網」（語義2）  

・人や組織のつながりによる仕組み → 「人脈、人的・組織的ネットワーク」（語義3）  

・放送局のつながりによる番組供給の仕組み → 「放送網、放送ネットワーク」（語義4）  

・利用者のつながりを提供する仕組み → 「交流サイト、ソーシャルネットワーク」（語義5）  

・仕事に役立つ人のつながりを作る行為 → 「人脈を築く」（語義6）  

・仕事に役立つ人のつながり作りという活動 → 「人脈形成、交流活動」（語義7）  

・機器のつながりを作る行為 → 「機器をネットワーク接続する」（語義8）  

・機器のつながりを作り運用する技術・活動 → 「ネットワークの構築・運用」（語義9）  

・同じ背景を持つ男性のつながりによる互助 → 「同窓・身内の男性人脈」（語義10）  

・放送局のつながりを使う番組送出 → 「系列局で同時放送する」（語義11）  

・糸や線のつながりによる網状の作り → 「網細工、網地」（語義12）  

＃意味・用法・関連表現

1. 【名詞・可算】通信網、コンピューターネットワーク

【日本語訳・定義】複数のコンピューター、電話、周辺機器などが接続され、情報のやり取りや資源の共有ができる仕組み。有線・無線のどちらも含み、小さな家庭内の網から広域の通信網までを指す。  

【頻度】〈8/10〉  

【レジスター/領域】日常、通信、情報技術。  

【文法パターン】a 〈computer/wireless/mobile〉 network＝機器・方式を示す名詞句／a network of 〈複数の機器〉＝構成要素／on the network＝その網に接続されて／over/across a network＝網を通じて／access to the network＝網へのアクセス／a network connection＝ネットワーク接続。  

【コロケーション・構文例】

・a wireless network  
用途: 無線で接続する通信網を指す。  
例: The hotel has a separate wireless network for guests.  
訳: そのホテルには宿泊客用の独立した無線ネットワークがある。  

・a mobile network  
用途: 携帯電話の通信網を指す。  
例: The mobile network was overloaded after the concert.  
訳: コンサートのあと、携帯電話の通信網は混雑していた。  

・a network of 〈複数の機器〉  
用途: どの機器でネットワークを構成しているかを示す。  
例: The laboratory uses a network of sensors to monitor temperature.  
訳: その研究所は、温度を監視するためにセンサーのネットワークを利用している。  

・on the network  
用途: 機器がネットワークの一部として接続されていることを示す。  
例: Every printer on the network has a different name.  
訳: ネットワーク上のプリンターには、それぞれ別の名前が付いている。  

・over a network  
用途: データなどの移動にネットワークを利用することを示す。  
例: The files are transferred over a secure network.  
訳: ファイルは安全なネットワークを通じて転送される。  

・access to the network  
用途: 接続できること、またはその権限を指す。  
例: Visitors do not have access to the internal network.  
訳: 来訪者は内部ネットワークにアクセスできない。  

・a network connection  
用途: 機器と通信網の接続状態・接続手段を指す。  
例: The application needs a stable network connection.  
訳: そのアプリを使うには、安定したネットワーク接続が必要だ。  

【語法・注意】a network、several networks と数え、特定の網なら the network とする。connect to a network は「接続する」で、名詞には通常冠詞などの限定詞が必要。network と the internet は同義ではなく、外部インターネットにつながっていないネットワークもある。Wi-Fi は無線接続の方式であり、network 全体の言い換えではない。LAN は local area network、WAN は wide area network の略。  

【類義語】

・communications system  
定義: 情報を送受信するための設備・仕組み。  
頻度: 〈6/10〉  
違い: 端末や運用全体に重点があり、必ずしも網状につながる構造を強調しない。network は要素どうしの接続に焦点がある。  
例: The storm damaged the island's communications system.  
訳: 嵐で島の通信システムが損傷した。  

・LAN  
定義: 建物や施設などの比較的限られた範囲のコンピューターネットワーク。  
頻度: 〈5/10〉  
違い: network の一種を範囲によって限定する語。広域網まで含む network 全般とは同義ではない。  
例: The new printers are connected to the office LAN.  
訳: 新しいプリンターはオフィスのLANにつながっている。  

2. 【名詞・可算】網状の系統・模様、路線網

【日本語訳・定義】道、線、管、神経などがつながる系統や、ひびなどが交差してできる網状の模様。また、そのような構造に見立てた関係・依存関係の体系。すべての要素がすべてのほかの要素に直接つながっている必要はない。  

【頻度】〈8/10〉  

【レジスター/領域】一般、交通、地理、生物、科学、分析。  

【文法パターン】a 〈road/rail/transport〉 network＝交通の網／a network of 〈複数の経路・要素〉＝構成要素／a network of fine cracks＝細かいひびが網状に広がる模様／an extensive network＝広範な網／through the network＝その網を通じて／a neural network＝神経の網、またはそれを模した計算モデル。  

【コロケーション・構文例】

・a road network  
用途: 道路がつながってできる体系を指す。  
例: The region's road network links even the smallest villages.  
訳: その地域の道路網は、最も小さな村々にも通じている。  

・a rail network  
用途: 鉄道の路線全体を指す。  
例: The city is expanding its rail network into the northern suburbs.  
訳: その都市は鉄道網を北部の郊外へ拡張している。  

・a network of tunnels  
用途: 多数のトンネルがつながる構造を指す。  
例: The old mine contains a network of narrow tunnels.  
訳: その古い鉱山には、狭い坑道が網の目のように張り巡らされている。  

・a network of blood vessels  
用途: 血管が枝分かれしてつながる系統を指す。  
例: A dense network of blood vessels supplies the tissue with oxygen.  
訳: 密な血管網が、その組織に酸素を供給している。  

・a network of fine cracks  
用途: ひびがつながり・交差してできた網状の模様を指す。  
例: A network of fine cracks had formed in the vase's glaze.  
訳: 花瓶の釉薬には、細かいひびが網の目のように入っていた。  

・a network of relationships  
用途: 多くの関係が相互につながる抽象的な構造を指す。  
例: The diagram shows a network of relationships between the variables.  
訳: その図は、変数間の関係が網状につながる様子を示している。  

・a neural network  
用途: 特に情報科学では、結び付いた処理単位から成る計算モデルを指す。  
例: The researchers trained a neural network to recognize handwritten digits.  
訳: 研究者たちは、手書きの数字を認識するようニューラルネットワークを学習させた。  

【語法・注意】a network of roads の of は「網を構成する要素」を示す。a road network とほぼ同じ内容を表せる。network は複雑さを連想させることがあるが、複雑であること自体が必須条件ではない。a network of cracks のように形だけを述べることもあり、全体が何らかの機能を果たすとは限らない。数学や情報科学では点とその接続関係を network と呼ぶこともあり、必ずしも実在の道路や線ではない。人工の neural network は、単にコンピューターを通信線でつないだ語義1の網とは違う。  

【類義語】

・system  
定義: 複数の部分が関係し合って働く体系。  
頻度: 〈9/10〉  
違い: 規則・組織・手順の体系も含む広い語。network は各部分の間の接続に重点がある。  
例: The town needs a better drainage system.  
訳: その町には、もっとよい排水システムが必要だ。  

・grid  
定義: 線が交差する格子状の構造、または送電などの接続網。  
頻度: 〈6/10〉  
違い: 格子の配置や電力網を連想しやすい。network は不規則な道路網・生物の系統にも自然に使う。  
例: The streets form a simple grid.  
訳: その街路は単純な格子状になっている。  

・web  
定義: 多数の要素が複雑に絡み合った構造・関係。  
頻度: 〈6/10〉  
違い: 複雑な絡まりや抜け出しにくさを含みやすい。network は機能的な接続を中立に述べる場合にもよく使う。  
例: The investigation revealed a web of financial links.  
訳: 調査で、複雑に絡み合う資金面のつながりが明らかになった。  

3. 【名詞・可算】人脈、人的・組織的ネットワーク

【日本語訳・定義】情報、支援、仕事などのやり取りでつながる人・組織の集まりや関係。個人の知人関係だけでなく、支援者、研究機関、販売店、拠点などの連携も指す。非公式なつながりにも、組織された仕組みにも使える。  

【頻度】〈8/10〉  

【レジスター/領域】日常、仕事、社会、組織。  

【文法パターン】a network of 〈複数の人・組織〉＝構成員／a 〈support/professional/distribution〉 network＝目的・役割を示す名詞句／someone's network＝その人の人脈／in someone's network＝その人脈の中に／a network for 〈対象者〉＝特定の人々のための連携組織。  

【コロケーション・構文例】

・a network of contacts  
用途: 仕事や情報収集で連絡を取れる知人のつながりを指す。  
例: She has built a wide network of contacts in the publishing industry.  
訳: 彼女は出版業界に幅広い人脈を築いてきた。  

・a support network  
用途: 困ったときに助け合える人々のつながりを指す。  
例: Friends and neighbors became an important support network after the move.  
訳: 引っ越しのあと、友人や近所の人々が大切な支えとなった。  

・a distribution network  
用途: 商品などを各地へ届ける拠点・業者のつながりを指す。  
例: The company relies on a distribution network of local dealers.  
訳: その会社は地元の販売店から成る流通網を利用している。  

・in someone's network  
用途: ある人の知人・協力者の範囲に入ることを示す。  
例: Is there anyone in your network who knows about publishing contracts?  
訳: 出版契約に詳しい人が、あなたの知り合いにいますか。  

・a network for 〈対象者〉  
用途: 特定の立場の人の連携・支援を目的とする組織を指す。  
例: They set up a network for independent researchers.  
訳: 彼らは独立研究者のためのネットワークを作った。  

・a social network  
用途: インターネットに限定せず、社会的な人間関係のつながりを指す。  
例: After retirement, his social network extended well beyond his former colleagues.  
訳: 退職後、彼の交友関係は元同僚の範囲をはるかに超えて広がった。  

【語法・注意】build a network は「人脈・連携を作る」、expand one's network は「人脈を広げる」。個々の知人は a contact であり、a network はつながりの全体を指す。an extensive network の存在は、構成員全員が互いを直接知っていることを意味しない。social network はこの人的なつながりのほか、交流サイト自体も指す（語義5）。old-boy network は身内優遇の含みがある別の定型表現（語義10）。  

【類義語】

・contacts  
定義: 情報や仕事上の助けを得るために連絡できる知人たち。  
頻度: 〈8/10〉  
違い: 個々の人に焦点がある。network はその人々の間のつながりや全体の仕組みに焦点を置く。  
例: Her contacts helped her find a reliable translator.  
訳: 彼女は知人たちの助けで、信頼できる翻訳者を見つけた。  

・circle  
定義: 共通の関心や親交で結び付いた人の集まり。  
頻度: 〈7/10〉  
違い: 友人・同好の人など、ある程度まとまった範囲を連想しやすい。network は複数の集団にまたがる広いつながりにも使う。  
例: He has a small circle of close friends.  
訳: 彼には少数の親しい友人がいる。  

・community  
定義: 共通の関心・活動・所属などを持つ人々の集団。  
頻度: 〈8/10〉  
違い: 共有意識や帰属を強調しやすい。network は情報・支援の交換という接続関係を中心に述べられる。  
例: The online community welcomes new members.  
訳: そのオンラインのコミュニティーは、新しい参加者を歓迎している。  

4. 【名詞・可算】放送網、放送ネットワーク

【日本語訳・定義】複数地域の放送局へ番組を供給するテレビ・ラジオの組織・系列。また、その番組を制作・供給する放送会社。現代のメディア用語では、広域に提供されるケーブル放送のサービスなども network と呼ばれる。  

【頻度】〈7/10〉  

【レジスター/領域】放送、メディア。特に米国の放送会社・系列についてよく使う。  

【文法パターン】a television network、a radio network＝テレビ・ラジオの放送網／a cable network＝ケーブル放送のネットワーク／on a network＝その放送網で／a network of radio stations＝放送局の系列／network television、network news＝系列局向けのテレビ放送・ニュース。  

【コロケーション・構文例】

・a television network  
用途: 広域に番組を供給するテレビ会社・系列を指す。  
例: Several television networks bid for the rights to the series.  
訳: 複数のテレビネットワークが、そのシリーズの放送権獲得に名乗りを上げた。  

・a network of radio stations  
用途: 複数のラジオ局から成る系列を指す。  
例: The program reaches listeners through a network of local radio stations.  
訳: その番組は、地方ラジオ局のネットワークを通じてリスナーに届く。  

・on a cable network  
用途: ケーブル放送のサービスで番組が放送されることを示す。  
例: The film first appeared on a cable network.  
訳: その映画は最初にケーブルテレビのチャンネルで放送された。  

・network television  
用途: 地域局独自の番組などに対し、放送ネットワークによるテレビ放送を指す。  
例: She made her first appearance on network television at nineteen.  
訳: 彼女は19歳で初めてネットワークのテレビ番組に出演した。  

・network news  
用途: ネットワークが制作・供給するニュースを指す。  
例: The story led the evening network news.  
訳: その出来事は、夕方のネットワークニュースのトップで報じられた。  

【語法・注意】station は個々の放送局、network は複数の局・地域をつなぐ系列や番組供給元を指す。channel は視聴者が選ぶチャンネル・番組サービスで、network と同じ事業者を指す場合もあるが、語の焦点は異なる。network television と cable television を対比する米国の文脈では、前者が主に従来型の地上波系列を指す。ただし cable network という表現も正しいので、network 自体を「地上波専用」と定義しない。  

【類義語】

・broadcaster  
定義: テレビ・ラジオ番組を放送する事業者。  
頻度: 〈7/10〉  
違い: 放送主体に焦点がある。network は局の系列・番組供給の仕組みも指し、両者の範囲は完全には一致しない。  
例: The public broadcaster announced a new documentary series.  
訳: 公共放送事業者が新しいドキュメンタリーシリーズを発表した。  

・channel  
定義: 番組を継続して提供する放送チャンネル・サービス。  
頻度: 〈8/10〉  
違い: 視聴者が選ぶ番組の流れやサービスに焦点がある。network はその供給元や系列を表す。  
例: This channel shows classic films all day.  
訳: このチャンネルは一日中、名作映画を放送している。  

5. 【名詞・可算：social network】交流サイト、ソーシャルネットワーク

【日本語訳・定義】利用者がプロフィール、投稿、画像、メッセージなどを通じてつながり、交流するウェブサービス・アプリ。social network というまとまりでよく使い、話題が明らかなら network だけでも指す。  

【頻度】〈7/10〉  

【レジスター/領域】日常、インターネット、メディア。  

【文法パターン】a social network＝一つの交流サービス／on a social network＝そのサービス上で／a profile on a social network＝交流サイト上のプロフィール／a professional network＝仕事上の交流を目的とするサービス。  

【コロケーション・構文例】

・a social network  
用途: 人と人が交流するオンラインサービスを指す。  
例: The company launched a social network for amateur musicians.  
訳: その会社は、アマチュア音楽家向けの交流サービスを公開した。  

・on a social network  
用途: 投稿や活動が行われるオンラインの場を示す。  
例: She posted the photographs on a social network.  
訳: 彼女はその写真をSNSに投稿した。  

・a profile on a professional network  
用途: 仕事上の交流サービスに登録したプロフィールを指す。  
例: His profile on a professional network lists his recent projects.  
訳: ビジネス向けSNSの彼のプロフィールには、最近のプロジェクトが掲載されている。

【類義語】

・social networking site  
定義: 利用者どうしがつながって交流するウェブサイト。  
頻度: 〈6/10〉

頻度: 〈8/10〉  
違い: 情報発信・共有に重点があり、個人的な人間関係の形成を中心としないサービスも含む。

6. 【動詞・自動詞】人脈を築く

【日本語訳・定義】特に仕事や専門活動に役立つ関係を作るため、人と会う・話す・情報交換をする。対面に限らずオンラインでも行う。意識的な関係作りを表すが、不正な便宜や相手の利用を必ず含むわけではない。  

【頻度】〈7/10〉  

【レジスター/領域】仕事、就職、専門家の交流。一般的なビジネス語。  

【文法パターン】people + network＝人が人脈作りをする／network with someone＝人と交流して関係を築く／network at 〈催し〉＝その場で人脈作りをする／副詞を伴う network online＝オンラインで交流する／network to do＝ある目的のために人脈を築く。  

【コロケーション・構文例】

・network with someone  
用途: 交流してつながりを作る相手を示す。  
例: The reception gave us a chance to network with researchers from other fields.  
訳: その懇親会では、他分野の研究者と交流する機会が得られた。  

・network at 〈催し〉  
用途: 人脈作りをする場所・機会を示す。  
例: He spent the afternoon networking at the trade fair.  
訳: 彼は午後、見本市で人脈作りをして過ごした。  

・network online  
用途: オンラインで仕事上の関係を築くことを述べる。  
例: Freelancers often network online between projects.  
訳: フリーランスの人たちは、仕事の合間にオンラインで人脈を築くことが多い。  

・network to do  
用途: 人脈作りによって達成したい目的を示す。  
例: She networks to find collaborators for her research.  
訳: 彼女は研究の協力者を見つけるために人脈を広げている。  

【語法・注意】この基本用法は自動詞で、「顧客と交流する」は network with clients。network clients だと、顧客を何らかのネットワークにつなぐ他動詞的な別の読みになり、同じ意味を安定して表せない。network with someone の with は前置詞なので、network them with のように並べ替えない。network to find work の to 以下は目的を表す。Networking is useful. の networking は活動名詞（語義7）、She is networking. は動詞の進行形。  

【類義語】

・make contacts  
定義: 後で連絡・協力できる知人を作る。  
頻度: 〈7/10〉  
違い: 新たな知人を得る結果に焦点がある。network は既存の関係を深める活動も含みうる。  
例: The workshop helped her make contacts in the industry.  
訳: そのワークショップのおかげで、彼女は業界に知り合いを作れた。  

・socialize  
定義: 人と会って会話や付き合いを楽しむ。  
頻度: 〈7/10〉  
違い: 交流そのものが中心で、仕事上の目的は必要ない。network は有用な関係作りを意識した意味が強い。  
例: We usually socialize after the weekly meeting.  
訳: 私たちはたいてい、毎週の会議のあとに親睦を深める。  

・schmooze  
定義: 相手の好意や便宜を得るため、くだけた会話で付き合う。  
頻度: 〈4/10〉  
違い: くだけた表現で、愛想を振りまく・取り入るという軽い批判を帯びることがある。network 自体はそれほど評価的ではない。  
例: He spent the evening schmoozing with potential investors.  
訳: 彼はその晩、出資してくれそうな人々と愛想よく話して回った。

【日本語訳・定義】仕事や専門活動のために人とつながり、関係を育てる活動。動詞 network からできた活動名詞で、行為を一つの活動分野・機会として述べる。  

【頻度】〈7/10〉

・a networking event  
用途: 仕事上の知人・協力者を作るための催しを指す。  
例: The university hosted a networking event for recent graduates.  
訳: 大学は、卒業して間もない人たちのために交流会を開いた。  

・networking opportunities  
用途: 人脈を作れる機会を指す。  
例: The conference offers plenty of networking opportunities.  
訳: その会議では、人脈を作る機会が豊富に用意されている。  

・do some networking

例: We stayed after the talks to do some networking.

・professional networking

例: Professional networking helped her learn about openings that were not advertised.

【類義語】

・relationship building  
定義: 相手との信頼・協力関係を作り育てる活動。  
頻度: 〈6/10〉  
違い: 既存の相手との関係深化にも重点を置ける。networking は接点やつながりの広がりに焦点を置きやすい。

8. 【動詞・他動詞】機器をネットワーク接続する

【日本語訳・定義】複数のコンピューターや機器を、情報・設備を共有できるようにつなぐ。ケーブルだけでなく、無線で接続する場合も含む。  

【頻度】〈6/10〉  

【レジスター/領域】コンピューター、通信、設備。  

【文法パターン】network 〈複数の機器〉＝機器を接続する／network 〈複数の機器〉 together＝機器を相互接続する／network A to B＝AをBに接続する／be networked、be networked to 〈機器〉＝接続されている／networked 〈機器・システム〉＝ネットワーク接続された機器・システム。  

【コロケーション・構文例】

・network 〈複数の機器〉  
用途: 機器群をネットワークにつなぐ作業を述べる。  
例: The technician networked all the computers in the classroom.  
訳: 技術者は教室内のすべてのコンピューターをネットワークにつないだ。  

・network 〈複数の機器〉 together  
用途: 複数の機器を互いに接続することを強調する。  
例: We networked the two computers together so they could share a printer.  
訳: プリンターを共有できるよう、2台のコンピューターをネットワークでつないだ。  

・be networked to 〈機器〉  
用途: 機器がサーバーなどに接続されている状態を示す。  
例: Each workstation is networked to a central server.  
訳: 各ワークステーションは中央サーバーにネットワーク接続されている。  

・networked devices  
用途: 接続された機器を過去分詞で前から修飾する。  
例: All networked devices must receive regular security updates.  
訳: ネットワークに接続されたすべての機器に、定期的なセキュリティー更新が必要だ。  

【語法・注意】受動形と networked computer などの前置修飾がよく使われる。networked はここでは動詞の結果をそのまま表し、very networked のような程度評価は普通しない。become/get networked は接続される変化を表せるが、接続済みの状態は be networked が明確。人の network with clients（語義6）と、機器を目的語にする network the computers を区別する。技術的には機器を主語に自動詞的に「ネットワーク接続できる」と述べることもあるが、接続作業の基本形は他動詞。  

【類義語】

・connect  
定義: 機器などをつないでやり取りできるようにする。  
頻度: 〈9/10〉  
違い: 単純な物理接続も含む広い語。network は複数機器による通信・共有の仕組みを作ることを示す。  
例: Connect the laptop to the router.  
訳: ノートパソコンをルーターに接続してください。  

・link  
定義: 2つ以上の機器やシステムを結び付ける。  
頻度: 〈7/10〉  
違い: 特定の相互接続に焦点があり、network のように網全体の構成を必ずしも含意しない。  
例: The software links the sensors to the control system.  
訳: そのソフトウェアがセンサーと制御システムをつなぐ。  

・interconnect  
定義: 複数の機器・システムを相互に接続する。  
頻度: 〈5/10〉  
違い: 相互接続を明示する技術的な語。network は通信・資源共有のための網を作る意味が中心。  
例: The project will interconnect the regional systems.  
訳: その事業では、地域ごとのシステムを相互に接続する。  

【反意語】

・disconnect  
定義: 機器を接続から切り離す。  
頻度: 〈7/10〉  
違い: 接続を作る network に対する、接続をなくす方向の反対。機器の電源を切ることとは同じではない。  
例: Disconnect the affected computer from the network.  
訳: 問題が起きたコンピューターをネットワークから切り離してください。

違い: 網目の構造や材料に焦点があり、金網や布の網地にも使える。network は関係や接続の意味へ広く発達している。
