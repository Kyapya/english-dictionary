＃発音記号

米・英: /ɪˈfɪʃ.ənt/  
3音節で、第2音節 /fɪʃ/ に主強勢を置く。第1・第2音節の母音はいずれも /ɪ/、第3音節は弱い /ə/。-cient の部分は /ʃ.ənt/ で、「シエント」と母音を増やさない。effective /ɪˈfek.tɪv/ と取り違えない。  

＃語源

ラテン語 efficere「成し遂げる、生み出す」の現在分詞 efficiens に由来する。efficere は ex-「外へ、十分に」と facere「する、作る」から成る。もともとの「結果を生む」という意味は、哲学の efficient cause「作用因」に残る。現代の一般用法では、結果を生む際の無駄の少なさが中心になっている。同系語は effect「結果、効果」、effective「効果的な」、efficacy「有効性」。  

＃語形成

・efficiently：副詞「効率よく、無駄なく」。work efficiently のように行為を修飾する。  
・efficiency：主に不可算名詞「効率、能率」。improve efficiency のように使い、技術文脈では投入量に対する有用な出力量の比率にも使う。  
・inefficient：形容詞「非効率な、無駄の多い」。必ずしも成果が全く出ないという意味ではない。  
・inefficiency：不可算名詞「非効率」、可算名詞「無駄を生む点・仕組み」。identify inefficiencies は複数の無駄な点を特定すること。  
・energy-efficient・fuel-efficient・cost-efficient：形容詞。それぞれエネルギー・燃料・費用の使用効率がよいことを表し、複合語内部をハイフンでつなぐのが一般的。  

＃意味・用法・関連表現

1. 【形容詞・限定・叙述】効率的な、手際のよい

【日本語訳・定義】人・組織・方法・機械などが、時間・労力・費用・材料・エネルギーを無駄にせず、必要な仕事や機能をうまく果たすこと。人やサービスでは手際のよさ、機器では投入する資源に対して得られる働きの大きさが前面に出る。何を無駄とみなすかは、目的と比較条件による。  

【頻度】〈8/10〉  

【レジスター/領域】一般語。業務評価、サービス、技術、経済などで広く使う。人に対しては仕事ぶりの評価であり、親切さ・創造性などを直接表す語ではない。  

【文法パターン】an efficient 〈人・仕組み・機械〉／someone・something + be・become・seem efficient／be efficient at doing something＝作業を無駄なくこなす／be efficient in doing something・be efficient in the use of something＝行為・資源使用の面で効率がよい／an efficient way to do something・an efficient way of doing something／make efficient use of something／it is efficient for someone to do something／be 〈数値〉 percent efficient。highly・very・more・less で修飾できる。  

【コロケーション・構文例】

・an efficient 〈人〉  
用途: 仕事の進め方が手際よい人を評価する。  
例: Our efficient coordinator arranged all six interviews in one afternoon.  
訳: 手際のよい担当者は、6件の面接の日程調整を午後のうちに済ませた。  

・an efficient 〈service・system・process〉  
用途: 無駄なく機能する業務や仕組みを述べる。  
例: An efficient booking system reduces the time customers spend waiting for confirmation.  
訳: 効率的な予約システムは、顧客が確認を待つ時間を短くする。  

・be efficient at doing something  
用途: 人や機器が、特定の作業を無駄なくこなすことを示す。  
例: The scanner is efficient at processing large batches of documents.  
訳: そのスキャナーは、大量の書類をまとめて効率よく処理できる。  

・be efficient in the use of 〈資源〉  
用途: 効率を評価する資源を明示する。  
例: The new cooling system is more efficient in the use of water.  
訳: 新しい冷却システムは、水をより効率よく使う。  

・be efficient in doing something  
用途: 行為の遂行における効率を述べる。  
例: The team was efficient in handling routine requests, leaving more time for complex cases.  
訳: チームは定型的な依頼を効率よく処理し、複雑な案件のための時間をより多く確保できた。  

・an efficient way to do something  
用途: 目的を達成する際の無駄が少ない方法を提案する。  
例: Grouping deliveries by neighborhood is an efficient way to reduce travel time.  
訳: 配達先を地域ごとにまとめるのは、移動時間を減らす効率的な方法だ。  

・make efficient use of something  
用途: 限られた資源を無駄なく活用することを述べる。  
例: Shared desks make efficient use of the limited floor space.  
訳: 共用の机は、限られた床面積を無駄なく活用する。  

・it is more efficient for someone to do something  
用途: 誰がどう動くと無駄が減るかを比較する。  
例: It is more efficient for one person to place the combined order.  
訳: 1人がまとめて注文するほうが効率的だ。  

・an energy-efficient 〈機器・建物〉  
用途: 必要な機能に対するエネルギー使用の少なさを示す。  
例: We replaced the old freezer with a more energy-efficient model.  
訳: 古い冷凍庫を、よりエネルギー効率のよい機種に買い替えた。  

・be 〈数値〉 percent efficient  
用途: 技術上の効率を比率で表す。  
例: Under these test conditions, the motor is ninety percent efficient.  
訳: この試験条件では、そのモーターの効率は90パーセントだ。  

【語法・注意】efficient を単に「速い」「安い」「効果がある」と覚えない。速くても材料を大量に無駄にすれば、資源使用の面では inefficient と評価され得る。effective は目的の達成、efficient はその達成に要する資源の無駄の少なさが中心で、an effective but inefficient process「成果は出るが無駄の多い工程」は矛盾しない。efficient at と efficient in はどちらも動名詞を続けられ、人と物で厳密に分かれるわけではない。「彼女は手際よく働く」は She works efficiently であり、She works efficient とはしない。「彼女は予約処理が手際よい」は She is efficient at handling bookings とし、She is efficient to handle bookings とはしない。it is efficient for someone to do は行為全体を評価する別構造。energy-efficient はエネルギー使用の効率を指し、大型機が小型機より消費総量まで少ないとは限らない。費用と成果の釣り合いを強調するなら cost-effective、費用の使い方の無駄の少なさなら cost-efficient が中心となる。ただし、実際の用法では両者は大きく重なり、同義的にも使われる。  

【類義語】

・effective  
定義: 意図された結果を生む、または生む力がある。  
頻度: 〈9/10〉  
違い: efficient と成果の点で重なるが、投入する資源が少なくて済むことまでは含まない。  
例: The campaign was effective, but it required a large team and a substantial budget.  
訳: そのキャンペーンは効果を上げたが、大人数のチームと多額の予算を必要とした。  

・productive  
定義: 多くの成果や有用な結果を生む。  
頻度: 〈8/10〉  
違い: 得られる成果の量や有用性に焦点を置く。多くを生産しても、材料を無駄に使っていれば efficient とは限らない。  
例: It was a productive meeting, and we resolved three outstanding issues.  
訳: 実りのある会議で、未解決の問題を3つ解決できた。  

・economical  
定義: 費用・燃料・材料などを無駄にせず、少なく済ませられる。  
頻度: 〈7/10〉  
違い: 資源の節約という点で重なり、特に使用費用の低さを表しやすい。efficient は人の仕事の手際にも広く使う。  
例: The smaller van is more economical to run on short delivery routes.  
訳: 短距離の配達では、小型バンのほうが運用費を抑えられる。  

・competent  
定義: ある仕事を適切に行う能力を備えている。  
頻度: 〈7/10〉  
違い: 必要な技能・判断力があるという評価。efficient が重視する時間や資源の無駄の少なさは、必須ではない。  
例: We need a competent technician who can diagnose the fault safely.  
訳: 不具合を安全に診断できる、確かな能力のある技術者が必要だ。  

・streamlined  
定義: 不要な手順や複雑さが減らされ、機能しやすくなっている。  
頻度: 〈6/10〉  
違い: 効率を生むために工程や組織を簡素化した状態を表す。efficient は、簡素化という方法に限定しない。  
例: The streamlined approval process requires only one signature.  
訳: 簡素化された承認手続きでは、署名は1つだけでよい。  

【反意語】

・inefficient  
定義: 時間・費用・労力などを無駄にし、仕事の進め方や機能に無駄が多い。  
頻度: 〈7/10〉  
違い: 効率という同じ軸の直接的な程度上の対立。仕事が全くできないことや結果が出ないこととは限らない。  
例: The process is inefficient because every record must be entered twice.  
訳: すべての記録を2回入力しなければならないため、その工程は非効率だ。  

・wasteful  
定義: 必要以上の資源を使い、無駄にしている。  
頻度: 〈6/10〉  
違い: 資源使用の無駄という軸で対立し、浪費への批判が強い。inefficient は仕組み上の性能不足を比較的客観的にも述べられる。  
例: Printing a new copy after every minor change is wasteful.  
訳: 小さな変更のたびに新しいものを印刷するのは無駄が多い。  

2. 【形容詞・主に限定・哲学】結果を直接生み出す、作用因となる

【日本語訳・定義】何かを実際に生じさせる原因・作用を表す。主に efficient cause「作用因、能動因」という定着した組み合わせで使い、結果を生む働き手・起点を指す。  

【頻度】〈2/10〉  

【レジスター/領域】哲学、思想史などの専門用法。日常の効率評価とは異なる。  

【文法パターン】the efficient cause of something／an efficient cause。efficient は cause を修飾する形容詞で、句全体が名詞句になる。この意味では通常 very efficient・more efficient のような効率の程度表現にしない。  

【コロケーション・構文例】

・the efficient cause of something  
用途: 哲学上の原因の分類で、何を生み出す働きかを示す。  
例: In this account, the sculptor is the efficient cause of the statue.  
訳: この説明では、彫刻家がその彫像の作用因である。  

【語法・注意】an efficient cause を「効率のよい原因」と訳さない。この cause は、素材を問う material cause「質料因」や目的を問う final cause「目的因」などと対比されるが、それらは反意語ではなく異なる原因の分類である。The sculptor is efficient と efficient だけを人の述語にすると、通常は語義1「彫刻家は手際がよい」になる。文脈が哲学であっても、この2つの構造を混同しない。
