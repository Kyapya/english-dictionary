＃発音記号

米・英: /ˈelɪmənt/。3音節で第1音節に主強勢がある。ここに示す基本発音に英米差はない。第2音節の母音は /ɪ/、第3音節の母音は弱い /ə/。複数形 elements は /ˈelɪmənts/ で、音節数と強勢位置は変わらない。  

elemental は米・英: /ˌelɪˈmentl/。4音節で第3音節に主強勢、第1音節に副強勢がある。語末の /l/ が音節の中心になる読みを含む。elementary は米・英: /ˌelɪˈmentri/。この表記では4音節で第3音節に主強勢、第1音節に副強勢がある。  

＃語源

古フランス語を通じて、ラテン語 elementum（基本原理、基礎となるもの）に由来する。全体を成り立たせる基本的なものという意味が、構成部分・学習の基礎・物質の元素などに関わる。現代英語の el と ment に分けて意味を組み立てる語ではない。  

＃語形成

・elements：通常の複数形に加え、the elements で風雨などの天候、the elements of … である分野の基礎を表す用法がある。  

・elemental：基本的で重要な、自然の激しい力に関わる、元素に関するなどを表す形容詞。elementary といつでも交換できるわけではない。  

・elementary：学習の初歩的な段階、基本的なこと、非常に簡単なことを表す形容詞。  

＃コアイメージ

全体を形作る部分や、物事の土台となる基本的なものという捉え方。構成部分・基礎知識・物質の基本単位に加え、自然や活動を成り立たせる条件にも意味が広がり、in／out of one's element では自分に合う環境との関係を表す。  

・全体の一部分を成すもの → 「構成要素、要素」（語義1）  

・全体の一部分として含まれる性質 → 「ある性質の一分、多少の～」（語義2）  

・予期外という働きをする一要因 → 「不意打ち・意外性が生む効果」（語義3）  

・物質の成り立ちを支える基本的な種類 → 「元素」（語義4）  

・屋外の条件を形作る自然の力 → 「風雨などの自然の力、悪天候」（語義5）  

・学びの土台となる基本的な原理 → 「基礎、初歩的な原理」（語義6）  

・集団の一部分を成す人々 → 「集団内の一派、勢力、層」（語義7）  

・活動の土台となる適した環境 → 「本来の活動場所、適した環境」（語義8）  

・自分の活動に合う環境の中にいる状態 → 「得意な場で生き生きして、本領を発揮して」（語義9）  

・自分の活動に合う環境から離れた状態 → 「不慣れな場にいて、勝手が分からなくて」（語義10）  

・機器を構成し加熱を担う部分 → 「電熱器などの発熱体」（語義11）  

・集合を成す個々の対象 → 「集合の要素、元」（語義12）  

・行列を成す各位置の値 → 「行列の成分」（語義13）  

・文書構造を成す単位 → 「HTMLなどの要素」（語義14）  

・自然の成り立ちを支える力との関係 → 「自然の激しい力に関わる、根源的で力強い」（語義15）  

・物事の根本に関わる性質 → 「基本的で重要な、根源的な」（語義16）  

・物質の基本となる元素との関係 → 「元素に関する」（語義17）  

・他の元素と化合せず存在する形 → 「化合していない元素の形の、単体の」（語義18）  

・学びの初めの段階に属する性質 → 「初歩の、初級の」（語義19）  

・ある分野の土台に属する性質 → 「基本的な、初歩に属する」（語義20）  

・初歩で理解できるほど簡単な性質 → 「非常に簡単な、容易に分かる」（語義21）  

・学校教育の初期段階を担う学校 → 「小学校」（語義22）  

・物質中に微量含まれる元素 → 「微量元素」（語義23）  

・物質を捉える際の基本的な粒子 → 「素粒子」（語義24）  

・古い自然観で世界を形作る基本的なもの → 「古代の四元素の一つ」（語義25）  

・聖餐を構成するパンとぶどう酒 → 「聖餐のパンとぶどう酒」（語義26）  

＃意味・用法・関連表現

1. 【名詞：可算】構成要素、要素

【日本語訳・定義】全体を成り立たせる一つの部分・要因。物理的な部品だけでなく、計画・考え・制度・作品などの一面にも使う。重要な要素を指すことは多いが、常に不可欠という意味を含むわけではない。  

【頻度】〈9/10〉  

【レジスター/領域】一般・仕事・学習・分析。  

【文法パターン】an element of something／an element in something／a key element／an essential element／different elements。  

【コロケーション・構文例】

・an element of something  
用途: 全体に含まれる一つの部分を示す。  
例: Trust is an important element of a successful partnership.  
訳: 信頼は、協力関係を成功させる重要な要素である。  

・an element in something  
用途: ある過程・状況で働く要因を示す。  
例: Timing was a crucial element in the success of the project.  
訳: 時機が、その計画の成功にとって極めて重要な要因だった。  

・a key element  
用途: 特に重要な部分を述べる。  
例: The proposal leaves out a key element of the original plan.  
訳: その提案では、当初の計画の重要な要素が抜けている。  

・an essential element  
用途: 不可欠だと評価する要素を述べる。  
例: Reliable data is an essential element of the analysis.  
訳: 信頼できるデータは、その分析に不可欠な要素である。  

・different elements  
用途: 全体の異なる構成部分を複数形で述べる。  
例: The design brings several different elements together.  
訳: その設計は、異なる複数の要素を組み合わせている。  

【語法・注意】an element は一つの要素で、全体そのものではない。essential や key を付けることで重要性を明示できる。人・意見の集団を表す elements や、悪天候を表す the elements とは文脈で区別する。  

【類義語】

・component  
定義: 機器・仕組みなどを構成する、区別できる部分。  
頻度: 〈7/10〉  
違い: component は部品や機能上の構成単位を捉えやすい。element は抽象的な性質・要因にも広く使い、物として切り離せるとは限らない。  
例: The battery is one component of the device.  
訳: 電池は、その装置の構成部品の一つである。  

・ingredient  
定義: 混合物・料理を作る材料、また成功などに寄与する要因。  
頻度: 〈7/10〉  
違い: ingredient は混ぜ合わせる材料のイメージを持ち、比喩では結果を生む要因を捉えやすい。element は全体に含まれる部分をより広く述べる。  
例: Patience is an important ingredient in successful negotiation.  
訳: 忍耐は、交渉を成功させる重要な要因である。  

2. 【名詞：可算・通常単数】ある性質の一分、多少の～

【日本語訳・定義】ある性質が、全体の中に一部分として含まれていること。全面的にそうだと断定せず、その面もあると述べる。しばしば程度を控えめに示すが、常にごく微量という意味ではない。  

【頻度】〈7/10〉  

【レジスター/領域】一般・議論・説明。  

【文法パターン】an element of truth／an element of risk／an element of doubt／a considerable element of something。  

【コロケーション・構文例】

・an element of truth  
用途: 全面的ではなく、ある程度は真実だと述べる。  
例: There is an element of truth in what she says.  
訳: 彼女の言うことには、一理ある。  

・an element of risk  
用途: 危険が一部含まれることを述べる。  
例: Every new venture involves an element of risk.  
訳: 新しい試みには、どれも多少の危険が伴う。  

・an element of doubt  
用途: 疑わしさが残ることを述べる。  
例: The missing records leave an element of doubt about the conclusion.  
訳: 記録が欠けているため、その結論には多少の疑いが残る。  

・a considerable element of something  
用途: 一部の性質がかなりあると述べる。  
例: There was a considerable element of luck in their victory.  
訳: 彼らの勝利には、運による部分がかなりあった。  

【語法・注意】of の後ろに truth・risk などの性質を置く。an element of truth は、その話が全て真実だという保証ではない。considerable のような修飾語を伴えば、element を機械的にごく少しと訳さない。  

3. 【定型表現：the element of surprise】不意打ち・意外性が生む効果

【日本語訳・定義】相手や聞き手が予期していないことによって生まれる効果・優位性。単に驚きが少し含まれるという程度ではなく、予想外であることが結果に働く要因を指す。  

【頻度】〈6/10〉  

【レジスター/領域】一般・戦略・企画・演出。  

【文法パターン】retain the element of surprise／lose the element of surprise／use the element of surprise。  

【コロケーション・構文例】

・retain the element of surprise  
用途: 予想外という効果を保つ。  
例: The designers kept the new feature secret to retain the element of surprise at the launch.  
訳: デザイナーたちは、発表時の意外性を保つために新機能を秘密にした。  

・lose the element of surprise  
用途: 予期されてしまい意外性の効果が失われることを述べる。  
例: After the ending was revealed, the performance lost the element of surprise.  
訳: 結末が明かされると、その上演は意外性による効果を失った。  

・use the element of surprise  
用途: 予想外であることを演出などに利用する。  
例: The speaker used the element of surprise to make the demonstration memorable.  
訳: 話し手は、実演を印象に残すために意外性を利用した。  

【語法・注意】この句では通常 the element of surprise とする。an element of truth のある程度の真実という部分的な程度と、同じ型だとだけ覚えない。surprise が結果に効く一要因という捉え方である。  

4. 【名詞：可算】元素

【日本語訳・定義】化学的な物質の基本的な種類で、同じ原子番号を持つ原子からなるもの。通常の化学反応で、さらに別の元素へ分解される物質ではない。異なる元素が結びついた化合物とは区別する。  

【頻度】〈7/10〉  

【レジスター/領域】化学・科学・教育。  

【文法パターン】a chemical element／the element oxygen／elements in the periodic table／a radioactive element。  

【コロケーション・構文例】

・a chemical element  
用途: 化学上の元素であることを明示する。  
例: Copper is a chemical element used in many electrical products.  
訳: 銅は、多くの電気製品に使われる化学元素である。  

・the element oxygen  
用途: 元素の名前を続けて示す。  
例: The lesson introduces the element oxygen and some of its compounds.  
訳: その授業は、元素としての酸素と、その化合物のいくつかを紹介する。  

・elements in the periodic table  
用途: 周期表に配列される元素を述べる。  
例: Students compared the properties of several elements in the periodic table.  
訳: 学生たちは、周期表のいくつかの元素の性質を比較した。  

・a radioactive element  
用途: 放射性の元素について述べる。  
例: The exhibition explains why uranium is described as a radioactive element.  
訳: その展示は、ウランが放射性元素と呼ばれる理由を説明している。  

【語法・注意】element は元素の種類、atom はその原子を表す。ある元素の原子は原子番号が同じでも、同位体によって質量が異なる場合がある。element を全ての原子があらゆる点で同一だという意味にしない。  

5. 【名詞：複数形 the elements】風雨などの自然の力、悪天候

【日本語訳・定義】風・雨・雪などの天候、特に厳しい天候が及ぼす力。屋外で人や物がさらされる自然条件をまとめて述べる。  

【頻度】〈6/10〉  

【レジスター/領域】一般・天候・屋外活動。  

【文法パターン】be exposed to the elements／shelter from the elements／protect something from the elements／brave the elements。  

【コロケーション・構文例】

・be exposed to the elements  
用途: 風雨などにさらされていることを述べる。  
例: The equipment had been exposed to the elements for years.  
訳: その機器は、何年も風雨にさらされていた。  

・shelter from the elements  
用途: 天候から身を守る場所を述べる。  
例: The old shed offered some shelter from the elements.  
訳: その古い小屋は、多少は風雨をしのぐ場所になった。  

・protect something from the elements  
用途: 物を風雨などから保護することを述べる。  
例: A cover protects the furniture from the elements.  
訳: カバーが、家具を風雨から守る。  

・brave the elements  
用途: 厳しい天候をものともせず外へ出ることを述べる。  
例: A few spectators braved the elements to watch the match.  
訳: 数人の観客が、悪天候をものともせず試合を見に来た。  

【語法・注意】この意味では通常 the elements という複数形を使う。the を外した elements だけで、常に悪天候という意味になるわけではない。a chemical element の元素とも区別する。  

6. 【名詞：複数形 elements】基礎、初歩的な原理

【日本語訳・定義】ある分野を学ぶ際の基本的な知識・原理。細かな専門事項全体ではなく、その分野の土台となる内容を述べる。  

【頻度】〈5/10〉  

【レジスター/領域】教育・学習・やや改まった説明。  

【文法パターン】the elements of something／learn the elements of something／teach the elements of something。  

【コロケーション・構文例】

・the elements of something  
用途: 分野の基本事項を示す。  
例: The book explains the elements of musical theory.  
訳: その本は、音楽理論の基礎を説明している。  

・learn the elements of something  
用途: 初歩的な知識を身につけることを述べる。  
例: We learned the elements of logic before tackling more difficult arguments.  
訳: より難しい議論に取り組む前に、私たちは論理学の基礎を学んだ。  

・teach the elements of something  
用途: 基本原理を教えることを述べる。  
例: The course teaches the elements of design through practical exercises.  
訳: その講座は、実習を通じてデザインの基礎を教える。  

【語法・注意】この用法は通常複数形。the elements of a machine なら機械の構成部分を指すこともあるため、of 以下だけでなく、学習や原理という文脈を見る。  

【類義語】

・basics  
定義: ある分野を理解・実行するための基礎事項。  
頻度: 〈7/10〉  
違い: basics は日常的な説明にも使いやすい。the elements of は、その分野を形作る初歩的な原理という捉え方が出やすい。  
例: The workshop covers the basics of digital photography.  
訳: その講習会は、デジタル写真の基礎を扱う。  

7. 【名詞：可算・通常複数】集団内の一派、勢力、層

【日本語訳・定義】大きな組織・社会などの中で、共通する態度や特徴を持つ人々を一つの層として捉える。しばしば評価的な修飾語とともに使う。  

【頻度】〈5/10〉  

【レジスター/領域】報道・政治・社会についての説明。  

【文法パターン】elements within a group／radical elements／a fringe element。  

【コロケーション・構文例】

・elements within a group  
用途: 組織内部の一部の勢力を述べる。  
例: Some elements within the party opposed the compromise.  
訳: 党内の一部の勢力は、その妥協案に反対した。  

・radical elements  
用途: 急進的な考えを持つ層を述べる。  
例: The report distinguishes radical elements from more moderate members.  
訳: その報告書は、急進派の層を、より穏健な構成員と区別している。  

・a fringe element  
用途: 周辺的な一派を一まとまりとして述べる。  
例: The speaker argued that the incident involved only a fringe element of the movement.  
訳: 発言者は、その事件に関わったのは運動の周辺的な一派にすぎないと主張した。  

【語法・注意】複数形が多いが、a fringe element のような単数形も使う。人々をまとめて分類するため、修飾語や文脈によって距離を置く響きや否定的な評価が生じ得る。elements そのものが必ず犯罪者を意味するわけではない。  

8. 【名詞：可算・通常単数】本来の活動場所、適した環境

【日本語訳・定義】人や生き物が自然に活動し、能力を発揮できる環境。物理的な生息環境にも、人に合った活動の場にも使われる。  

【頻度】〈4/10〉  

【レジスター/領域】一般・描写。  

【文法パターン】one's natural element／water is someone's element。  

【コロケーション・構文例】

・one's natural element  
用途: 生き物が本来活動する環境を述べる。  
例: The documentary shows the animals moving freely in their natural element.  
訳: その記録映画は、動物たちが本来の環境で自由に動く様子を映している。  

・water is someone's element  
用途: 水中などが得意な活動の場であると述べる。  
例: For this experienced swimmer, water is her element.  
訳: この熟練した泳ぎ手にとって、水中は本領を発揮できる場所だ。  

【語法・注意】element はここでは物質の種類ではなく、活動に合った環境を指す。in one's element という慣用句の理解にもつながるが、物理的な場所だけに限定されない。  

9. 【慣用句：in one's element】得意な場で生き生きして、本領を発揮して

【日本語訳・定義】自分に合った活動や環境にいて、気楽に、楽しみながら能力を発揮している。単にその場所に慣れているだけでなく、そこで生き生きしていることを表しやすい。  

【頻度】〈6/10〉  

【レジスター/領域】一般・会話・人物描写。  

【文法パターン】be in one's element／feel in one's element／in one's element when doing something。  

【コロケーション・構文例】

・be in one's element  
用途: 得意な状況で本領を発揮していることを述べる。  
例: Surrounded by old books, she was in her element.  
訳: 古い本に囲まれ、彼女は水を得た魚のようだった。  

・feel in one's element  
用途: 自分に合った場だと感じることを述べる。  
例: He feels in his element when discussing technical problems with other engineers.  
訳: ほかの技術者と技術的な問題を話していると、彼は自分の得意な場にいると感じる。  

・in one's element when doing something  
用途: 本領を発揮する活動を示す。  
例: She is in her element when teaching beginners how to cook.  
訳: 初心者に料理を教えているとき、彼女は生き生きと本領を発揮する。  

【語法・注意】one's は主語などに対応して my／your／her などに変える。日本語の水を得た魚に近いが、英語で必ず水について述べているわけではない。単数形 element を用いる。  

10. 【慣用句：out of one's element】不慣れな場にいて、勝手が分からなくて

【日本語訳・定義】自分に合う通常の環境や得意分野から離れ、居心地の悪さや戸惑いを感じている。その人の能力が全般的に低いという意味ではない。  

【頻度】〈5/10〉  

【レジスター/領域】一般・会話・人物描写。  

【文法パターン】be out of one's element／feel out of one's element。  

【コロケーション・構文例】

・be out of one's element  
用途: 場違い・不慣れな状況にいることを述べる。  
例: The experienced researcher was out of her element at the crowded networking party.  
訳: 熟練した研究者である彼女も、混み合う交流会では勝手が分からなかった。

【コロケーション・構文例】

・an elementary particle  
用途: 一つの素粒子を述べる。  
例: The lecture introduces the electron as an elementary particle.  
訳: その講義は、電子を素粒子として紹介している。  

・elementary particles  
用途: 素粒子を複数・種類全体として述べる。  
例: The experiment investigates interactions between elementary particles.  
訳: その実験は、素粒子同士の相互作用を調べている。  

・the properties of elementary particles  
用途: 素粒子が持つ性質を述べる。  
例: The textbook compares the properties of several elementary particles.  
訳: その教科書は、いくつかの素粒子の性質を比較している。  

【語法・注意】chemical element は化学元素、elementary particle は素粒子で、分野も概念も異なる。small particle なら大きさが小さい粒子を広く述べるが、elementary particle は内部の構成に関わる専門用語である。  

25. 【名詞：可算】古代の四元素の一つ

【日本語訳・定義】古代の思想などで、世界を形作る基本的なものと考えられた土・空気・火・水などを指す。現代化学の元素とは異なる歴史的な用法。  

【頻度】〈3/10〉  

【レジスター/領域】思想史・古代の自然観・文学。  

【文法パターン】the four elements／the element of fire。  

【コロケーション・構文例】

・the four elements  
用途: 古代の四元素という考えを述べる。  
例: The text describes the world in terms of the four elements.  
訳: その文献は、四元素によって世界を説明している。  

・the element of fire  
用途: 古い自然観における火の元素を述べる。  
例: In this ancient account, the element of fire has a central role.  
訳: この古代の説明では、火の元素が中心的な役割を持つ。  

【語法・注意】火や水をここで element と呼ぶのは、その歴史的な世界観に基づく。現代化学で水が元素である、火が周期表の元素である、という意味ではない。全ての文化が同じ四分類を採ったとも一般化しない。  

26. 【名詞：複数形 elements】聖餐のパンとぶどう酒

【日本語訳・定義】キリスト教の聖餐で用いられるパンとぶどう酒を指す用語。儀礼上の扱いや理解は教派などによって異なる。  

【頻度】〈2/10〉  

【レジスター/領域】キリスト教・礼拝・儀礼。  

【文法パターン】the Eucharistic elements／prepare the elements for Communion。  

【コロケーション・構文例】

・the Eucharistic elements  
用途: 聖餐で使われるものを専門的な名称で述べる。  
例: The service book refers to the bread and wine as the Eucharistic elements.  
訳: その礼拝用の書物は、パンとぶどう酒を聖餐の要素と呼んでいる。  

・prepare the elements for Communion  
用途: 聖餐のためのパンとぶどう酒を準備することを述べる。  
例: The volunteers prepared the elements for Communion.  
訳: ボランティアたちは、聖餐のためにパンとぶどう酒を準備した。  

【語法・注意】天候を表す the elements と形が同じでも、礼拝の文脈では別の専門義になる。名称だけで、どの教派でも同じ儀礼や神学的理解を採ると一般化しない。
