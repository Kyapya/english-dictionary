＃発音記号

米: /ˈkærəktər/・/ˈkærɪktər/｜英: /ˈkærəktə(r)/・/ˈkærɪktə(r)/。3音節で、第1音節の母音 /æ/ に強勢、第2音節は示した各変異により /ə/ または /ɪ/。第3音節は、示した米語形では /ər/、英語形では /ə(r)/ で、英語形の括弧の r は後ろに母音が続く場合などに発音される。語頭の ch は /k/ であり、chair の /tʃ/ ではない。第2音節の /ə/ と /ɪ/ の違いは、米英を一律に分ける対立ではない。  

＃語源

古フランス語・ラテン語を経て、ギリシャ語 kharaktēr「刻みつける道具・刻まれた印」に遡る。その背景には「刻む・彫る」という動詞がある。印や特徴、人物を特徴づける性質などの意味が発達したが、語源の「彫刻」を現在のどの用法にも当てはめるわけではない。  

char と actor を組み合わせた語ではない。現代の character actor は、すでにある character と actor を組み合わせた表現で、character 自体の語源説明とは逆方向になる。  

＃語形成

・characters：登場人物・文字・形質など可算の意味で用いる複数形。人格的な強さの不可算義に、そのまま複数語尾を付けない。  

・characteristic：特徴・特性を表す名詞、特徴的なことを表す形容詞。character の性格・役・文字という全語義を置き換える語ではない。  

・characterize／characterise：特徴づける、どのようなものか述べる、という動詞。-ize は米語や一部の英語表記、-ise は英語表記に見られる。characterization／characterisation はその名詞形。  

・characterful／characterless：独特の味わいがあること／面白みのある個性に乏しいことを表す形容詞。後掲する。  

・character-building：人格や困難に向き合う力を育てる、という複合形容詞。名詞の前では通常ハイフンを用いる。  

＃コアイメージ

中心は「性質やしるしによって対象を示すこと」。性質や人物像ではその対象らしさ、文字の系統では情報を表す識別のしるしと、それを記す行為に具体化する。語義22は制度的専門義で、表現行列のトレースから定まる関数という語彙的定義を、この一般的な核だけからは導けないため個別に参照する。  

・人を特徴づける性格のまとまり → 「性格・人柄」（語義1）  

・物語内で一個体を特徴づける人物像 → 「登場人物・役・ゲーム内のキャラクター」（語義2）  

・文字情報を表す識別のしるし → 「文字・記号」（語義3）  

・物事を特徴づける性質 → 「性質・特色」（語義4）  

・人を特徴づける優れた精神的資質 → 「人格的な強さ・高潔さ」（語義5）  

・場所や人を特徴づける魅力的な個性 → 「独特の味わい・個性」（語義6）  

・人を特徴づける資質への世間の評価 → 「人格についての評判」（語義7）  

・人を特徴づける際立った個性 → 「風変わりで面白い人」（語義8）  

・人を特徴づける性質に着目した呼称 → 「ある性質を持つ人物・やつ」（語義9）  

・普段その人を特徴づける性質との一致・不一致 → 「その人らしく・その人らしくなく」（語義10）  

・役を示す人物像の維持・離脱 → 「役になりきる・役を離れる」（語義11）  

・周囲を特徴づける様式との一致 → 「様式・雰囲気に合って」（語義12）  

・役を特徴づける個性の演技 → 「個性的な人物の役を演じる・性格俳優の」（語義13）  

・人を特徴づける評判への攻撃 → 「人格攻撃・評判を傷つける中傷」（語義14）  

・人を特徴づける人柄の証言 → 「人柄についての推薦・証明」（語義15）  

・物を特徴づける魅力的な味わいの存在 → 「独特の味わいがある」（語義16）  

・物を特徴づける面白い個性の欠如 → 「個性や面白みに乏しい」（語義17）  

・生物を特徴づける観察可能な性質 → 「形質」（語義18）  

・物語の人物を特徴づける描写 → 「人物描写・人物造形」（語義19）  

・人を特徴づける役割上の立場 → 「資格・立場」（語義20）  

・人物類型を特徴づける短い描写 → 「人物類型を描いた短文」（語義21）  

・信仰上の関係を特徴づける霊的なしるし → 「秘跡による消えない霊的な印」（語義23）  

・対象を特徴づける性質の描写 → 「描写する・特徴づける」（語義24）  

・文字情報を表す識別のしるしの書込み → 「書き記す・刻みつける」（語義25）  

・人を特徴づける資質・能力の証言 → 「人物評価の証明・推薦書」（語義26）  

＃意味・用法・関連表現

1. 【名詞：通常単数】性格・人柄

【日本語訳・定義】人の考え方・行動傾向・道徳的な資質など、その人をその人らしくしている性質のまとまり。良い性格だけを意味するわけではない。  

【頻度】〈8/10〉  

【レジスター/領域】一般・人物理解・心理や社会についての説明。  

【文法パターン】someone's character／a strong/weak character／a side of someone's character／character traits／in someone's character。  

【コロケーション・構文例】

・someone's character  
用途: 人の性質全体を述べる。  
例: The experience revealed a generous side of her character.  
訳: その経験を通じて、彼女の寛大な一面が明らかになった。  

・a strong character  
用途: 人のしっかりした性格を述べる。  
例: She has a strong character and rarely gives in to pressure.  
訳: 彼女は気がしっかりしていて、圧力にはめったに屈しない。  

・character traits  
用途: 性格を構成する個々の特徴を述べる。  
例: The questionnaire asks about several character traits.  
訳: その質問票は、性格に関わるいくつかの特性を尋ねている。  

・in someone's character  
用途: その人の性格にある傾向を述べる。  
例: There is a stubborn streak in his character.  
訳: 彼の性格には、頑固なところがある。  

【語法・注意】character は性質のまとまり、a character trait はその一つの特徴。「彼には性格がある」を言うつもりで He has character とすると、語義5の強さや語義6の個性を評価する意味になり得る。国民性などに用いる場合も、集団全員が同じ性質を持つことを単語だけで保証しない。  

【類義語】

・personality  
定義: その人の行動・感情・対人印象などに現れる個性。  
頻度: 〈8/10〉  
違い: character と重なるが、道徳的な評価よりも、どんな人として感じられるかに焦点を置きやすい。  
例: Her lively personality made the interview enjoyable.  
訳: 彼女の生き生きした人柄のおかげで、面接は楽しいものになった。  

・temperament  
定義: 感情の動き方や反応の仕方に見られる気質。  
頻度: 〈5/10〉  
違い: 生来の傾向や反応様式に重点があり、道徳的な資質にも重点を置き得る character と、焦点が必ず一致するわけではない。  
例: The twins have very different temperaments.  
訳: その双子は、気質がとても異なる。  

・disposition  
定義: 普段の気分・態度に表れる性向。  
頻度: 〈5/10〉  
違い: 気立てや物事への向き合い方を述べる。character の全体的な人格より焦点が狭い。  
例: He has a calm disposition.  
訳: 彼は穏やかな気性の持ち主だ。  

2. 【名詞：可算】登場人物・役・ゲーム内のキャラクター

【日本語訳・定義】小説・映画・演劇・漫画などに描かれる個体や、演じられる役。人間だけでなく動物なども含む。ゲームではプレイヤーが操作する個体や物語内の存在にも使う。  

【頻度】〈8/10〉  

【レジスター/領域】物語・映像・演劇・ゲーム。  

【文法パターン】a character in 〈作品〉／the main character／a supporting character／play/portray a character／a playable character。  

【コロケーション・構文例】

・the main character  
用途: 物語の中心人物を示す。  
例: The main character returns to the village in the final chapter.  
訳: 主人公は、最終章で村に戻る。  

・a character in 〈作品〉  
用途: どの作品に登場するかを示す。  
例: The fox is my favourite character in the story.  
訳: その物語では、キツネが私のいちばん好きな登場人物だ。  

・play a character  
用途: 俳優がある役を演じることを述べる。  
例: She plays a character who hides her real identity.  
訳: 彼女は、本当の身元を隠している人物を演じる。  

・a playable character  
用途: ゲームで操作できる個体を示す。  
例: Each playable character has a different set of abilities.  
訳: 操作できる各キャラクターには、それぞれ異なる能力の組合せがある。  

【語法・注意】actor は演じる実在の人、character は作品内の人物・役である。同じ俳優が複数の characters を演じることもある。実在人物を題材とした作品でも、その作品内での人物像を character と呼べる。  

3. 【名詞：可算】文字・記号

【日本語訳・定義】文字体系や情報処理で使う文字・数字・記号など。アルファベットの字だけに限らず、漢字、句読点、空白や制御に関わる文字を扱う文脈もある。  

【頻度】〈8/10〉  

【レジスター/領域】言語・印刷・コンピューター・入力欄の説明。  

【文法パターン】a Chinese character／special characters／a string of characters／a character set／character encoding。  

【コロケーション・構文例】

・Chinese characters  
用途: 漢字を指す。  
例: The sign uses both Chinese characters and Roman letters.  
訳: その標識には、漢字とローマ字の両方が使われている。  

・special characters  
用途: 通常の英数字と区別して記号などを述べる。  
例: This field accepts letters, numbers, and certain special characters.  
訳: この入力欄には、文字・数字と特定の特殊文字を入力できる。  

・a string of characters  
用途: 文字を順に並べた列を述べる。  
例: The program checks the string of characters before saving it.  
訳: そのプログラムは、保存前に文字列を検査する。  

・character encoding  
用途: 文字と符号化の関係を述べる。  
例: Using the wrong character encoding can make the text unreadable.  
訳: 文字コードを誤ると、文章が読めなくなることがある。  

【語法・注意】letter は通常アルファベットなどの字を指し、character のほうが広い。Unicodeの抽象文字、符号位置、符号単位、表示用の字形、利用者が一文字と認識する単位は区別する。一文字が必ず1バイト・1符号位置・一つの字形になるとは限らず、入力制限の「文字数」は実装の数え方を確認する。  

4. 【名詞：通常単数・不可算】性質・特色

【日本語訳・定義】物・場所・出来事などに特有の性質や、どの種類に属するかを示すあり方。必ず好意的な評価を含むわけではない。  

【頻度】〈7/10〉  

【レジスター/領域】一般・説明文・評論。  

【文法パターン】the character of something／have a distinctive character／take on a different character／be 〈形容詞〉 in character／of a 〈形容詞〉 character。  

【コロケーション・構文例】

・the character of something  
用途: 場所や事柄の性質を述べる。  
例: The new buildings have changed the character of the neighbourhood.  
訳: 新しい建物によって、その地域の雰囲気は変わった。  

・take on a different character  
用途: 性質や様相が変わることを示す。  
例: The discussion took on a different character after the announcement.  
訳: 発表の後、議論は違った様相を帯びた。  

・be 〈形容詞〉 in character  
用途: どのような性質かを述語で述べる。  
例: The event was informal in character.  
訳: その催しは、形式ばらない性格のものだった。  

・of a 〈形容詞〉 character  
用途: 名詞に性質・種類の説明を添える。  
例: The committee considered complaints of a similar character.  
訳: 委員会は、似た性質の苦情を検討した。  

【語法・注意】in character が常に「役になりきって」ではない。informal in character のように形容詞を伴う場合、ここでは「性質として形式ばらない」の意。物事に personality があると言う擬人的な表現とは区別する。  

5. 【名詞：不可算】人格的な強さ・高潔さ

【日本語訳・定義】困難に立ち向かう精神的な強さ、誠実さ、信念を保つ力など、評価される人格的資質。  

【頻度】〈6/10〉  

【レジスター/領域】人物評価・スポーツ・教育。通常好意的。  

【文法パターン】show character／strength of character／a person of character／build character／good moral character。  

【コロケーション・構文例】

・show character  
用途: 困難に対して精神的強さを示す。  
例: The team showed character by continuing to compete after the setback.  
訳: そのチームは、つまずいた後も競技を続け、精神的な強さを示した。  

・strength of character  
用途: 信念を保つ人格的な強さを述べる。  
例: It took strength of character to admit the mistake publicly.  
訳: 公の場で誤りを認めるには、芯の強さが必要だった。  

・a person of character  
用途: 高潔さやしっかりした人格を評価する。  
例: They remember him as a person of character and kindness.  
訳: 人々は彼を、高潔で思いやりのある人物として記憶している。  

【語法・注意】show a character とすると通常は、ある人物・文字を示すなど別の構造になる。この不可算義の character は、目立つ個性や話の面白さだけではない。good character/bad character と修飾する場合は、資質の良し悪しを明示して評価する。  

6. 【名詞：不可算】独特の味わい・個性

【日本語訳・定義】人・場所・建物などにある、印象に残る独特の味わいや面白み。中立的な特徴の列挙より、魅力的な個性を評価することが多い。  

【頻度】〈6/10〉  

【レジスター/領域】人物・住まい・店・地域の描写。通常好意的。  

【文法パターン】have character／full of character／give character to something／a house with character。  

【コロケーション・構文例】

・full of character  
用途: 独特の味わいが豊かであると述べる。  
例: The old café is small but full of character.  
訳: その古いカフェは小さいが、独特の味わいにあふれている。  

・give character to something  
用途: 特徴的な魅力をもたらす。  
例: The uneven wooden floor gives character to the room.  
訳: 少しでこぼこした木の床が、その部屋に味わいを与えている。  

・a house with character  
用途: 個性や趣のある家を述べる。  
例: They were looking for a house with character rather than a standard new build.  
訳: 彼らは、画一的な新築ではなく、趣のある家を探していた。  

【語法・注意】has character と has a character は同じでない。前者は魅力的な個性を述べやすく、後者は物語上の人物など可算の意味にもなる。「古いほど必ず character がある」という条件は含まない。  

7. 【名詞：可算・不可算】人格についての評判

【日本語訳・定義】その人がどれほど信頼できるか、誠実かなどについて、周囲に持たれている評価・評判。本人の実際の性格と、他人の評価は一致するとは限らない。  

【頻度】〈5/10〉  

【レジスター/領域】硬めの文章・対人評価・報道。  

【文法パターン】an attack on someone's character／damage someone's character／a stain on someone's character／a character witness。  

【コロケーション・構文例】

・an attack on someone's character  
用途: 人格についての評判への攻撃を示す。  
例: She described the accusation as an attack on her character.  
訳: 彼女はその非難を、自分の人格を傷つける攻撃だと述べた。  

・a stain on someone's character  
用途: 評判に傷がつくことを比喩的に述べる。  
例: He feared that the allegation would leave a stain on his character.  
訳: 彼は、その申し立てによって自分の評判に傷がつくことを恐れた。  

【語法・注意】reputation と重なるが、character はとくに人柄・誠実さなどに関する評判を扱う。人物の評判をめぐる表現を、法的な名誉毀損の成立要件と同一視しない。character witness は人物の資質を証言する人を指し、どの手続で証言が認められるかは別の制度上の問題である。  

8. 【名詞：可算】風変わりで面白い人

【日本語訳・定義】目立つ癖や個性を持つ、風変わりで面白い人。親しみや面白がる気持ちを含み得るが、文脈によっては揶揄にもなる。  

【頻度】〈5/10〉  

【レジスター/領域】くだけた会話・人物評。  

【文法パターン】be a character／quite a character／a real character／local characters。  

【コロケーション・構文例】

・quite a character  
用途: 一風変わった面白い人だと評する。  
例: Our neighbour is quite a character and always has a surprising story to tell.  
訳: 隣人はなかなか面白い人で、いつも驚くような話をしてくれる。  

・local characters  
用途: 地域で個性の際立つ人々を述べる。  
例: The documentary introduces several local characters.  
訳: そのドキュメンタリーは、地元の個性豊かな人々を何人か紹介している。  

【語法・注意】He is a character は「彼は性格を持つ」の意味ではない。He has character の人格的な強さ・味わいとも異なる。相手によっては「変わり者」と評する失礼さが生じるため、常に褒め言葉とは考えない。  

9. 【名詞：可算】ある性質を持つ人物・やつ

【日本語訳・定義】形容詞などを伴い、どのような人かに着目して人物を指す。怪しい人・不快な人などの描写にも使う。  

【頻度】〈5/10〉  

【レジスター/領域】くだけた人物の呼称。修飾語により評価が変わる。  

【文法パターン】a suspicious character／a shady character／a determined character。  

【コロケーション・構文例】

・a suspicious character  
用途: 怪しく見える人物を述べる。  
例: A suspicious character was waiting near the locked entrance.  
訳: 怪しい人物が、鍵のかかった入口の近くで待っていた。  

・a determined character  
用途: 決意の固い人物を描く。  
例: She is a determined character who does not give up easily.  
訳: 彼女は、簡単には諦めない意志の固い人物だ。  

【語法・注意】character だけで必ず犯罪者や変人を意味するのではなく、修飾語と文脈が人物評価を決める。物語の登場人物を指す語義2と異なり、現実の人物にも使う。  

10. 【慣用的な形容詞句・副詞句：in/out of character】その人らしく・その人らしくなく

【日本語訳・定義】行動や発言が、普段の性格・振る舞いと一致している、または一致していないこと。  

【頻度】〈5/10〉  

【レジスター/領域】一般・人物の行動についての説明。  

【文法パターン】be in character／be out of character／be out of character for someone／act out of character。  

【コロケーション・構文例】

・be out of character for someone  
用途: 普段らしくない言動を述べる。  
例: That angry reply was completely out of character for him.  
訳: あんなに怒った返事は、彼にはまったくらしくなかった。  

・be in character  
用途: 普段の性質に合っていると述べる。  
例: Her generous response was entirely in character.  
訳: その寛大な対応は、まさに彼女らしいものだった。  

【語法・注意】out of character は「性格がない」ではなく、普段のその人から予想される行動との不一致。普段らしくない行動が、必ず悪い行動とは限らない。演技の in character は次の語義で区別する。  

11. 【慣用的な形容詞句・副詞句・動詞句】役になりきる・役を離れる

【日本語訳・定義】in character は、その役の人物として振る舞っていること。out of character は役を離れて本人として振る舞うこと。break character は、役としての振る舞いを崩す・中断することを表す。  

【頻度】〈4/10〉  

【レジスター/領域】演技・演劇・映像・ロールプレイ。  

【文法パターン】stay/remain in character／answer in character／speak out of character／break character。前2型は役を保つ状態・行為、out of character は役外の状態、break character はその状態への移行を述べる動詞句。  

【コロケーション・構文例】

・stay in character  
用途: 演じる人物像を保つ。  
例: The actors stayed in character while speaking to the visitors.  
訳: 俳優たちは、訪問者に話しかける間も役になりきっていた。  

・answer in character  
用途: 役の人物として返答する。  
例: She answered the question in character rather than as herself.  
訳: 彼女は、自分自身としてではなく、役の人物として質問に答えた。  

・speak out of character  
用途: 役の人物ではなく、演者本人として話すことを示す。  
例: The players spoke out of character during the break to clarify the rules.  
訳: 参加者たちは休憩中、ルールを確認するため、役を離れて本人として話した。  

・break character  
用途: 役としての振る舞いを中断することを述べる。  
例: She broke character to ask the director a question.  
訳: 彼女は、演出家に質問するために役としての演技をいったんやめた。  

【語法・注意】本人の普段の性格に合うという語義10とは、判断の基準が異なる。演者本人と性格が違う役でも、役の人物像を維持していれば in character と言える。break character は笑って思わず役を崩す場合にも、質問などのために意図して中断する場合にも使える。out-of-character discussion のように名詞前の複合修飾にするときはハイフンを用いる。  

12. 【慣用的な形容詞句：in character with】様式・雰囲気に合って

【日本語訳・定義】建物や装飾などが、他のものと様式・雰囲気の面で調和していること。  

【頻度】〈4/10〉  

【レジスター/領域】建築・景観・デザインの説明。  

【文法パターン】be in character with something／not be in character with something。with の後ろに調和の比較対象を置く。  

【コロケーション・構文例】

・be in character with something  
用途: 周囲の様式との一致を示す。  
例: The new extension is in character with the original house.  
訳: 新しい増築部分は、もとの家の雰囲気に合っている。  

【語法・注意】この with は演者が一緒にいる相手を示すのではなく、様式の一致を判断する相手を示す。in character with は一つの比較関係を表し、単に物が個性的だという has character とは異なる。  

13. 【形容詞的用法】個性的な人物の役を演じる・性格俳優の

【日本語訳・定義】actor・role・part などの前で、目立った性格や身体的特徴を持つ人物を描き分ける演技・役を表す。character actor はそのような人物役を得意とする俳優。  

【頻度】〈4/10〉  

【レジスター/領域】映画・演劇・俳優の説明。名詞前の用法。  

【文法パターン】a character actor／a character role／a character part。  

【コロケーション・構文例】

・a character actor  
用途: 特徴の際立つ役を演じる俳優を述べる。  
例: He became known as a character actor with a wide range of voices and mannerisms.  
訳: 彼は、多彩な声や仕草を使い分ける性格俳優として知られるようになった。  

・a character role  
用途: 個性の際立つ人物を演じる役を述べる。  
例: She enjoys character roles that require a distinctive way of speaking.  
訳: 彼女は、独特な話し方を要する個性的な人物の役を好んでいる。  

【語法・注意】脇役に用いられることが多いが、「絶対に主役を演じない」「必ず悪役」という条件にしない。品詞分析は辞書により形容詞または名詞の修飾用法とされるが、ここでは actor 等の前で役の種類を限定する働きを扱う。  

14. 【名詞句：不可算】人格攻撃・評判を傷つける中傷

【日本語訳・定義】character assassination の形で、人の評判を損なうことを狙った不当な攻撃・中傷を表す。  

【頻度】〈4/10〉  

【レジスター/領域】報道・政治・人物をめぐる論争。  

【文法パターン】character assassination／a campaign of character assassination／accuse someone of character assassination。  

【コロケーション・構文例】

・a campaign of character assassination  
用途: 継続的な人格攻撃を述べる。  
例: The article examines a campaign of character assassination against the candidate.  
訳: その記事は、候補者への一連の人格攻撃を検証している。  

【語法・注意】assassination はここでは実際の殺人ではなく、評判を傷つける比喩。批判される側がそう呼んだだけで、すべての批判が不当だと確定するわけではない。法的な名誉毀損の要件とも同一ではない。  

15. 【名詞句：可算】人柄についての推薦・証明

【日本語訳・定義】character reference の形で、人柄・誠実さ・信頼性などについて述べる推薦・証明。職務上の専門能力を中心に評価する推薦とは、説明の焦点が異なる。  

【頻度】〈4/10〉  

【レジスター/領域】推薦・就職・人物証明の説明。  

【文法パターン】a character reference／provide a character reference for someone／write a character reference。  

【コロケーション・構文例】

・provide a character reference for someone  
用途: 人物の資質について推薦を行う。  
例: Her former supervisor agreed to provide a character reference for her.  
訳: 以前の上司は、彼女の人柄について推薦状を書くことを承諾した。  

【語法・注意】この character reference は文章内の文字を参照することではない。推薦者が何を証言できるか、提出先が何を要求するかは個別の状況による。能力や仕事ぶりに触れることもあり得るが、専門的な職務能力の評価すべてをこの句の中心定義にはしない。単独 character の推薦義は語義26で別に扱う。  

16. 【形容詞：characterful】独特の味わいがある

【日本語訳・定義】人・物・場所などに、面白く印象に残る独特の個性があること。  

【頻度】〈3/10〉  

【レジスター/領域】描写・評論・観光や住まいの紹介。  

【文法パターン】a characterful building／a characterful voice／be characterful。  

【コロケーション・構文例】

・a characterful building  
用途: 建物の独特の魅力を評価する。  
例: The gallery occupies a characterful old workshop.  
訳: そのギャラリーは、趣のある古い工房を利用している。  

【語法・注意】「文字がいっぱいある」という意味ではなく、語義6の個性・味わいに対応する。-ful は一つの l で綴る。  

17. 【形容詞：characterless】個性や面白みに乏しい

【日本語訳・定義】印象に残る個性や味わいが乏しく、ありきたりで面白みがないこと。  

【頻度】〈3/10〉  

【レジスター/領域】描写・批評。否定的な評価。  

【文法パターン】a characterless room／a characterless building／be characterless。  

【コロケーション・構文例】

・a characterless room  
用途: 部屋に面白みや個性がないことを述べる。  
例: The room was clean but characterless.  
訳: その部屋は清潔だったが、個性や面白みはなかった。  

【語法・注意】ここでは道徳的に悪い、人間性がない、という意味を必ず表すのではない。文字データが空という意味でもない。characterful と個性の有無の軸で対照できる。  

18. 【名詞：可算】形質

【日本語訳・定義】生物の形・機能・行動・分子的な性質など、観察・比較の対象となる特徴。生物学では「形質」と訳す。  

【頻度】〈3/10〉  

【レジスター/領域】生物学・分類・進化の議論。  

【文法パターン】a morphological character／inherited characters／a derived character／compare characters。  

【コロケーション・構文例】

・a morphological character  
用途: 形態に関わる形質を述べる。  
例: Leaf shape is one morphological character used in the comparison.  
訳: 葉の形は、その比較で使う形態的形質の一つである。  

・compare characters  
用途: 生物の特徴を比較する。  
例: The researchers compared anatomical and molecular characters.  
訳: 研究者たちは、解剖学的形質と分子的形質を比較した。  

【語法・注意】人の性格に限定せず、見た目だけにも限定しない。遺伝だけで決まると一律に定義せず、環境や発達の影響を含む文脈もある。日常語の characteristic と近いが、専門文脈での分類単位や測定方法は研究ごとに確認する。  

19. 【名詞：不可算】人物描写・人物造形

【日本語訳・定義】小説や劇で、人物の性格や個性をどのように描き出しているかという描写・造形の側面。  

【頻度】〈3/10〉  

【レジスター/領域】文学・演劇の批評。  

【文法パターン】strong in character／character and plot／character development。  

【コロケーション・構文例】

・strong in character  
用途: 作品の人物描写が優れていると評する。  
例: The novel is strong in character but less convincing in plot.  
訳: その小説は人物描写に優れるが、筋書きの説得力は劣る。  

【語法・注意】a character は登場する一人、character という不可算の批評用語は人物をどう描くかという側面。character development は物語内で人物が成長・変化することを指す場合もあり、常に作者の技法だけを意味するわけではない。  

20. 【名詞：通常単数】資格・立場

【日本語訳・定義】ある人がどのような役割・資格で行動するかという立場。  

【頻度】〈2/10〉  

【レジスター/領域】硬い、または古い文章の役割説明。  

【文法パターン】in one's character as 〈役割〉／in the character of 〈役割〉。  

【コロケーション・構文例】

・in one's character as 〈役割〉  
用途: どの立場で行動するかを示す。  
例: He addressed them in his character as the head of the household.  
訳: 彼は一家の長という立場で、彼らに話しかけた。  

【語法・注意】現代の一般的な説明では in one's capacity as や as が明確な場合が多い。「家長の性格になりきった」という演技の意味ではなく、その人の立場を表す。  

21. 【名詞：可算】人物類型を描いた短文

【日本語訳・定義】ある種の人の性質や振る舞いを短く描写する文学的な文章。登場人物そのものではなく、人物類型の描写を一つの作品として指す。  

【頻度】〈2/10〉  

【レジスター/領域】文学史・人物素描。とくに近世の英文学についての議論。  

【文法パターン】a character of 〈人物類型〉／a collection of characters。  

【コロケーション・構文例】

・a collection of characters  
用途: 人物類型の短い描写を集めた作品を述べる。  
例: The book is a collection of characters, each portraying a different social type.  
訳: その本は、異なる社会的な人物類型を一編ずつ描いた人物素描集である。  

【語法・注意】文献の文脈なしに characters をいつも「人物素描」と訳さない。一般には登場人物や文字の複数形が先に考えられる。character sketch は人物の特徴を描く文章・描写であり、特定の歴史的ジャンルだけに限定されない。  

22. 【名詞：可算】指標

【日本語訳・定義】群の有限次元複素表現について、各群要素に対して、その要素を表す行列のトレースを対応させる関数。「指標」と訳す。  

【頻度】〈2/10〉  

【レジスター/領域】数学・群の表現論。  

【文法パターン】the character of a representation／an irreducible character／a character table。  

【コロケーション・構文例】

・the character of a representation  
用途: 表現に対応する指標を述べる。  
例: The character of the representation is constant on each conjugacy class.  
訳: その表現の指標は、各共役類上で一定である。  

【語法・注意】ここでの trace は行列の対角成分の和で、文字の形をなぞることではない。指標の単位元における値は、この設定では表現の次元になる。「特徴」という一般訳だけでは、何を計算するのかを示せない。  

23. 【名詞：可算】秘跡による消えない霊的な印

【日本語訳・定義】カトリックの教理で、洗礼・堅信・叙階の秘跡によって与えられる、消えない霊的なしるしを指す。  

【頻度】〈2/10〉  

【レジスター/領域】カトリック神学・秘跡の説明。  

【文法パターン】a sacramental character／an indelible character／confer a character。  

【コロケーション・構文例】

・an indelible character  
用途: 教理上の消えない霊的な印を述べる。  
例: Catholic teaching describes these sacraments as conferring an indelible character.  
訳: カトリックの教えでは、これらの秘跡は消えない霊的な印を与えると説明される。  

【語法・注意】ここでは本人の性格や人格の良し悪しを意味しない。宗教上の用語であり、身体に見える傷や印という説明でもない。対象の秘跡とその教理上の効果は、一般語義から推測せず区別する。  

24. 【他動詞：まれ・古風】描写する・特徴づける

【日本語訳・定義】人物や物事がどのようなものかを描写し、特徴づける。通常の現代文では characterize や describe が選ばれやすい。  

【頻度】〈1/10〉  

【レジスター/領域】古風な文章・文学的用法。  

【文法パターン】character someone/something as 〈性質・役割〉／be charactered as 〈性質・役割〉。  

【コロケーション・構文例】

・be charactered as 〈性質・役割〉  
用途: 古風な文体で人物の描写を述べる。  
例: In the old account, he is charactered as a man of unusual courage.  
訳: その古い記述では、彼は並外れた勇気を持つ人物として描かれている。  

【語法・注意】charactered はこの他動詞の過去分詞であり、characterized の綴り間違いではない。ただし一般的な現代の作文で頻繁に使う基本動詞として覚えない。辞書に無標示の記載があっても、全用法が日常的だとは限らない。  

25. 【他動詞：古風】書き記す・刻みつける

【日本語訳・定義】文字や記号を書き記したり、表面に刻みつけたりする。  

【頻度】〈1/10〉  

【レジスター/領域】古語・古風な文学表現。  

【文法パターン】character 〈文字・語〉／be charactered on 〈表面〉。  

【コロケーション・構文例】

・be charactered on 〈表面〉  
用途: 古風な表現で刻まれた文字を述べる。  
例: The words were charactered on a slab of stone.  
訳: その言葉は、一枚の石板に刻みつけられていた。  

【語法・注意】現代の普通の説明では write、inscribe、engrave などを使う。語義24は性質を描写し、こちらは文字や印を物理的に記すため、同じ動詞形でも対象と行為を区別する。  

古い文献で character が書体・書きぶりや暗号などを指す場合もある。通常の文章での主要義と同じ頻度で扱わず、文献の時代・分野と周辺の語から判断する。  

26. 【名詞：可算】人物評価の証明・推薦書

【日本語訳・定義】character 単独で、人の資質・勤務ぶり・信頼性などについて述べた人物評価や推薦書を指す用法。  

【頻度】〈1/10〉  

【レジスター/領域】辞書に載る限定的な用法。人物の証明・推薦に関する文脈。  

【文法パターン】give someone a good character／a character from a former employer。  

【コロケーション・構文例】

・give someone a good character  
用途: 元の雇用者などが好意的な人物評価を与えることを述べる。  
例: His former employer gave him a good character.  
訳: 以前の雇用者は、彼について好意的な人物評価を出した。  

【語法・注意】good character を持つという本人の人格の説明と、雇用者などが与える評価・証言を区別する。推薦書の形を取る場合もあるが、この表現だけで常に書面であると決まるわけではない。この単独義と、現代に使われる character reference という複合語の遭遇頻度を同一に扱わない。  

明確な現代的表現が必要な場面では、人物の資質についてなら character reference、仕事についての推薦一般なら reference などを文脈に合わせて選ぶ。
