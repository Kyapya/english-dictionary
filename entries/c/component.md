＃発音記号

米: /kəmˈpoʊnənt/｜英: /kəmˈpəʊnənt/。3音節で第2音節に主強勢がある。英米差は第2音節の二重母音で、米 /oʊ/、英 /əʊ/。第1・第3音節の母音は弱い /ə/。名詞と形容詞で基本的な発音は変わらない。複数形 components では語末に /s/ が加わり、音節数と強勢位置は変わらない。  

componential analysis は米: /kɑːmpəˌnenʃl əˈnæləsɪs/｜英: /kɒmpəˌnenʃl əˈnæləsɪs/。この表記では全体で8音節、第6音節に主強勢、第3音節に副強勢がある。英米差は第1音節の米 /ɑː/ と英 /ɒ/。componential の語末の /l/ が音節の中心になる読みを含む。  

＃語源

ラテン語 componere（組み合わせる）の現在分詞 componens の語幹 component- に由来する。com- は一緒に、ponere は置くという要素で、全体を組み立てる部分という意味につながる。compose と語源を共有するが、現代英語で compose に規則的な接尾辞を付けただけの形ではない。  

＃語形成

・componential：構成要素に関わるという形容詞。componential analysis は、語の意味を特徴に分けて扱う言語学の用語。  

＃コアイメージ

全体を組み立てる、区別可能な構成単位という捉え方。機器・ソフトウェア・数学・意味の分析で、何を一つの全体とし、どの単位に分けるかが変わる。  

・全体を組み立てる区別可能な部分 → 「構成要素、部品」（語義1）  

・ソフトウェアを組み立てる機能単位 → 「ソフトウェアの構成単位、UI部品」（語義2）  

・全体の構成部分であるという関係 → 「全体を構成する」（語義3）  

・合成して全体のベクトルを作る部分 → 「ベクトルを構成する方向別のベクトル成分」（語義4）  

・座標表現を組み立てる個々の数値 → 「座標値、数値としての成分」（語義5）  

・映像情報を構成成分に分けて扱う方式 → 「信号を成分別に分けた、コンポーネント方式の」（語義6）  

・語の意味を成す特徴を調べる分析 → 「意味の成分分析」（語義7）  

＃意味・用法・関連表現

1. 【名詞：可算】構成要素、部品

【日本語訳・定義】機械・仕組み・計画などの全体を構成する、区別できる一つの部分。物理的な部品だけでなく、成分・機能・抽象的な要因にも使う。  

【頻度】〈8/10〉  

【レジスター/領域】一般・技術・仕事・分析。  

【文法パターン】a component of something／a component in something／a component for something／a key component／electronic components／component failure／stereo components。  

【コロケーション・構文例】

・a component of something  
用途: 部分が属する全体を示す。  
例: Training is an important component of the new programme.  
訳: 研修は、新しい計画の重要な構成要素である。  

・a component in something  
用途: ある仕組みや関係の中で働く要素を示す。  
例: Mutual trust is a key component in a successful partnership.  
訳: 相互の信頼は、協力関係を成功させる重要な要素である。  

・a component for something  
用途: 部品の用途・組込み先を示す。  
例: The factory produces components for electric vehicles.  
訳: その工場は、電気自動車向けの部品を製造している。  

・a key component  
用途: 特に重要な構成部分を述べる。  
例: The proposal is missing a key component: a realistic budget.  
訳: その提案には、現実的な予算という重要な要素が欠けている。  

・electronic components  
用途: 電子機器の部品をまとめて述べる。  
例: The supplier sells electronic components to small manufacturers.  
訳: その供給業者は、小規模な製造業者に電子部品を販売している。  

・component failure  
用途: 構成部品の故障を名詞を重ねて述べる。  
例: The investigation traced the problem to a component failure.  
訳: 調査の結果、問題の原因は部品の故障にあると分かった。  

・stereo components  
用途: 音響システムを構成する個々の機器を述べる。  
例: The amplifier and tuner are separate stereo components.  
訳: アンプとチューナーは、別々の音響構成機器である。  

【語法・注意】of は全体との所属関係、in は仕組みの中での関わり、for は用途を示しやすい。component 自体が常に不可欠という意味とは限らず、essential component や optional component と修飾できる。component supplier／component failure の component は、部品のという関係を示す名詞の修飾用法として捉えられる。  

【類義語】

・part  
定義: 全体の一部分。  
頻度: 〈10/10〉  
違い: part は最も広い一般語で、場所の一部や時間の一部にも使う。component は、組み立てや働きに関わる区別可能な構成単位を捉えやすい。  
例: Only part of the document was available.  
訳: 文書の一部しか利用できなかった。  

・element  
定義: 全体を形作る部分・要因。  
頻度: 〈9/10〉  
違い: element は性質や基本要因にも広く使う。component は、全体を構成する単位としての区別が意識されやすいが、抽象的な文脈では両者が重なる。  
例: There is an element of uncertainty in every forecast.  
訳: どの予測にも、不確実な部分がある。  

・constituent  
定義: 全体を構成する要素・成分。  
頻度: 〈5/10〉  
違い: constituent は、何から成るかという構成や成分に重点を置く改まった語。component は機器の部品から抽象的な機能まで広く使う。  
例: The analysis identified the main constituents of the mixture.  
訳: 分析によって、その混合物の主な成分が特定された。  

2. 【名詞：可算】ソフトウェアの構成単位、UI部品

【日本語訳・定義】ソフトウェアや画面を、役割ごとの単位として組み立てる際の部分。UIではボタンから画面全体まで、表示や振る舞いをまとめた部品として使われる。  

【頻度】〈6/10〉  

【レジスター/領域】ソフトウェア開発・UI設計。  

【文法パターン】a software component／a reusable component／a parent component／a child component。  

【コロケーション・構文例】

・a software component  
用途: システムを構成するソフトウェア上の単位を述べる。  
例: The update replaces one software component without changing the whole system.  
訳: その更新は、システム全体を変えずに、一つのソフトウェア部品を置き換える。  

・a reusable component  
用途: 複数箇所で利用できるよう作られた部品を述べる。  
例: The team built a reusable component for displaying customer details.  
訳: チームは、顧客情報を表示するための再利用可能な部品を作った。  

・a parent component  
用途: UIの階層で、下位の部品を組み込む側を述べる。  
例: The parent component displays several smaller controls.  
訳: 親コンポーネントは、複数の小さな操作部品を表示する。  

・a child component  
用途: 親に組み込まれる部品を述べる。  
例: The child component shows the selected item's name.  
訳: 子コンポーネントは、選択された項目の名前を表示する。  

【語法・注意】component は、具体的な実装方法まで全ての技術で共通する名称ではない。Reactのように部品を組み合わせる仕組みでも、一度しか使わない component はあり、再利用可能という設計と、実際に複数回使われることを区別する。全てのソフトウェア部品を一律にJavaScriptの関数だと説明しない。  

3. 【形容詞】全体を構成する

【日本語訳・定義】ある全体を成り立たせる部分であることを述べる。名詞の前に置き、その部分が全体の構成単位だと示す。  

【頻度】〈5/10〉  

【レジスター/領域】改まった説明・技術・分析。  

【文法パターン】component parts／component elements。  

【コロケーション・構文例】

・component parts  
用途: 全体を作る各部分を述べる。  
例: The machine was separated into its component parts for inspection.  
訳: 検査のために、その機械は構成部品に分解された。  

・component elements  
用途: 全体の構成要素であることを明示する。  
例: The chapter examines the component elements of the argument.  
訳: その章は、議論を成り立たせる各要素を検討している。  

【語法・注意】この形容詞用法は名詞前で使い、通常 The part is component. や very component のような叙述・程度表現にはしない。a component は名詞、component parts の component は構成するという形容詞で、形が同じでも働きが異なる。  

4. 【名詞：可算】ベクトルを構成する方向別のベクトル成分

【日本語訳・定義】一つのベクトルを、指定された方向に沿う複数のベクトルの和として捉えるときの各ベクトル。成分そのものを向きと大きさを持つ量として述べる用法。  

【頻度】〈4/10〉  

【レジスター/領域】数学・物理。  

【文法パターン】a component of a vector／a horizontal component／a vertical component。  

【コロケーション・構文例】

・a component of a vector  
用途: 合成されて全体を成す方向別のベクトルを述べる。  
例: Each component of the vector points along one of the chosen axes.  
訳: そのベクトルの各ベクトル成分は、選んだ軸の一つに沿う向きを持つ。  

・a horizontal component  
用途: 水平方向に沿うベクトル部分を述べる。  
例: The diagram shows the horizontal component as an arrow pointing to the right.  
訳: 図では、水平方向のベクトル成分が、右向きの矢印で示されている。  

・a vertical component  
用途: 鉛直方向に沿うベクトル部分を述べる。  
例: The vertical component is drawn as an upward arrow.  
訳: 鉛直方向のベクトル成分は、上向きの矢印で描かれている。  

【語法・注意】ここでは component 自体をベクトルとして捉える。方向別の大きさを表す数値も component と呼ばれるため、矢印・ベクトルとして述べているか、座標値として述べているかを確認する。成分が必ず水平・鉛直の二つだけだと一般化しない。  

5. 【名詞：可算】座標値、数値としての成分

【日本語訳・定義】ベクトルや、数値を要素とする順序対などを表す、各座標位置の数値。方向ごとの量を、選んだ座標系における数で示す。  

【頻度】〈4/10〉  

【レジスター/領域】数学・物理・計算。  

【文法パターン】the first component／the x component／a component equal to zero。  

【コロケーション・構文例】

・the first component  
用途: 順序のある成分の最初の値を述べる。  
例: The first component of the ordered pair is three.  
訳: その順序対の第一成分は三である。  

・the x component  
用途: x軸方向に対応する数値を述べる。  
例: The x component of the vector is negative in this coordinate system.  
訳: この座標系では、そのベクトルのx成分は負である。  

・a component equal to zero  
用途: ある位置の成分がゼロだと述べる。  
例: The calculation gives a vector with one component equal to zero.  
訳: その計算では、一つの成分がゼロであるベクトルが得られる。  

【語法・注意】順序対の構成要素は一般には数値に限られないが、この語義では数値である場合を扱う。数値としての component は、選んだ座標系や単位などの条件に依存する。ベクトル成分を向きのある矢印で表す用法と、ここでの数値を同一の種類の対象として混同しない。  

6. 【形容詞：映像信号】信号を成分別に分けた、コンポーネント方式の

【日本語訳・定義】映像に関する情報を複数の信号・チャンネルに分けて扱う方式を表す。全ての情報を一つの信号にまとめる方式と区別するために使われる。  

【頻度】〈3/10〉  

【レジスター/領域】映像機器・信号方式。  

【文法パターン】component video／a component input／a component signal。  

【コロケーション・構文例】

・component video  
用途: 映像情報を分けて伝える方式を述べる。  
例: The manual lists component video among the supported connection types.  
訳: 取扱説明書は、対応する接続方式の一つとしてコンポーネント映像を挙げている。  

・a component input  
用途: その方式の信号を受ける入力を述べる。  
例: The monitor has a component input for compatible equipment.  
訳: そのモニターには、対応機器用のコンポーネント入力がある。  

・a component signal  
用途: 成分を分けた映像信号を述べる。  
例: The converter accepts a component signal from the source device.  
訳: その変換器は、出力元の機器からコンポーネント信号を受け取る。  

【語法・注意】一般的な部品という名詞義ではなく、映像信号の方式を区別する語。名称だけから、端子の形・信号の仕様・機器同士の互換性まで判断しない。具体的な接続条件は機器の説明で確認する。  

7. 【名詞句：不可算・可算・componential analysis】意味の成分分析

【日本語訳・定義】言語学で、語の意味を、共通する意味特徴や他の語と区別する意味特徴の組合せとして分析する方法。綴りや発音を小さく切り分けることそのものではない。  

【頻度】〈2/10〉  

【レジスター/領域】言語学・意味論。  

【文法パターン】use componential analysis／a componential analysis of something。  

【コロケーション・構文例】

・use componential analysis  
用途: 語の意味を特徴に分けて分析する方法を用いる。  
例: The researcher used componential analysis to compare the meanings of several related verbs.  
訳: 研究者は、意味の成分分析を用いて、関連する複数の動詞の意味を比較した。  

・a componential analysis of something  
用途: 特定の語群についての一つの分析を述べる。  
例: The chapter presents a componential analysis of words describing movement.  
訳: その章は、移動を表す語の意味についての成分分析を提示している。  

【語法・注意】方法一般としては不可算だが、特定の対象について行った一つの分析なら analysis を可算として扱える。componential の component は意味を成す特徴に関わる。接頭辞や接尾辞などを分ける語形成・形態の分析と、同じ作業だと考えない。
