＃発音記号

米: /kɔːr/｜英: /kɔː(r)/。1音節。英米差は第1音節末の /r/ で、米音では発音し、英音の括弧付き /r/ は後ろに母音が続く場合などの連結で現れる。名詞・形容詞・動詞で基本の発音は同じ。  

複数形・三人称単数現在形 cores は米: /kɔːrz/｜英: /kɔːz/、過去形・過去分詞 cored は米: /kɔːrd/｜英: /kɔːd/。どちらも1音節で、英米差は第1音節の母音に続く /r/ の有無である。coring は米・英: /ˈkɔːrɪŋ/。2音節で第1音節に主強勢があり、母音が続くため英音にも /r/ が現れる。corps の単数形とは同音になるが、corpse は語末に /s/ があり別の語である。  

＃語源

中英語から使われているが、語の起源は確定していない。心臓を意味するラテン語 cor と形や意味が似ていることだけで、直接の由来と断定しない。果実の芯を取り除く動詞は、名詞 core を基にした用法である。  

＃語形成

・cores：名詞の複数形、または動詞の三人称単数現在形。前後の構造で区別する。  

・cored：動詞の過去形・過去分詞。a cored apple は、芯を取り除いたリンゴという受動的な関係を示す。  

・coring：動詞の -ing 形。綴りは語末の e を落として作る。  

・corer：芯やコアを取り出す道具・器具を表す名詞。果実の芯抜き器やコア試料の採取器具などを指し、core の比較級として作られた形ではない。  

＃コアイメージ

外側や周辺に対して、内部を構成する部分や機能上の中核。物体の芯だけでなく、活動を支える主要部分を指し、専門用法では何の内部・中核として扱うかによって対象が定まる。  

・物事の中心を成す本質的な内容 → 「核心、本質、最も重要な部分」（語義1）  

・物体の中心を成す内部の部分 → 「物の中心部、内部の核」（語義2）  

・果実の中心を成す種を含む部分 → 「果実の芯」（語義3）  

・活動の中心を成す主要な部分 → 「主要な、中核の、基本となる」（語義4）  

・胴体の中心を成す筋肉のまとまり → 「体幹の筋群、胴体中心部」（語義5）  

・活動の中心を成す人のまとまり → 「中心を成す人々、中核集団」（語義6）  

・果実の中心部分を取り除く動作 → 「果実の芯を取り除く」（語義7）  

・対象の中心まで及ぶ深さや程度 → 「芯まで、心底、徹底的に：to the core」（語義8）  

・命令処理の中心を成すCPU内の単位 → 「CPUの処理コア」（語義9）  

・変動の大きい品目を除いて捉える物価の基調 → 「物価の基調を見るため一部の品目を除いた」（語義10）  

・原子炉の中心を成す反応部分 → 「原子炉の炉心」（語義11）  

・対象の内部を抜き出した試料 → 「内部から採った柱状の試料」（語義12）  

・内部の試料となる部分を取り出す動作 → 「コア試料を採取する」（語義13）  

・磁気回路の中心を成す材料・部材 → 「コイルなどの磁性体の芯、鉄心」（語義14）  

・鋳型内部の形を作る部材 → 「鋳型の中子」（語義15）  

・建物の設備や動線をまとめる中核部分 → 「建物の設備・縦動線をまとめたコア」（語義16）  

・ケーブル内部を構成する導体単位 → 「ケーブルの芯線・絶縁された導体」（語義17）  

・剥片を採る元となる石の塊 → 「石器の材料となる石核」（語義18）  

・磁気的な記憶を担う素子 → 「磁気コアメモリの記憶素子」（語義19）  

＃意味・用法・関連表現

1. 【名詞：可算・通常単数】核心、本質、最も重要な部分

【日本語訳・定義】問題・議論・考えなどを成り立たせる、中心的で重要な部分。周辺の事情や細部と区別して、何が本質なのかを述べる。  

【頻度】〈8/10〉  

【レジスター/領域】一般・議論・業務・評論。  

【文法パターン】the core of the problem／at the core of something／at its core／get to the core of something／form the core of something。  

【コロケーション・構文例】

・the core of the problem  
用途: 問題の本質的な部分を示す。  
例: The lack of reliable data is the core of the problem.  
訳: 信頼できるデータがないことが、その問題の核心だ。  

・at the core of something  
用途: 中心的な要因や理念の位置付けを示す。  
例: Trust is at the core of a lasting partnership.  
訳: 長続きする協力関係の中心には、信頼がある。  

・at its core  
用途: 対象を本質的に捉えて説明する。  
例: At its core, the dispute is about who has the authority to decide.  
訳: 本質的には、その争いは誰に決定権があるのかという問題だ。  

・get to the core of something  
用途: 周辺の話から重要な点へ到達することを述べる。  
例: Her question got to the core of the disagreement.  
訳: 彼女の質問は、意見の相違の核心を突いた。  

・form the core of something  
用途: 何が中心的内容を構成するかを述べる。  
例: These principles form the core of the training programme.  
訳: これらの原則が、その研修プログラムの中心を成している。  

【語法・注意】at the core of は中心的位置、get to the core of は核心へ到達する動きで、前置詞は構文ごとに読む。core が必ず唯一の原因を意味するわけではなく、中心的な考え・内容・部分にも使える。  

【類義語】

・essence  
定義: そのものをそのものたらしめる本質。  
頻度: 〈6/10〉  
違い: 本質的な性質や特徴に焦点がある。core は問題の中心部分や、中心を成す要素のまとまりにも使う。  
例: Simplicity is the essence of this design.  
訳: 簡潔さが、このデザインの本質だ。  

・heart  
定義: 物事の中心的・最重要の部分。  
頻度: 〈8/10〉  
違い: at the heart of などで core と近く、活力や感情的中心の含みを伴う場合もある。全ての専門分野の core と交換できるわけではない。  
例: The question of fairness lies at the heart of the debate.  
訳: 公平性の問題が、その議論の中心にある。  

2. 【名詞：可算】物の中心部、内部の核

【日本語訳・定義】物体の内側にあり、周囲の部分に包まれた中心的な部分。必ず幾何学的に一点の中心を指すのではなく、内部の層・塊・構造を指すこともある。  

【頻度】〈7/10〉  

【レジスター/領域】一般・科学・構造の説明。  

【文法パターン】the core of something／at the core of something／a solid core／the Earth's core／an inner core。  

【コロケーション・構文例】

・the core of something  
用途: 何の内部中心かを示す。  
例: The core of the structure is surrounded by several protective layers.  
訳: その構造の中心部は、いくつもの保護層に囲まれている。  

・a solid core  
用途: 内部の中心部が固体であることを述べる。  
例: The model contains a solid core inside a hollow shell.  
訳: その模型は、中空の外殻の内側に固体の芯を持つ。  

・the Earth's core  
用途: 地球の中心部を指す。  
例: The diagram shows the Earth's core beneath the outer layers.  
訳: その図は、外側の層の下にある地球の核を示している。  

・an inner core  
用途: さらに内側の中心部を区別する。  
例: The sample has an inner core and a darker outer layer.  
訳: その試料には、内側の芯と、より暗い色の外層がある。  

【語法・注意】the core of the Earth の of は全体と部分の関係を示す。中心という位置だけでなく、内側にまとまった部分を捉えるため、数学の点としての centre と必ず同じではない。天体の構造や組成の詳細は、core という語自体からは決まらない。  

【類義語】

・centre  
定義: 中心となる場所・点・部分。  
頻度: 〈9/10〉  
違い: 米語では center。位置としての中心を広く表す。core は、外側に包まれた内部や、物事を支える中心的な塊を意識させやすい。  
例: Place the marker at the centre of the circle.  
訳: 円の中心に印を置いてください。  

3. 【名詞：可算】果実の芯

【日本語訳・定義】リンゴ・ナシなどの中央にある、種を含む比較的硬い部分。果実全体の形や食べられる部分とは区別して呼ぶ。  

【頻度】〈7/10〉  

【レジスター/領域】日常・調理。  

【文法パターン】an apple core／a pear core／remove the core／cut out the core。  

【コロケーション・構文例】

・an apple core  
用途: リンゴの中央部分を一つの物として述べる。  
例: She left an apple core on the plate.  
訳: 彼女は、皿の上にリンゴの芯を残した。  

・a pear core  
用途: ナシの芯を述べる。  
例: The pear core contained several dark seeds.  
訳: そのナシの芯には、濃い色の種がいくつか入っていた。  

・remove the core  
用途: 果実から芯を取り除く作業を述べる。  
例: Remove the core before slicing the apple.  
訳: リンゴを薄く切る前に、芯を取り除いてください。  

・cut out the core  
用途: 切って芯を取り除くことを述べる。  
例: He cut out the core and divided the pear into pieces.  
訳: 彼は、芯を切り取ってナシを小分けにした。  

【語法・注意】core は種そのものを意味する seed と同じではなく、種を含む中央部分を指す。芯を取り除く動詞 core は、名詞をそのまま動詞として使った別の品詞である。  

4. 【形容詞】主要な、中核の、基本となる

【日本語訳・定義】組織・事業・教育・考え方などを成り立たせる、中心的で重要な部分に属する。周辺的・付随的なものに対し、外せない主要部分を示す。  

【頻度】〈8/10〉  

【レジスター/領域】一般・業務・教育。  

【文法パターン】core business／core subjects／a core curriculum／core values／core members／be core to something。  

【コロケーション・構文例】

・core business  
用途: 企業の中心となる事業を述べる。  
例: The company decided to focus on its core business.  
訳: その会社は、中核事業に集中することを決めた。  

・core subjects  
用途: 教育課程の基本となる科目を示す。  
例: Students take core subjects alongside a choice of electives.  
訳: 学生は、選んだ選択科目に加えて、基本となる科目を履修する。  

・a core curriculum  
用途: 共通の基本課程を述べる。  
例: The university introduced a core curriculum for first-year students.  
訳: その大学は、一年生向けの共通の基本課程を導入した。  

・core values  
用途: 行動や組織を支える基本的価値観を述べる。  
例: Fairness and transparency are among the organization's core values.  
訳: 公平性と透明性は、その組織の基本的価値観に含まれている。  

・core members  
用途: 集団の中心となるメンバーを述べる。  
例: The core members meet weekly to coordinate the work.  
訳: 中核メンバーは、作業を調整するため毎週集まる。  

・be core to something  
用途: 述語位置で、何にとって重要な中核かを示す。  
例: Clear communication is core to effective teamwork.  
訳: 明確な意思疎通は、効果的なチームワークの中核となる。  

【語法・注意】名詞前の用法が多いが、be core to something のような述語用法もあるため、限定用法だけと断定しない。core と同じ形の名詞が名詞を修飾する分析と重なる場合もある。core curriculum の具体的な必修範囲は制度によって異なり、全ての学校で同じ内容を示すわけではない。比較級を機械的に corer と作らない。  

【類義語】

・central  
定義: 中心的で、特に重要な。  
頻度: 〈8/10〉  
違い: central to something と広く使える。core は周辺に対する中核・基本部分という区別を強く出しやすい。  
例: Reliable data is central to the decision-making process.  
訳: 信頼できるデータは、意思決定の過程で中心的に重要だ。  

【反意語】

・peripheral  
定義: 中心ではなく周辺に位置する、重要度が低い。  
頻度: 〈5/10〉  
違い: 中心性の軸で対立する。core が中核・主要部分なら、peripheral は周辺・付随部分を示す。  
例: The discussion focused on peripheral issues rather than the main problem.  
訳: 議論は、主な問題よりも周辺的な事柄に集中した。

6. 【名詞：可算・通常単数】中心を成す人々、中核集団

【日本語訳・定義】組織・運動などの中心となって活動を支える、比較的小さな集団。外側の参加者が変わっても中心部分として残ることを述べる場合がある。  

【頻度】〈6/10〉  

【レジスター/領域】組織・活動・業務。  

【文法パターン】a core of volunteers／a small core of members／form the core of a team／a loyal core。  

【コロケーション・構文例】

・a core of volunteers  
用途: 中心を支える人々を of 以下で示す。  
例: The event depends on a core of experienced volunteers.  
訳: その行事は、中核となる経験豊富なボランティアたちに支えられている。  

・a small core of members  
用途: 少人数の中心集団を述べる。  
例: A small core of members kept the organization running.  
訳: 少人数の中核メンバーが、組織の活動を維持した。  

・form the core of a team  
用途: 誰がチームの中核になるかを述べる。  
例: The original developers still form the core of the team.  
訳: 初期の開発者たちが、今もチームの中核を成している。  

・a loyal core  
用途: 支持を続ける中心集団を述べる。  
例: The club retained a loyal core even during the difficult years.  
訳: 苦しい時期にも、そのクラブには忠実な中核メンバーが残った。  

【語法・注意】a core of people は一つの中核集団を名詞として捉える形。core members は core が members を限定する形容詞用法で、同じ人々を指しても構造が異なる。core の小ささは外側全体との比較であり、特定の人数を定める語ではない。  

7. 【動詞：他動詞、過去分詞修飾を含む】果実の芯を取り除く

【日本語訳・定義】リンゴやナシなどから、種を含む中央の芯を取り除く。名詞 core が表す部分を除去する動作であり、芯を加えるという意味ではない。  

【頻度】〈5/10〉  

【レジスター/領域】調理・レシピ。  

【文法パターン】core an apple／peel and core something／a cored pear／be cored before cooking。  

【コロケーション・構文例】

・core an apple  
用途: リンゴの芯を取り除く作業を述べる。  
例: Core the apple before cutting it into rings.  
訳: リンゴを輪切りにする前に、芯を取り除いてください。  

・peel and core something  
用途: 皮むきと芯の除去を並べて述べる。  
例: She peeled and cored the pears for the dessert.  
訳: 彼女は、デザート用にナシの皮をむき、芯を取り除いた。  

・a cored pear  
用途: 芯を取った状態の果実を過去分詞で修飾する。  
例: Place each cored pear in the baking dish.  
訳: 芯を取り除いたナシを、それぞれ焼き皿に入れてください。  

・be cored before cooking  
用途: 調理前の下ごしらえを受動形で述べる。  
例: The apples are cored before they are cooked.  
訳: リンゴは、加熱調理の前に芯を取り除く。  

【語法・注意】規則活用で core–cored–cored、-ing 形は coring。a cored apple は過去分詞による修飾であり、この動詞が果実を直接目的語に取ることと整合する。remove the core from an apple と言い換えると、除去する部分と処理される果実の関係が見えやすい。  

8. 【前置詞句】芯まで、心底、徹底的に：to the core

【日本語訳・定義】人や物の中心的な部分にまで及ぶほど、完全に・深く、という程度を示す。感情的な衝撃にも、人の性質が根本までそうであるという評価にも使う。  

【頻度】〈6/10〉  

【レジスター/領域】一般・強調的な表現。  

【文法パターン】shake someone to the core／be shocked to the core／be rotten to the core／a professional to the core。  

【コロケーション・構文例】

・shake someone to the core  
用途: 人を深く動揺させることを述べる。  
例: The sudden loss shook him to the core.  
訳: 突然の喪失に、彼は心の底から動揺した。  

・be shocked to the core  
用途: 衝撃の深さを強調する。  
例: She was shocked to the core by what she discovered.  
訳: 発見したことに、彼女は心底衝撃を受けた。  

・be rotten to the core  
用途: 腐敗や悪さが根本まで及ぶという強い評価を述べる。  
例: The novel portrays the fictional regime as rotten to the core.  
訳: その小説は、架空の政権を根っから腐敗したものとして描いている。  

・a professional to the core  
用途: 徹底してある性質を持つ人物を評価する。  
例: Even under pressure, she remained a professional to the core.  
訳: 重圧の中でも、彼女は徹底してプロとして振る舞った。  

【語法・注意】the を含む to the core という形を使う。句全体は程度の深さを示し、必ず否定的とは限らない。a professional to the core のように肯定的な評価にも使える。at the core は中心にある位置、to the core は中心まで及ぶ範囲・程度という違いがある。  

9. 【名詞：可算】CPUの処理コア

・a processor core

訳: 各プロセッサコアは、命令を実行できる。

【語法・注意】six-core のように名詞の前でまとめて修飾すると、core を単数形にしハイフンでつなぐ。一方、six cores は複数形。thread や logical processor の数は物理コア数と必ず一致するわけではなく、全てのCPUで1コアが常に2スレッドという決まりもない。コア数だけで性能比率を断定しない。Intel Core のようなブランド名と、一般名詞の core も区別する。  

10. 【形容詞・経済指標】物価の基調を見るため一部の品目を除いた
