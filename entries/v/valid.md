＃発音記号

米・英: /ˈvæl.ɪd/  
2音節で、第1音節に強勢を置く。第1音節の母音は /æ/、第2音節は短い /ɪ/。語末は /d/ で、母音を付け足さない。  

＃語源

フランス語 valide またはラテン語 validus「強い、効力のある」に由来し、さらに valēre「強い、健全である」にさかのぼる。現在の「効力がある」「根拠がしっかりしている」につながる。同じ valēre に由来する語には value「価値」と valiant「勇敢な」がある。  

＃語形成

・validity（名詞）: 「有効性、妥当性」。the validity of a ticket「切符の有効性」、the validity of a claim「主張の妥当性」。第2音節に強勢が移る。  
・validate（他動詞）: 「有効性・妥当性を確認する、有効にする」。検証と有効化のどちらかは目的語や文脈で決まる。  
・validation（名詞）: 「検証、確認、有効化」。data validation「データの検証」。  
・invalid（形容詞）: 「無効な、妥当でない」。/ɪnˈvæl.ɪd/ と第2音節に強勢を置く。「病弱な人」を指す同綴りの名詞 /ˈɪn.və.lɪd/ とは発音・意味が異なる。  

＃コアイメージ

「判断の基準を満たし、認められる」という共通核がある。基準は、使用上の規則、理由の確かさ、入力条件、推論の成立条件によって変わる。  

・使用の基準を満たして認められること → 「有効な、正式に認められる」（語義1）  

・理由の基準を満たして認められること → 「妥当な、もっともな」（語義2）  

・入力の基準を満たして認められること → 「入力条件を満たす、有効な」（語義3）  

・推論の基準を満たして認められること → 「論理的に妥当な」（語義4）  

＃意味・用法・関連表現

1. 【形容詞】有効な、正式に認められる

【日本語訳・定義】切符・証明書・契約などが、適用される規則や条件を満たし、使用できる、または効力を持つこと。単に本物であることだけでなく、期限・対象・場所などの条件も関係する。  

【頻度】〈8/10〉  

【レジスター/領域】一般、旅行、事務、法律。  

【文法パターン】a valid 〈ticket/passport/contract〉／be/remain valid／be valid for 〈期間/用途〉／be valid until 〈期限〉／be valid from 〈開始時点〉／be valid in 〈地域〉／be valid on 〈交通機関・サービス〉  

【コロケーション・構文例】

・a valid 〈passport/ticket〉  
用途: 使用条件を満たす証明書や切符。  
例: You need a valid passport to complete the application.  
訳: 申請を完了するには有効なパスポートが必要です。  

・be valid for 〈期間〉  
用途: 有効期間の長さ。  
例: This pass is valid for three days from the date of first use.  
訳: このパスは最初に使用した日から3日間有効です。  

・be valid until 〈期限〉  
用途: 有効期限。  
例: The voucher is valid until the end of November.  
訳: この引換券は11月末まで有効です。  

・be valid for 〈用途〉  
用途: 利用できる目的や対象。  
例: The discount is valid for online purchases only.  
訳: この割引はオンラインでの購入にのみ適用されます。  

・be valid in 〈地域〉  
用途: 効力が認められる地域。  
例: This permit is valid in all three districts.  
訳: この許可証は3地区すべてで有効です。  

・be valid on 〈交通機関・サービス〉  
用途: 切符などを利用できる交通機関。  
例: The ticket is valid on local buses but not on express services.  
訳: この切符は路線バスで使えますが、急行便では使えません。  

【語法・注意】名詞の前と be などの後で使う。有効・無効の区別では普通 very valid とはせず、still valid「まだ有効な」、no longer valid「もはや有効でない」とする。for は期間の長さや用途、until は終点を示す。a valid contract は「有効な契約」だが、何をもって有効とするかは法制度や契約内容による。  

【類義語】

・good  
定義: 切符や券などが使える、有効である。  
頻度: 〈7/10〉  
違い: この意味では日常的な言い方。good for two journeys のように使用回数にも使い、valid より意味の広い語。  
例: The coupon is good for one free drink.  
訳: このクーポンで飲み物を1杯無料でもらえます。  

・effective  
定義: 規則・契約などが発効し、効力を持つ。  
頻度: 〈7/10〉  
違い: 効力が生じていることに重点がある。valid は成立・使用条件を満たすことを表し、発効日だけの問題ではない。  
例: The new agreement becomes effective on Monday.  
訳: 新しい協定は月曜日に発効する。  

・legitimate  
定義: 法律や正式な規則にかなって認められる。  
頻度: 〈6/10〉  
違い: 権利・請求・手段などの正当性に焦点がある。切符の有効期限を述べる valid の通常の代わりにはしない。  
例: The company has a legitimate claim to the name.  
訳: その会社にはその名称を使用する正当な権利がある。  

【反意語】

・invalid  
定義: 条件を満たさず、使用や効力が認められない。  
頻度: 〈7/10〉  
違い: 有効・無効という同じ軸上の反対。期限切れ以外の理由でも invalid になる。  
例: The ticket is invalid without a date.  
訳: 日付のない切符は無効です。  

・expired  
定義: 有効期限が過ぎた。  
頻度: 〈7/10〉  
違い: 時間の経過による有効性の喪失を表す。invalid より理由が限定される。  
例: I accidentally brought an expired passport.  
訳: うっかり期限切れのパスポートを持ってきてしまった。  

2. 【形容詞】妥当な、もっともな

【日本語訳・定義】理由・主張・疑問などが筋の通った根拠を持ち、考慮に値すること。方法や判断について、その目的・状況に照らして適切だという意味にもなる。  

【頻度】〈8/10〉  

【レジスター/領域】一般、議論、仕事、学術。  

【文法パターン】a valid 〈reason/point/argument/concern〉／a valid reason for 〈名詞/-ing〉／be/seem valid／equally/perfectly valid／a valid 〈method/comparison〉  

【コロケーション・構文例】

・a valid reason for 〈名詞/-ing〉  
用途: 行動や判断を正当化する理由。  
例: She had a valid reason for asking for more time.  
訳: 彼女が時間の延長を求めたのにはもっともな理由があった。  

・make a valid point  
用途: 議論で筋の通った点を指摘する。  
例: You make a valid point about the cost of repairs.  
訳: 修理費についてのご指摘はもっともです。  

・a valid 〈concern/objection〉  
用途: 無視できない懸念や異論。  
例: The residents raised valid concerns about traffic noise.  
訳: 住民たちは交通騒音についてもっともな懸念を示した。  

・an equally valid 〈approach/method〉  
用途: 別の方法にも妥当性があると認める。  
例: There may be an equally valid approach to solving this problem.  
訳: この問題の解決には、同じくらい妥当な別の方法があるかもしれない。  

・a valid comparison  
用途: 比較に意味があると述べる。  
例: We need data from the same period to make a valid comparison.  
訳: 妥当な比較をするには同じ期間のデータが必要です。  

【語法・注意】限定・叙述の両方で使い、perfectly valid「まったくもっともな」、more valid「より妥当な」などの程度表現も可能。a valid argument は日常的には「筋の通った議論」だが、論理学では語義4の厳密な意味になる。Your feelings are valid.「そう感じるのも無理はないよ」のような言い方は、感情を否定せず受け止めるもので、相手の判断や行動すべてが正しいと認める意味ではない。  

【類義語】

・reasonable  
定義: 考えや判断が常識や理屈にかなっている。  
頻度: 〈8/10〉  
違い: 極端でなく納得できることに重点がある。valid は理由や判断に認めるだけの根拠があることを強調する。  
例: It is reasonable to ask how the money will be spent.  
訳: そのお金がどう使われるのかを尋ねるのは当然だ。  

・sound  
定義: 判断・議論などの基礎がしっかりしている。  
頻度: 〈7/10〉  
違い: 信頼できる根拠や考え方を強調する。日常語の sound は論理学の専門義とは区別する。  
例: The decision was based on sound evidence.  
訳: その決定は確かな証拠に基づいていた。  

・justified  
定義: 理由や証拠によって正当と認められる。  
頻度: 〈7/10〉  
違い: 判断・行動・感情が正当化されることに重点がある。valid は疑問や方法そのものの妥当性にも使う。  
例: Her concern about the deadline was justified.  
訳: 締め切りについての彼女の心配には理由があった。  

・cogent  
定義: 論拠が明快で説得力がある。  
頻度: 〈4/10〉  
違い: 主に議論や説明に使う硬い語。単に妥当という以上に、相手を納得させる力を強調する。  
例: He gave a cogent explanation of the delay.  
訳: 彼は遅延について筋の通った説得力のある説明をした。  

【反意語】

・unfounded  
定義: 主張・懸念などに根拠がない。  
頻度: 〈6/10〉  
違い: 根拠があるかどうかという軸で反対になる。証明されていないことだけで直ちに unfounded とは限らない。  
例: The accusation proved to be unfounded.  
訳: その非難には根拠がないと分かった。  

・unreasonable  
定義: 考えや要求が理屈・常識にかなっていない。  
頻度: 〈7/10〉  
違い: 妥当性の程度上の反対。特に要求や期待が過大な場合にも使う。  
例: It is unreasonable to expect an answer within five minutes.  
訳: 5分以内の返答を求めるのは無理がある。  

3. 【形容詞】入力条件を満たす、有効な

【日本語訳・定義】データ・値・入力内容などが、形式・範囲・認証といったシステムの条件を満たしていること。何が条件なのかは処理によって異なる。  

【頻度】〈6/10〉  

【レジスター/領域】コンピューター、ウェブフォーム、データ処理。  

【文法パターン】a valid 〈value/input/password〉／a valid email address／be valid／valid 〈JSON/XML〉  

【コロケーション・構文例】

・a valid 〈value/input〉  
用途: プログラムが受け付ける値や入力。  
例: Zero is a valid value for this field.  
訳: この欄には0を入力できます。  

・a valid email address  
用途: メールアドレスの入力を求める。  
例: Please enter a valid email address.  
訳: 有効なメールアドレスを入力してください。  

・a valid password  
用途: 認証条件を満たすパスワード。  
例: Access requires a valid password.  
訳: アクセスには有効なパスワードが必要です。  

・valid JSON  
用途: 指定形式に従うデータ。  
例: The server rejected the response because it was not valid JSON.  
訳: 応答が正しいJSON形式になっていなかったため、サーバーは受け付けなかった。  

【語法・注意】限定・叙述の両方で使う。通常は条件を満たすか否かの区別なので very valid とはしない。a valid email address が形式の正しさだけを指す場合、実在や受信可能性まで確認済みとは限らない。valid JSON も、内容が事実として正しいことを保証する表現ではない。  

【類義語】

・acceptable  
定義: 定められた条件の範囲内で、受け付けられる。  
頻度: 〈6/10〉  
違い: 技術用語としての valid より広く、入力以外の許容範囲にも使う。  
例: Only positive integers are acceptable inputs.  
訳: 入力できるのは正の整数だけです。  

・well-formed  
定義: データなどが定められた構文規則に従っている。  
頻度: 〈4/10〉  
違い: 構文の整い方に焦点がある。特にXMLでは well-formed と valid は同じ条件ではなく、valid は追加の定義への適合も問題にする。  
例: The document is well-formed XML.  
訳: その文書はXMLの構文規則に従っている。  

【反意語】

・invalid  
定義: 入力・値などが要求された条件を満たさない。  
頻度: 〈6/10〉  
違い: 同じシステム条件についての直接の反対。形式不備・範囲外・認証失敗など理由はさまざま。  
例: The form displays an error for invalid dates.  
訳: そのフォームは無効な日付に対してエラーを表示する。  

4. 【形容詞】論理的に妥当な

【日本語訳・定義】演繹的な議論・推論で、すべての前提が真なら結論も必ず真となる関係が成立していること。前提が現実に真であるかどうかとは別の性質。  

【頻度】〈4/10〉  

【レジスター/領域】論理学、哲学、数学。  

【文法パターン】a valid 〈argument/inference/deduction〉／be logically valid／a valid argument form  

【コロケーション・構文例】

・a valid argument  
用途: 前提と結論の論理的なつながり。  
例: An argument can be valid even if one of its premises is false.  
訳: 前提の一つが偽でも、議論が論理的に妥当であることはある。  

・a valid inference  
用途: 前提から結論へ進む推論。  
例: The conclusion follows by a valid inference from the two premises.  
訳: その結論は二つの前提から妥当な推論によって導かれる。  

・be logically valid  
用途: 日常的な説得力と区別して論理的妥当性を述べる。  
例: The deduction is logically valid, but we still need to check the assumptions.  
訳: その演繹は論理的に妥当だが、仮定が正しいかはなお確認する必要がある。  

【語法・注意】限定・叙述の両方で使い、厳密な定義では程度を付けず、valid か invalid かを判定する。true は通常、命題・前提・結論の真偽を述べる語。valid と true を同じ意味にしない。sound argument「健全な議論」は、妥当であることに加えて前提がすべて真であることを必要とする。  

【反意語】

・invalid  
定義: 前提がすべて真で結論が偽になる場合を排除できない。  
頻度: 〈4/10〉  
違い: 論理的妥当性についての直接の反対。結論がたまたま真でも、推論自体は invalid であり得る。  
例: The argument is invalid because the conclusion does not follow from the premises.  
訳: 結論が前提から導かれないため、その議論は妥当ではない。
