＃発音記号

米・英: /kwiˈesnt/  
米の別表記・異形: /kwaɪˈɛsənt/、/kwiˈɛsənt/  
英の別表記: /kwɪˈɛsənt/  

現代の形容詞は3音節で、第2音節に主強勢がある。第1音節の母音には、示した表記の /i/、/ɪ/、/aɪ/ の違いがある。/aɪ/ の形も、全体を2音節と数えない。第2音節の /e/ と /ɛ/ は異なる辞書の転写法を含む差で、地域差と直結させない。第3音節を /snt/ と示す形では /n/ が音節の核になることがあり、/sənt/ と弱母音を明示する形と区別する。語頭の /kw/ を保ち、最後の音節の /s/ を /ʃ/ に変えない。  

＃語源

ラテン語 quiescens、語幹 quiescent- にさかのぼる。quiescere「休む・静まる」の現在分詞で、quies「休息・静けさ」に関係する。-esc- はラテン語で状態変化に関わる形成だが、現代の各用法が必ず直前の変化を表すわけではない。  

同根語には quiet「静かな」と acquiesce「黙って受け入れる・黙認する」がある。quiescent を、現代英語の quiet に機械的に -escent を付けてできた語と説明しない。また、活動が静かなことと、相手に同意していることは同じではない。  

＃語形成

・quiescence：名詞。「静止・休止・静穏」など。状態を不可算的に表す。  
・quiescently：副詞。「静かに・活動を休止して」。  
・quiescency：辞書に載る関連名詞。  

quiescence と acquiescence「黙認・受入れ」を取り違えない。  

＃コアイメージ

注目する活動や働きが静まった状態にある、という捉え方が共通する。完全な停止を指す場合と活動の低さを指す場合があり、以前には必ず活動していたという意味でもない。  

・一般の活動が静まった状態 → 「静かな・活動を休止した」（語義1）  
・社会の騒乱が静まった状態 → 「平穏な・騒乱のない」（語義2）  
・疾患の活動が静まった状態 → 「病状が活動・進行していない」（語義3）  
・症状の現れが静まった状態 → 「症状を起こしていない」（語義4）  
・細胞増殖が静まった状態 → 「細胞が増殖を休止した」（語義5）  
・回路の対象動作が静まった状態 → 「静止・待機状態に関する」（語義6）  
・天体活動が静まった状態 → 「天体などが低活動の」（語義7）  
・文字の発音が静まった状態 → 「文字が発音されない」（語義8）  

＃意味・用法・関連表現

1. 【形容詞】静かな・活動を休止した

【日本語訳・定義】人、物、場所などが静かで、目立った動きや活動をしていないこと。  

【頻度】〈2/10〉  

【レジスター/領域】改まった状態描写。頻度は学習上の目安で、実測値ではない。  

【文法パターン】a quiescent town＝活動の静かな町／in a quiescent state＝休止した状態で。  

【コロケーション・構文例】

・a quiescent town  
用途: 町の活動や動きが静かな様子を描く。  
例: We entered a quiescent town just before dawn.  
訳: 私たちは夜明け直前に、静まり返った町に入った。  

・in a quiescent state  
用途: 目立った活動のない状態を述べる。  
例: The project remained in a quiescent state during the winter.  
訳: その計画は、冬の間は動きのない状態にとどまっていた。  

【語法・注意】人・場所・物事などの名詞を前から修飾し、それらを主語にする補語にもなる。in a quiescent state の in は state を核とする名詞句を導き、quiescent 自体に必ず続く補語ではない。  

一時的な休止の含みを持つことがあるが、必ず再開するという予測ではない。対象のあらゆる機能が完全に停止した、死んだ、という意味にも一律にしない。  

【類義語】

・dormant  
定義: 眠っているように、活動を休止している。  
頻度: 〈5/10〉  
違い: 活動を表さず休眠していることを意識させる。quiescent は、注目している動きが静かな・一時的に休止した状態にも使う。両者の全専門用法を同一にはしない。  
例: The proposal lay dormant for several years.  
訳: その提案は、何年もの間棚上げされたままだった。  

【反意語】

・active  
定義: 活動している・活発な。  
頻度: 〈8/10〉  
違い: 注目する活動の有無や程度という軸で対照になる。何の活動かは、一般義と各専門義で確認する必要がある。  
例: The group became active again in the spring.  
訳: その団体は、春に再び活動するようになった。  

2. 【形容詞】平穏な・騒乱のない

【日本語訳・定義】社会や時代などに、騒乱や不和が目立たず平穏であること。  

【頻度】〈1/10〉  

【レジスター/領域】改まった社会・歴史の記述。  

【文法パターン】a quiescent period＝平穏な時期／politically quiescent＝政治的に動きや騒乱が少ない。  

【コロケーション・構文例】

・a quiescent period  
用途: 社会の騒乱が少ない時期を述べる。  
例: The historian describes the decade as a quiescent period between two major upheavals.  
訳: その歴史家は、その十年間を二つの大きな動乱の間の平穏な時期と述べている。  

【語法・注意】時期・社会などの名詞を前から修飾し、それらを主語にする補語にもなる。remarkably でその平穏さを強調したり、politically で政治面という領域に限定したりできる。  

騒乱がないことは、社会が道徳的に望ましいことや、人々が体制へ積極的に同意していることまで意味しない。  

3. 【形容詞】病状が活動・進行していない

【日本語訳・定義】疾患が活動していない、または進行していない状態であること。  

【頻度】〈1/10〉  

【レジスター/領域】医療。  

【文法パターン】a quiescent disease＝活動・進行していない疾患／describe a disease as quiescent＝疾患を非活動性と記述する。  

【コロケーション・構文例】

・describe a disease as quiescent  
用途: 病状の活動性を表す語として読む。  
例: The report describes the disease as quiescent rather than progressive.  
訳: その報告は、その疾患を進行性ではなく非活動性と記述している。  

【語法・注意】疾患を表す名詞の前、またはその疾患を主語とする叙述・目的語補語で使う。病状を分類する用法なので、通常の静けさの程度を比べる very / more を機械的に移さない。describe ... as の as は describe の構文であり、quiescent 固有の必須補語ではない。  

治癒した・病気が消滅したという意味ではない。再び活動する可能性があることと、必ず再発するということも別。この語だけで個別の診断や予後を判定するものではない。  

4. 【形容詞】症状を起こしていない

【日本語訳・定義】病変や感染などが、症状を生じさせていないこと。  

【頻度】〈1/10〉  

【レジスター/領域】医療。  

【文法パターン】quiescent gallstones＝症状を起こしていない胆石。  

【コロケーション・構文例】

・quiescent gallstones  
用途: 症状の有無に焦点を置いて病変を述べる。  
例: The notes refer to quiescent gallstones that caused no symptoms.  
訳: その記録は、症状を生じさせていなかった無症状の胆石に言及している。  

【語法・注意】病変などの名詞を前から修飾する。無症状という分類へ、一般の静けさの more / very を機械的に転用しない。  

語義3の病状の非活動・非進行と、この語義の症状の不在は別の軸である。症状がないことだけで、疾患の活動性や治癒の有無を同じように判定しない。  

5. 【形容詞】細胞が増殖を休止した

【日本語訳・定義】細胞が生存しながら増殖を休止していること。増殖を再開する能力を保つ状態として扱う。  

【頻度】〈1/10〉  

【レジスター/領域】細胞生物学。  

【文法パターン】quiescent cells＝増殖を休止している細胞。  

【コロケーション・構文例】

・quiescent cells  
用途: 細胞の増殖状態を区別する。  
例: The diagram distinguishes quiescent cells from actively dividing cells.  
訳: その図は、増殖を休止している細胞と、活発に分裂している細胞を区別している。  

【語法・注意】cells などを前から修飾し、細胞を主語にする補語でも使う。細胞状態を分類する用法なので、一般義の比較級をそのまま移さない。  

死細胞や代謝が完全にゼロの細胞という意味ではない。また、再開能力を保つことと、すべての細胞が将来必ず増殖を再開することは同じではない。ここでは細胞状態の語義だけを扱い、治療の効果や方法を説明していない。根拠: https://www.cancer.gov/ccg/blog/2018/responses-to-cancer-therapies-are-complex  

6. 【形容詞】静止・待機状態に関する

【日本語訳・定義】電子回路や部品で、特定の動作が行われていない静止・待機状態に関係すること。  

【頻度】〈1/10〉  

【レジスター/領域】電子工学。  

【文法パターン】quiescent current＝静止電流／low quiescent current＝低い静止電流。  

【コロケーション・構文例】

・quiescent current  
用途: 仕様書などの静止電流を読む。  
例: The data sheet lists the quiescent current separately from the shutdown current.  
訳: そのデータシートは、静止電流をシャットダウン電流とは別に記載している。  

【語法・注意】current などの名詞を前から修飾する関係的な用法。low quiescent current の low は電流値の低さをいい、quiescent 自体の程度比較ではない。  

無負荷・非スイッチングなどの状態に伴う電流を指すことがあるが、定義する動作状態は部品や仕様書によって異なる。電源が切れていることや、電流がゼロであることと同一にしない。メーカー資料でも quiescent current と shutdown current が区別される。根拠: https://www.ti.com/document-viewer/lit/html/SSZT118/GUID-F94006BD-D988-4D54-9FEA-AE291C53A9C4  

7. 【形容詞】天体などが低活動の

【日本語訳・定義】天体や天体現象で、注目する活動が少ない状態にあること。何の活動かは対象と文脈で異なる。  

【頻度】〈1/10〉  

【レジスター/領域】天文学・太陽物理学。  

【文法パターン】a quiescent Sun＝黒点活動の乏しい太陽という読み方／a quiescent prominence＝静穏型紅炎／quiescent galaxies＝低活動の銀河。  

【コロケーション・構文例】

・a quiescent Sun  
用途: 辞書にある黒点活動の乏しさの意味を示す。  
例: The chapter describes a quiescent Sun with little sunspot activity.  
訳: その章は、黒点活動の少ない静穏な太陽を説明している。  

・a quiescent prominence  
用途: 大規模な運動などが目立たない紅炎を分類する。  
例: The telescope recorded a quiescent prominence above the solar limb.  
訳: その望遠鏡は、太陽の縁の上方にある静穏型紅炎を記録した。  

・quiescent galaxies  
用途: 星形成の乏しい銀河を対比する文脈などで読む。  
例: The study contrasts star-forming galaxies with quiescent galaxies.  
訳: その研究は、星形成を行う銀河と、星形成の乏しい銀河を対比している。  

【語法・注意】天体・天体現象を表す名詞を前から修飾する。紅炎を主語に、補語として性質を述べる用法もある。技術的な状態分類へ一般義の more / most を機械的に移さず、比較するなら活動の判定軸を区別する。  

黒点活動、紅炎の大規模な動き、銀河の星形成は別の現象である。銀河の用例を「黒点がない銀河」と訳さない。quiescent galaxy の活動軸も文脈によって異なり、上の作例は星形成の対比で読む。宇宙の対象の全運動・全機能が停止したという意味ではない。  

太陽・紅炎・銀河など、何を低活動と評価するかに応じて読み分ける。単一の分類から、天体のすべての活動がないと判断しない。  

8. 【形容詞】文字が発音されない

【日本語訳・定義】文字が綴りに残っていても、その文脈では音として発音されないこと。  

【頻度】〈1/10〉  

【レジスター/領域】古い文法用語や、ヘブライ語文法などの限定された説明。  

【文法パターン】a quiescent letter＝発音されない文字。  

【コロケーション・構文例】

・a quiescent letter  
用途: 文法書中で、文字が音として現れないことを読む。  
例: The final character is a quiescent letter in this grammatical analysis.  
訳: この文法分析では、末尾の文字は発音されない文字として扱われる。  

【語法・注意】letter などを前から修飾し、文字を主語にする補語の用例もある。発音されるかどうかを分類する用法へ、一般の静けさの very / more を一律に移さない。特定の前置詞補語は常に必須ではない。一般向けには silent の方が平易だが、この用法をすべて廃語とはしない。  

古い名詞用法には「発音されない文字」という意味もあるが、現代の一般的な名詞として無条件に使うことは勧めない。形容詞の発音を、そのまま古い名詞の発音と決めつけない。
